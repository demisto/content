
#### Scripts

##### DiagnoseSyslogCollector

- Updated the DiagnoseSyslogCollector script to use the Cortex built-in commands for retrieving broker information and querying the collection auditing logs, instead of the ***core-list-brokers*** and ***core-xql-generic-query-platform*** commands.

##### SearchIndicatorInEvents

- Updated the SearchIndicatorInEvents script to use the ***runXQLQuery*** built-in command on the Cortex platform. Cortex XSIAM tenants that are not on the Cortex platform continue to use the ***xdr-xql-generic-query*** and ***xdr-xql-get-query-results*** commands.
