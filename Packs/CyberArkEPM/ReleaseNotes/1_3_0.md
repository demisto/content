
#### Integrations

##### CyberArk EPM Event Collector

- Added support for CyberArk Identity (Idira ISPSS) OAuth 2.0 `client_credentials` authentication, selectable via the new *Authentication Method* parameter, alongside the existing EPM and SAML methods.  
- Added the *Identity URL* and *Web App ID* parameters, required for the Idira OAuth authentication method.
