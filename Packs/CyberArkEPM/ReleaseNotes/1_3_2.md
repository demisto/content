
#### Integrations

##### CyberArk EPM Event Collector

Added the *EPM API Version* parameter, which sets the version segment of the EPM API data-call paths (`/epm/api/<version>/sets`) for the Idira OAuth authentication method. Leave it empty to use the latest version deployed on the tenant.

- Fixed an issue where set names containing a comma could not be configured. The *Set name* parameter now also accepts a JSON array.
