
#### Integrations

##### TAXII Server

- Fixed an issue where polling the outbound TAXII 1 feed could return an HTTP 500 error.
  - An unhandled exception while building the poll response (e.g. an unknown collection name) no longer crashes the request; the server now returns a proper error response.
  - File indicators whose value is not a valid MD5/SHA1/SHA256/SHA512 hash (such as file paths, file names, or fuzzy/SSDEEP hashes) are no longer sent to the STIX/CybOX serializer, since this produced invalid STIX output that failed schema validation downstream.
  - Invalid XML control characters (e.g. NULL bytes) are now stripped from indicator values before they are embedded in STIX/CybOX observables, preventing XML serialization failures.
