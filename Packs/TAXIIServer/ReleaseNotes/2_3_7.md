
#### Integrations

##### TAXII Server

- Fixed an issue where polling the outbound TAXII 1 feed could return an HTTP 500 error.
- Fixed an issue where File indicators whose value is not a valid MD5/SHA1/SHA256/SHA512 hash (such as file paths, file names, or fuzzy/SSDEEP hashes) were sent to the STIX/CybOX serializer, which produced invalid STIX output that failed schema validation downstream.
- Fixed an issue where invalid XML control characters (e.g. NULL bytes) in indicator values caused XML serialization failures when embedded in STIX/CybOX observables.
