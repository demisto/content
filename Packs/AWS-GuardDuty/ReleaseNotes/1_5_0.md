
#### Integrations

##### AWS - GuardDuty

- Added the ***aws-gd-create-threat-entity-set*** command to create a GuardDuty Threat Entity Set.
- Added the ***aws-gd-list-threat-entity-sets*** command to list the GuardDuty Threat Entity Sets of a detector.
- Added the ***aws-gd-delete-threat-entity-set*** command to delete a GuardDuty Threat Entity Set.
