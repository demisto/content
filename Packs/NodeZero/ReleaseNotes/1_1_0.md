
#### Integrations

##### NodeZero

- Every request to NodeZero now identifies the integration with a `User-Agent` header in the form `NodeZero-Cortex/<pack version> (NodeZero; Cortex <platform version>)` and an `X-Request-ID` header in the form `<run ID>-<n>`. HTTP error messages include the ID of the request that failed, and name the NodeZero endpoint path (for example, `v1/graphql`) instead of the full request URL.
- Fixed an issue where an authentication failure (HTTP 401) showed an error message with no details. The message now says that the API key is invalid or expired.
- Updated the names of the integration's GraphQL operations from `HelloWorld` and `WeaknessesPage` to `CortexXsoarConnectivity` and `CortexXsoarWeaknessesPage`. The operations request the same fields as before.
- Updated the Docker image to: *demisto/py3-tools:1.0.0.14199497*.

<~XSIAM>
##### New: NodeZero Event Collector

- New: Added the **NodeZero Event Collector** integration, which collects every weakness from completed (done) NodeZero pentests, at all severities, as events in the *horizon3_nodezero_raw* dataset. Pentests that are stopped before they complete are not collected.
- Added the ***nodezero-fetch-events*** command, which gets the events of one pentest or of recent pentests on demand, and can send the ones the scheduled fetch hasn't sent yet. The command and the scheduled fetch don't send a pentest that the other already sent.
- Every request to NodeZero identifies the integration with a `User-Agent` header and an `X-Request-ID` header. When NodeZero answers a request with an error, the error message includes that request's ID. For details, see the integration's README.
</~XSIAM>

##### New: Horizon3 NodeZero Modeling Rule

#### XSIAM Dashboards

##### New: NodeZero Overview

- New: Added the **NodeZero Overview** dashboard, which shows key weakness counts, ingestion health, weaknesses by severity, downstream impact, category and proof, the most common weaknesses, the top hosts by severity, and a **Fix first** list of the highest-priority weaknesses from NodeZero events. A **Pentest** filter narrows the dashboard to one or more pentests.
