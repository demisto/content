
#### Integrations

##### ServiceNow MCP

- Renamed the **Authorization code** parameter to **Redirect URL or Authorization Code**. It now accepts the full redirect URL returned after running the `\!servicenow-mcp-generate-login-url` command, in addition to a bare authorization code.
- Pasting the full URL lets Cortex verify the **state** and **iss** parameters on the authorization response, protecting against CSRF and authorization server mix-up attacks.
- Support for pasting only the authorization code is deprecated and will be removed in a future version.
