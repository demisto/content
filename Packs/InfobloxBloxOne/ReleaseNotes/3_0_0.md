
#### Integrations

##### Infoblox Threat Defense with DDI

- Updated the **Fetch incidents** to retrieve the **IQ for TD Insight** as Cortex XSOAR incidents.
- Added support for *IQ for TD Insight Severity* parameter to filter the IQ for TD Insights matching the specified severity.
- Added support for *IQ for TD Insight Threat Properties* parameter to filter the IQ for TD Insights matching the specified threat properties (free text), e.g. malware, phishing, ransomware.
- Added support for *IQ for TD Insight Status* parameter to filter the IQ for TD Insights matching the specified workflow status.
- Added support for ***infobloxcloud-iq-for-td-insight-get*** command to get the full detail view for a single IQ for TD Insight from Infoblox Cloud.
- Added support for ***infobloxcloud-iq-for-td-insight-asset-list*** command to list assets associated with a specific IQ for TD Insight from Infoblox Cloud.
- Added support for ***infobloxcloud-iq-for-td-insight-list*** command to list IQ for TD Insights from Infoblox Cloud.
- Added support for ***infobloxcloud-iq-for-td-insight-status-update*** command to update the workflow status of an IQ for TD Insight from Infoblox Cloud, with an optional analyst comment.
- Added support for ***infobloxcloud-iq-for-td-insight-action-execute*** command to execute a recommendation action on a specific IQ for TD Insight from Infoblox Cloud.
- Added support for ***infobloxcloud-iq-for-td-insight-action-undo*** command to undo a previously executed recommendation action on a specific IQ for TD Insight from Infoblox Cloud.
- Added support for ***infobloxcloud-iq-for-td-insight-event-list*** command to list events for a specific IQ for TD Insight from Infoblox Cloud.
- Added support for ***infobloxcloud-iq-for-td-insight-indicator-list*** command to list threat indicators associated with a specific IQ for TD Insight from Infoblox Cloud.
- Deprecated the ***infobloxcloud-soc-insight-list*** command. Use ***infobloxcloud-iq-for-td-insight-list*** instead.
- Deprecated the ***infobloxcloud-soc-insight-event-list*** command. Use ***infobloxcloud-iq-for-td-insight-event-list*** instead.
- Deprecated the ***infobloxcloud-soc-insight-asset-list*** command. Use ***infobloxcloud-iq-for-td-insight-asset-list*** instead.
- Deprecated the ***infobloxcloud-soc-insight-indicator-list*** command. Use ***infobloxcloud-iq-for-td-insight-indicator-list*** instead.
- Deprecated the ***infobloxcloud-soc-insight-comment-list*** command. No available replacement.
- Updated the default value of the *Ingestion Type* parameter from **SOC Insight** to **IQ for TD Insight**. This change applies to newly created instances only; existing instances keep their saved value and are not affected by this change on upgrade.
- Updated the Docker image to: *demisto/python3:3.12.13.11753038*.

#### Playbooks

##### New: IQ for TD Insight Response - Infoblox Cloud

- Added a new playbook **IQ for TD Insight Response - Infoblox Cloud** that collects the insight's full detail (including AI-generated recommendations), indicators, assets, and events, executes the insight's pending recommendation actions with an undo option, notifies the SOC and assigns an analyst for Low severity, creates a ServiceNow ticket for Medium, High, or Critical severity, and updates the insight's workflow status on Infoblox at the end of the run.
