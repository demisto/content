#### Integrations

##### Netskope - Direct to Zero Trust

- Renamed the pack display name from Netskope API v2 to Netskope - Direct to Zero Trust. The pack folder and integration ID remain unchanged for upgrade compatibility.
- Added API v1 authentication for ***netskopev2-update-file-hash-list*** using a dedicated, credential-backed token.
- Added commands for Destination Profiles, Network Profiles, device classification, private applications, publishers, bulk URL lookup, and file inspection workflows.
- Added an exact `name` argument to ***netskopev2-list-destination-profiles*** and ***netskopev2-list-network-profiles***. Exact-name comparisons are performed locally so input is not interpolated into an API filter expression.
- Improved file hash validation, long-running request handling, duplicate-request handling, and private application JSON argument validation.
- Updated integration setup guidance for API v2 keys, API v1 tokens, and required permissions.
- Updated the Docker image to: *demisto/fastapi:0.125.0.12689358*.
