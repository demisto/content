#### Integrations

##### Netskope - Direct to Zero Trust

- Renamed the pack display name from Netskope API v2 to Netskope - Direct to Zero Trust. The pack
  folder and integration ID remain unchanged for upgrade compatibility.
- Added API v1 authentication for ***netskopev2-update-file-hash-list*** using a dedicated,
  credential-backed token.
- Added commands for Destination Profiles, Network Profiles, device classification, private
  applications, publishers, bulk URL lookup, and file inspection workflows.
- Added an exact `name` argument to ***netskopev2-list-destination-profiles*** and
  ***netskopev2-list-network-profiles***. Exact-name comparisons are performed locally so input is
  not interpolated into an API filter expression.
- Improved file hash validation, long-running request handling, duplicate-request handling, and
  private application JSON argument validation.
- Updated integration setup guidance for API v2 keys, API v1 tokens, and required permissions.

#### Scripts

- Added ***NetskopeBuildProtocolsJson***, ***NetskopeResolvePrivateAppId***,
  ***NetskopeResolvePublishers***, and ***NetskopeMergePrivateAppFields*** for private application
  workflows.
- Added ***NetskopeIndicatorSync*** and ***NetskopeFileHashSync*** with bounded default indicator
  queries, tag exclusions, deduplication, and per-run limits.
- Added ***NetskopeGetXsoarListContent*** and ***NetskopeSetXsoarListContentWithRetry*** to maintain
  the Cortex XSOAR mirror required by the replace-only file hash list API.
- Added ***NetskopeFileScanLabels*** and ***NetskopeURLLookupLabels*** for incident-label output.

#### Playbooks

- Added playbooks for URL and domain blocking, Destination and Network Profile enforcement,
  private application management, Threat Intel synchronization, file inspection, file hash list
  updates, and URL lookup.
- Updated all playbooks to be non-silent and compatible with Cortex XSOAR 6.10.0 and later.
- Added explicit deployment controls and change notes to enforcement workflows. Deployment is
  disabled by default.
- Added safety checks that prevent replace-only file hash list operations when the Cortex XSOAR
  mirror is empty unless `AllowEmptyMirrorOverwrite` is explicitly enabled.
- Removed tenant-specific fallback names and validated synchronization inputs independently.
- Added configurable close reasons and close notes to scheduled synchronization playbooks.
