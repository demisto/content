#### Integrations

##### Orca Event Collector

- Fixed an issue where only a single page of events was fetched per cycle, causing events to be missed on high-volume tenants. Fetching now paginates through the full time window.
- Improved implementation of fetch reliability by using the *LastUpdated* field with a two-sided time window and de-duplication of events on the window boundary.
- Added the *_ENTRY_STATUS* field to each event, indicating whether it is a new or an updated alert.
- Updated the Docker image to: *demisto/python3:3.12.13.11753038*.
