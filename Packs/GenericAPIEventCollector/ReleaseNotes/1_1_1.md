
#### Integrations

##### Generic API Event Collector (Beta)

- Fixed an issue where fetching events failed with the *unhashable type: 'list'* error when *Is pagination needed* was enabled. The next page value is now sent as a query parameter for GET requests and in the JSON body for POST requests.
- Fixed an issue where pagination could loop indefinitely when the API kept returning the same next page value.
- Fixed an issue where the *integer* ID type was ignored, so the last fetched ID was the ID of the last event returned instead of the highest ID.
- Improved implementation so that when the ID type is *integer*, events with an ID higher than the last fetched ID are collected even if their timestamp is older than the last fetch time.
- Fixed an issue where a request parameter referencing a placeholder with no stored value yet (for example, *@last_fetched_id* before the first ID was saved) was sent as literal text. Such parameters are now omitted from the request.
