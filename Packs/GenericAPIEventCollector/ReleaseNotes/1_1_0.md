
#### Integrations

##### Generic API Event Collector (Beta)

- Added support for the *OAuth 2.0* authentication type, supporting both the Client Credentials and the Authorization Code grants.
- Added the ***generic-api-event-collector-generate-login-url*** command, used to generate the login URL for the OAuth 2.0 Authorization Code flow.
- Fixed an issue where the configured *Timestamp format* was ignored when parsing event timestamps.
- Fixed an issue where an event with an unparsable timestamp advanced the last run time to the current time, causing events to be skipped.
- Updated the Docker image to: *demisto/fastapi:0.125.0.10158186*.
