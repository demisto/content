Satellite pack of the Cisco Meraki pack, used by the Cisco Meraki Standard Connector. Its integrations are configured automatically from the connector page and share their logic with the Cisco Meraki pack through the `CiscoMerakiApiModule` and `CiscoMerakiEventCollectorApiModule`.

## What does this pack contain?

- **Cisco Meraki v2 (Standard Connector)**: automation and remediation commands for the Meraki Dashboard API.
- **Cisco Meraki Event Collector (Standard Connector)**: collects configuration changes, network events, API requests and appliance security events into the `cisco_meraki_raw` dataset.
