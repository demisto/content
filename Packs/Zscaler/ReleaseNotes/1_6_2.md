
#### Integrations

##### Zscaler Internet Access

- Fixed an issue where the ***zscaler-get-blacklist*** command returned "No results found" and the ***zscaler-unblacklist-url*** and ***zscaler-unblacklist-ip*** commands failed when the ZIA API returned the blacklist under *blacklistUrlsDetailsList* instead of *blacklistUrls*.

##### Zscaler Internet Access via ZIdentity

- Fixed an issue where the ***zia-denylist-list*** command returned "No items found." when the ZIA API returned the denylist under *blacklistUrlsDetailsList* instead of *blacklistUrls*.
