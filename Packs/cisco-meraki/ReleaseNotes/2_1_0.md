
#### Integrations

##### New: Cisco Meraki Event Collector

- New: Collects configuration changes, network events, API requests and appliance security events from Cisco Meraki into the `cisco_meraki_raw` dataset. Supports OAuth 2.0 and API key authentication.

##### Cisco Meraki v2

- Added support for OAuth 2.0 authentication (supported for the api.meraki.com cluster).
- Added the ***meraki-generate-login-url***, ***meraki-auth-test*** and ***meraki-auth-reset*** commands.
- Added support for the Cisco Meraki regional clusters.
- The integration logic now resides in the *CiscoMerakiApiModule*.
