#### Integrations

##### Rasterize

- Fixed an issue where a concurrent-execution race condition occurred in lightweight mode where multiple simultaneous ***rasterize-email*** or ***rasterize-html*** calls shared the single Chrome instance. One execution could call *terminate_chrome* while another was still navigating, causing the victim to receive a *chrome-error://chromewebdata/* page and enter a lengthy retry loop that exceeded the engine dispatch timeout. A cross-process file lock (*/var/rasterize.lock*) now serialises all *perform_rasterize* calls so executions queue rather than collide.
- Fixed an issue where *terminate_chrome* crashed with an *IndexError* when the Chrome process list was empty (e.g. the process had already been killed by a concurrent execution).
- Improved implementation by capping the *retry_loading* total retry budget to *min(navigation_timeout, 120)* seconds so that a single failed navigation cannot consume more time than the engine's dispatch timeout allows.
