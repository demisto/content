
#### Modeling Rules

##### IBM_AIX Modeling Rule

- Updated the Modeling Rule to support IBM AIX syslog messages sent directly to the Broker VM (standard RFC 3164 header without the `Message forwarded from` prefix).
- Added support for `sshd-session` messages and improved the extraction of the source IP, port, username, authentication method, and outcome from SSH authentication events.
- Added mapping for `su`, `SU_CRON`, and `sudo` events, and a generic mapping for other AIX syslog processes.
