
#### Integrations

##### Lumu SecOps

- New: Added the **LumuSecops** integration for the new Lumu Defender SecOps API with incident operations, security event retrieval/export, fetch support, and bidirectional mirroring.
- Changed: Enriched normalized/mirrored incident payload with latest action metadata and action counts for improved investigation context.
- Changed: Added normalization and remote-data mapping for the **counts** payload into:
    - **lumu_secops_endpoint_targets_count**
    - **lumu_secops_user_targets_count**
    - **lumu_secops_other_targets_count**
    - **lumu_secops_total_targets_count**
    - **lumu_secops_offenders_count**

#### Incident Types

- New: Added incident type **LumuSecops**.
- Changed: Updated incident type **LumuSecops** to use a dedicated **LumuSecops** layout.

#### Classifiers

- New: Added classifier **LumuSecops**.
- New: Added incoming mapper **LumuSecopsInMap**.

#### Incident Fields

- New: Added custom incident fields for LumuSecops events and mirror metadata.
- New: Added custom incident fields for richer SecOps triage context:
    - **lumu_secops_last_action**
    - **lumu_secops_last_action_time**
    - **lumu_secops_last_action_user_id**
    - **lumu_secops_last_comment**
    - **lumu_secops_actions_count**
- New: Added custom Lumu SecOps incident fields for incident target counters:
    - **lumu_secops_endpoint_targets_count**
    - **lumu_secops_user_targets_count**
    - **lumu_secops_other_targets_count**
    - **lumu_secops_total_targets_count**
    - **lumu_secops_offenders_count**

#### Mappers

- Changed: Updated incoming mapper **LumuSecopsInMap** to map triage and target counter fields.
- Changed: Fixed **lumu_secops_status** mapping to use the Lumu SecOps field source.
- Changed: Added mapping for **lumu_secops_last_action**, **lumu_secops_last_action_time**, **lumu_secops_last_action_user_id**, **lumu_secops_last_comment**, and **lumu_secops_actions_count**.

#### Layouts

- New: Added **LumuSecops** layout with dedicated sections for Summary, Latest Activity, and Details.
- Changed: Updated **LumuSecops** layout to use **lumu_secops_status** in the Lumu SecOps Summary section.
- Changed: Added dedicated **Target Counts** and **Latest Activity** sections to the **Lumu SecOps** tab.
