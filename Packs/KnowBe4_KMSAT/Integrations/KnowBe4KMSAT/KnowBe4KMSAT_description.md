## KnowBe4's KSAT Console API

Integrate KnowBe4's KSAT (Security Awareness Training) console with Palo Alto Networks' XSOAR platform for threat intelligence based on KSAT phishing security tests and security awareness training. Then, you can act on risk, automate remediation, and more in your XSOAR platform.

### Subscription Levels & Pricing

API access availability depends on your KnowBe4 subscription level. For details, see the [KnowBe4 Security Awareness Training pricing page](https://www.knowbe4.com/products/security-awareness-training/pricing).

### Generate API Keys

For this integration, you'll need a Reporting API key and User Event API key from your KSAT console. You can generate these API keys from your KSAT Account Settings. For more information, see KnowBe4's [Reporting API](https://developer.knowbe4.com/rest/reporting#tag/Authentication) and [User Event API](https://developer.knowbe4.com/rest/userEvents#tag/Authentication) documentation.
