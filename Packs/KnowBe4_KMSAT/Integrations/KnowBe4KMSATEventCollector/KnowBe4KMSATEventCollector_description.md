KnowBe4 KSAT (Security Awareness Training) allows you to push and pull your external data to and from the KnowBe4 console.

## Subscription Levels & Pricing

API access availability depends on your KnowBe4 subscription level. For details, see the [KnowBe4 Security Awareness Training pricing page](https://www.knowbe4.com/products/security-awareness-training/pricing).

## Create the API Key

1. Go to your KnowBe4 account settings.
2. Click the API Key tab.
3. Create an API Key.
4. In the Name field, enter a unique name for your API key.
5. Click the +Create API Key button.
