
#### Integrations

##### SecurityScorecard Event Collector

- Fixed an issue where scheduled fetches returned no events because the first fetch looked back only 1 minute and the fetch window advanced on every cycle that returned no events.
- Added the *First fetch time* parameter (default: 1 day). The first fetch now starts at midnight UTC of that day.
- The fetch start time is now saved even when a fetch cycle returns no events.
