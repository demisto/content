#### Integrations

##### Simple API Proxy

- Fixed an issue where the API permission definition could be bypassed by using path traversal sequences in the request target. Requests with a target that is not a clean absolute path (for example, containing `..` or `.` path segments, including encoded forms, or backslashes) are now rejected.
- Updated the Docker image to: *demisto/fastapi:0.162.0.14169403*.
