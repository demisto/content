
#### Integrations

##### Doppel

- Added the ***doppel-get-alert-screenshot*** command, which fetches the alert's current screenshot from Doppel and attaches it to the incident as a War Room file entry. The image is stored durably in Cortex XSOAR, so the short-lived signed screenshot URL in the alert payload no longer limits analysts. The command attaches a file only when the screenshot version changed since the last attachment and reports when the attached screenshot is already current (use the *force* argument to re-attach regardless).
- Added the *Attach alert screenshots to incidents* integration parameter (disabled by default). When enabled, incoming mirroring automatically attaches the alert screenshot to the incident whenever the screenshot version changes. Screenshot versions are de-duplicated, so re-signed URLs for an unchanged screenshot never produce duplicate files.
