#### Integrations

##### Doppel

- Fixed an issue where incoming mirroring failed on the first sync for incidents whose *dbotMirrorLastSync* timestamp was not yet set.
- Fixed an issue where ***get-modified-remote-data*** returned only the first page of modified alerts, causing updates to be missed.
- Fixed an issue where incoming mirroring skipped alert updates when the alert had no audit logs.
- Updated the outgoing mirroring to send the incident close notes to Doppel as an alert comment when the incident is closed.
- Updated the *product* argument of the ***doppel-get-alerts*** command to use the correct *email* and *paid_ads* values and to add the *telco* and *darkweb* values. The previous *emails* and *paid_adds* values were not valid Doppel API values and were rejected by the API.
- Fixed an issue where flat entity content objects were dropped from the entity content grid instead of being displayed as rows.
- Improved implementation of error logging in outgoing mirroring to include the full traceback.
- Improved implementation of debug logging in outgoing mirroring to no longer include the content of incident close notes.
- Improved implementation of the alert commands to include the raw API response in the command results.

#### Layouts

##### Doppel Incident Layout

- Updated the **Doppel Incident Layout** layout to display the **Doppel Audit Logs** incident field and the per-product entity content grid fields.

#### Mappers

##### Doppel Incoming_Mapper

- Updated the **Doppel Incoming_Mapper** mapper to map the **Doppel Audit Logs** field, the per-product entity content fields, and the new **Doppel Alert Telco** incident type.

##### Doppel Outgoing_Mapper

- Updated the **Doppel Outgoing_Mapper** mapper to map the incident close notes and to support the **Doppel Alert Telco** incident type.
