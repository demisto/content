
#### Integrations

##### Doppel

- Added the *Select products to fetch* integration parameter. When one or more products are selected, only alerts for those Doppel products are fetched as incidents. No product is selected by default, so existing instances continue to fetch alerts for all products.
- Fixed an issue where ***fetch-incidents*** failed on every run when Doppel refused the alert search as too large (HTTP 422 *result_window_exceeded*, more than 50,000 matching alerts). The integration now fetches such a backlog in smaller time ranges. Fetch requests are unchanged when Doppel does not refuse the search.
- Fixed an issue where incoming mirroring skipped a cycle of updates when Doppel refused the search for modified alerts as too large.
- Added the *last_activity_before* argument to the ***doppel-get-alerts*** command.
- Updated the ***doppel-get-alerts*** command to return a clear error message when Doppel refuses a search as too large.
