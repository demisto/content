
#### Integrations

##### ThreatMon Threat Feed

- Fixed an issue where only the first fetch ingested indicators. Subsequent fetches skipped every IOC that was re-observed by ThreatMon, because the checkpoint was based on the IOC creation time.
- The integration now fetches from the ThreatMon TAXII 2.1 server with full cursor pagination instead of the daily IOC API, which returned at most 1,000 indicators per request.
- Added the *Collections*, *First Fetch Time*, *Look-back Window (minutes)* and *Maximum pages per fetch* parameters. Large fetches resume from the last saved page in the next run.
- Added support for IPv6, CIDR, DomainGlob, Email and Cryptocurrency Address indicators, and the TLP marking published by ThreatMon.
- IP addresses (with or without a port), URLs and Ethereum wallets that ThreatMon publishes as domain names are now ingested with the correct indicator type.
- Added the ***threatmon-get-collections***, ***threatmon-get-fetch-state*** and ***threatmon-reset-fetch-state*** commands.
- Added the *collection* argument to the ***threatmon-get-indicators*** command.
- Removed the *Data Type to Fetch* and *Maximum number of indicators per fetch* parameters. Use *Collections* instead.
