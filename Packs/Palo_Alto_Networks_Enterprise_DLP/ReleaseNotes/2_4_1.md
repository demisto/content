#### Integrations

##### Palo Alto Networks Enterprise DLP

- Fixed an issue where the ***pan-dlp-update-incident*** command failed when the *dlp_channel* argument was not provided, which is how most playbook tasks call it. The channel of the incident the command runs in is now used.
- Fixed an issue where the ***pan-dlp-update-incident*** command failed for incidents from the *SG*, *FR*, *CH* and *SA* regions. The region is now translated to the region name the Enterprise DLP API accepts.
- Fixed an issue where the ***pan-dlp-update-incident*** command reported an unsuccessful update instead of an error when the Enterprise DLP API rejected the update. The command now returns an error that includes the reason, and fails with a clear error for incidents from channels that do not support feedback, such as *saas-api*.
- Fixed an issue where the ***pan-dlp-update-incident*** command failed when granting an exemption and the response did not include the exemption duration.
- Updated the ***pan-dlp-update-incident*** command outputs in the documentation to match the context paths the command writes: *IncidentUpdate* and *Exemption*.
