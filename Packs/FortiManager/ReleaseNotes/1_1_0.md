
#### Integrations

##### FortiManager

- Added the *Workspace Mode - lock the ADOM before changes* integration parameter. When enabled, write commands lock the ADOM, commit the change, and unlock the ADOM, so they work when FortiManager Workspace Mode is set to Normal.
- Improved implementation of error handling to include the error returned by FortiManager.
- Updated the Docker image to: *demisto/python3:3.12.16.14990175*.
