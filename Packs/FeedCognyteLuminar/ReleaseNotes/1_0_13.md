#### Integrations

##### New: Cognyte Luminar V3 Feed

- New feed integration that fetches intelligence-based IOCs and customer-related leaked records identified by Luminar using the Luminar TAXII 2.1 external API (STIX 2.1). Supports incremental fetching with per-collection checkpoints, OAuth2 client-credentials authentication, and creates STIX relationships via a dummy indicator. STIX `incident` objects become `Luminar Incident` indicators. See the integration README.md file for the full field mapping documentation.

#### Indicator Types

##### New: Luminar Incident

- New indicator type for Luminar `incident` objects (leak bundles), enabling relationship edges between leaked accounts and the incidents they belong to.

#### Indicator Fields

##### New: Luminar indicator fields

- Added 24 new indicator fields to store Luminar-specific data: Luminar Score, Luminar Threat Score, Luminar Collection Date, Luminar Valid Until, Luminar Last Seen, Luminar Resolving Domains, Luminar Conviction Reasons, Luminar Protocols, Luminar Threat Types, Luminar Targeted Systems, Luminar Targeted Locations, Luminar Targeted Industries, Luminar Cloud Provider, Luminar MITRE ATT&CK IDs, Luminar IP Type, Luminar City, Luminar Computer Name, Luminar Leaked Credential, Luminar Leak Source, Luminar Leak URL, Luminar Monitoring Plan Terms, Luminar Credential Is Fresh, Luminar Incident Name, Luminar Incident Description.
