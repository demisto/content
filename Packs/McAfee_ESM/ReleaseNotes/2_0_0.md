
#### Integrations

##### McAfee ESM v2

- **Breaking change**: Removed support for ESM versions earlier than 11.6, which reached Trellix end-of-life.
- Added support for Trellix ESM 11.6.11 and later, which require the login credentials to be AES-encrypted. The integration applies the encryption automatically - no manual encryption is required.
- The **Version** parameter now takes the exact ESM version number, for example *11.6.11*. Instances configured with a version earlier than 11.6.0 now fail with an explicit error until the parameter is updated.
- Fixed an issue where credentials containing non-ASCII characters caused the login to fail.
- Updated the Docker image to: *demisto/crypto:1.0.0.8931184*.
