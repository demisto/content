
#### Integrations

##### McAfee ESM v2

- Updated the minimum supported ESM version to *11.6.0*. Support for earlier versions was removed, as they reached Trellix end-of-life.
- Updated the *Version* parameter to take the version number of the ESM instance, for example *11.6.11*. Instances configured with a version earlier than *11.6.0* now fail with an explicit error until the parameter is updated.
- Added support for Trellix ESM *11.6.11* and later, which require the login credentials to be AES-encrypted. The integration applies the encryption automatically, so no manual encryption is required.
- Improved implementation to cache the ESM session between command executions instead of logging in on every run.
- Fixed an issue where credentials containing non-ASCII characters caused the login to fail.
- Updated the Docker image to: *demisto/crypto:1.0.0.8931184*.
