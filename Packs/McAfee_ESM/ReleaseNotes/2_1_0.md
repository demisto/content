
#### Integrations

##### McAfee ESM v2

- Fixed an issue where fetch incidents stopped fetching new alarms and kept the same last run until the last fetch timestamp was reset. Each fetch now queries a bounded time window that always moves forward, even when ESM returns no alarms.
- Added the *Maximum fetch window (hours)* parameter, which sets the maximum time range that a single fetch queries for alarms.
- Fixed an issue where dates returned by an ESM configured with a day-first date format were parsed with the day and month swapped, and failed to parse when the day was greater than 12.
- Added the *ESM date format* parameter, which sets the date format configured for the ESM user.
