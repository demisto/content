
#### Integrations

##### McAfee ESM v2

- Fixed an issue where an ESM with a day-first date format read the alarms query time range with the day and month swapped. As a result, fetch incidents retrieved old alarms or stopped retrieving new alarms, and custom time ranges in the ***esm-fetch-alarms*** command returned alarms from the wrong dates.
- Added the *ESM date format* parameter. Select *DD/MM/YYYY* if the ESM uses a day-first date format.
- Fixed an issue where the *McAfee ESM Timezone in hours* parameter did not accept half-hour offsets. You can now enter a decimal number, for example *5.5* for an ESM timezone of +05:30.
