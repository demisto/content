
#### Integrations

##### New: Taegis XDR v3

New: For integration with the Secureworks Taegis XDR platform. Adds Taegis XDR case ingestion, bi-directional mirroring, and assignee and status management.

- All 20 **TaegisXDR v2** command names are preserved verbatim, so existing playbooks continue to work without modification after switching instances.
- Added 2 new commands:
  - **taegis-push-assignee-status** - Push assignee and status changes back to Taegis XDR from the incident layout.
  - **taegis-close-investigation** - Close a Taegis XDR investigation, with optional archive-on-close.
- Added support for bi-directional incident mirroring (`isremotesyncin` and `isremotesyncout`), including comment, status, and assignee sync.
- Added support for configurable API and XDR console base URLs, replacing the fixed environment picker.
- Available from Cortex XSOAR 6.13.0.

##### TaegisXDR v2 (Deprecated)

- Deprecated the integration. Use **Taegis XDR v3** instead.

#### Incident Types

##### New: Taegis XDR - Case

New: Custom incident type for ingested Taegis XDR cases.

#### Incident Fields

##### New: Taegis XDR Case Status

New: The current status of the Taegis XDR case.

##### New: Taegis XDR Case Type

New: The Taegis XDR case type.

##### New: Taegis XDR Case Detections

New: Detections associated with the Taegis XDR case.

##### New: Taegis XDR Case Entities

New: Entities associated with the Taegis XDR case.

##### New: Taegis XDR Key Findings

New: Key findings recorded on the Taegis XDR case.

##### New: Taegis XDR Close Reason

New: The reason the Taegis XDR case was closed.

##### New: Taegis XDR Archive on Close

New: Whether to archive the Taegis XDR case when the incident is closed.

##### New: Taegis XDR Case Comments Synced IDs

New: Tracks which Taegis XDR case comments have already been mirrored.

##### New: Taegis XDR Detection Status

New: The status of the detection associated with the case.

##### New: Taegis XDR Assignee

New: The analyst currently assigned to the Taegis XDR case.

##### New: Taegis XDR Assignee ID

New: The Taegis XDR user ID of the current assignee.

##### New: Taegis XDR Assignee Previous

New: The previous assignee, used to detect assignee changes for mirroring.

##### New: Taegis XDR Assignee Options Data

New: Cached Taegis XDR user list backing the assignee picker.

##### New: Taegis XDR Requested Assignee

New: The assignee requested from the incident layout, pending push to Taegis XDR.

##### New: Taegis XDR Requested Status

New: The status requested from the incident layout, pending push to Taegis XDR.

#### Classifiers

##### New: TaegisXDR-Case-Classifier

New: Routes incoming Taegis XDR cases to the **Taegis XDR - Case** incident type.

##### New: TaegisXDR-Case-Incoming-Mapper

New: Maps Taegis XDR case fields onto Cortex XSOAR incident fields.

##### New: TaegisXDR-Case-Outgoing-Mapper

New: Maps Cortex XSOAR incident fields back onto Taegis XDR case fields.

#### Layouts

##### New: Taegis XDR Case

New: Custom incident layout with case tabs, a close form including archive-on-close, and assignee and status action buttons.

#### Playbooks

##### New: Taegis XDR Case Playbook

New: Abbreviated triage playbook. On case pickup it assigns the investigating analyst as owner, prompts review, and optionally closes the case.

#### Scripts

##### New: TaegisXDRAddCommentNote

New: Adds a War Room note that mirrors to Taegis XDR as a comment, attributed to the Cortex XSOAR user who added it.

##### New: TaegisXDRAssigneeOptions

New: Populates assignee selection options from Taegis XDR users.

##### New: TaegisXDRCaseCommentsDisplay

New: Dynamic section that renders case comments newest-first, with author, timestamp, and direction.

##### New: TaegisXDRCaseStatusOpenOptions

New: Populates the available Taegis XDR case status options.

##### New: TaegisXDRPushAssigneeStatusForm

New: Pushes assignee and status changes back to Taegis XDR.

##### New: TaegisXDRSetRequestedStatusFromRequestedAssignee

New: Sets the requested status based on the assignee selection.
