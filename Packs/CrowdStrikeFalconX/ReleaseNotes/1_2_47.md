
#### Integrations

##### CrowdStrike Falcon Intelligence Sandbox

Fixed an issue where the ***file*** and ***cs-fx-get-full-report*** commands created excessively large context objects. The full data remains available in the command's raw response.
- Added the *Maximum relationships per file* parameter (default 50) to cap the number of relationships stored per file indicator.
- Added the *Maximum sandbox array entries in context* parameter (default 50) to truncate the large sandbox arrays (*processes*, *http_requests*, *dns_requests*, *contacted_hosts*, *extracted_files*) stored in the context outputs.
- Updated the Docker image to: *demisto/python3:3.12.14.13053055*.
