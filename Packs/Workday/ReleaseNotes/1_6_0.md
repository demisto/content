
#### Integrations

##### Workday

- Updated the default Workday Human Resources API version used by the integration from v34.0 to v47.0.
- Added the *API Version* integration parameter to set the Workday Human Resources API version.
- Documentation and metadata improvements for the *Server URL*, *Username*, *Tenant name* and *Token* parameters.
- Fixed an issue where the ***workday-list-workers*** command and the test failed with a `Client.validationError - Invalid request` error on some Workday tenants.
- Fixed an issue where the ***workday-list-workers*** command failed with a `'NoneType' object is not subscriptable` error when a worker record was missing optional data, such as the hire reason or termination reason.
- Updated the Docker image to: *demisto/python3:3.12.14.13919218*.
