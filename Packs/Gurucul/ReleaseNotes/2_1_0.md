#### Integrations

##### Gurucul-GRA

- Added the *Fetch type* parameter (*Incidents* | *Alerts*). New imports use GRA Incidents or Alerts APIs; Cases are no longer fetched.
- Added the incident commands: ***gra-incidents***, ***gra-incident-action***, ***gra-incident-action-anomaly***, ***gra-incidents-anomaly***.
- Added the alert commands: ***gra-alerts***, ***gra-alert-get***, ***gra-alert-action***, ***gra-alert-update-history***.
- Added the thin War Room alert commands: ***gra-alert-comment***, ***gra-alert-assign***, ***gra-alert-in-progress***.
- Updated the ***gra-alert-action*** documentation for closeAlert *subStatus* enums (Incident: True Positive, Benign Positive, Policy Violation; Not An Incident: Model Review, Disable Model, False Positive).
- Updated the fetch behavior so Incident and Alert fetch use an ID cursor after the first bootstrap (*maxIncidentId* / *maxAlertId*). The time window from *First fetch time* is used only when no cursor exists yet.
- Added the *GRA server timezone* parameter (set the GRA server timezone; default *UTC*) so Incident and Alert fetch parse naive GRA dates (`openDate`, `riskDate`, `detectionTimestamp`) in that zone and store UTC. War Room commands are unchanged.
- Updated the upgrade path so an existing *maxCaseId* last-run cursor is reused as *maxIncidentId* when the Incident cursor is missing (avoids re-bootstrapping with *First fetch time*).
- Set integration defaults for new instances: Mapper (incoming) *GRAIncident-Mapper* and Incident type *GRAIncident* (aligned with default *Fetch type* Incidents). Use a separate instance for Alerts with *GRAAlert-Mapper* and *GRAAlert*.
- Incident and Alert fetch now consume GRA v1 responses (`datasourcename` on those APIs).
- `gra-alert-get` uses `/alerts/v1/getAlert` (top-level `datasourcename`; analytical-feature map keys named `resourceName` become `datasourcename`). Alert list/fetch do not include those maps.
- Replaced GRA Alert Resource with **GRA Alert Data Source** (`graalertdatasource`).
- Incident anomaly grid column Resource Name is now **Data Source Name**.
- Deprecated Resource-named account commands (still available): ***gra-fetch-active-resource-accounts***, ***gra-fetch-resource-highrisk-accounts***, ***gra-fetch-resource-hpa***, ***gra-fetch-resource-orphan-accounts***.
- Added Data Source replacements: ***gra-fetch-active-datasource-accounts***, ***gra-fetch-datasource-highrisk-accounts***, ***gra-fetch-datasource-hpa***, ***gra-fetch-datasource-orphan-accounts***.
- Deprecated Case commands (runtime unchanged): ***gra-cases***, ***gra-case-action***, ***gra-case-action-anomaly***, ***gra-cases-anomaly***.
- Updated other command outputs to GRA's endpoint-specific Data Source keys (`datasourcename`, `datasource_name`, or `datasource`).
