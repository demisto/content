#### Integrations

##### Gurucul-GRA

- This pack requires **GRA 14.5.0** or later.
- Added the *Fetch type* parameter (*Incidents* | *Alerts*). New imports use GRA Incidents or Alerts; Cases are no longer fetched. Existing GRACase incidents remain actionable with the Case commands.
- Added the incident commands: ***gra-incidents***, ***gra-incident-action***, ***gra-incident-action-anomaly***, ***gra-incidents-anomaly***.
- Added the alert commands: ***gra-alerts***, ***gra-alert-get***, ***gra-alert-action***, ***gra-alert-update-history***, ***gra-alert-comment***, ***gra-alert-assign***, ***gra-alert-in-progress***.
- Updated Incident and Alert fetch to use an ID cursor after the first bootstrap. *First fetch time* is used only when no cursor exists yet. An existing *maxCaseId* last-run cursor is reused as *maxIncidentId* on upgrade.
- Added the *GRA server timezone* parameter (IANA id, default *UTC*) so Incident and Alert fetch **Occurred** matches GRA. Not used for *First fetch time*. War Room commands are unchanged.
- Set defaults for new instances: Mapper (incoming) *GRAIncident-Mapper* and Incident type *GRAIncident*. Use a separate instance for Alerts with *GRAAlert-Mapper* and *GRAAlert*.
- GRA nomenclature now uses **Data Source** instead of **Resource**. These commands now return Data Source instead of Resource: ***gra-fetch-accounts***, ***gra-fetch-user-accounts***, ***gra-fetch-hpa***, ***gra-fetch-orphan-accounts***, ***gra-user-activities***, ***gra-incidents***, ***gra-incidents-anomaly***, ***gra-alerts***, ***gra-alert-get***, ***gra-investigate-anomaly-summary***, ***gra-analytical-features-entity-value***.
- Deprecated Resource-named account commands still return Resource; prefer the new Data Source commands: ***gra-fetch-active-datasource-accounts***, ***gra-fetch-datasource-highrisk-accounts***, ***gra-fetch-datasource-hpa***, ***gra-fetch-datasource-orphan-accounts***. Deprecated Case commands still return Resource (runtime unchanged): ***gra-cases***, ***gra-case-action***, ***gra-case-action-anomaly***, ***gra-cases-anomaly***.
