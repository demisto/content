#### Integrations

##### Bitbucket

- Added support for scoped API token authentication, replacing the deprecated app password authentication.
- Added support for **OAuth 2.0 client credentials** authentication using a Bitbucket OAuth consumer key and secret.
- Updated the Docker image to: *demisto/python3:3.12.13.11753038*.
- **Breaking Change**: Bitbucket Cloud has deprecated app passwords in favor of Scoped API tokens.
- **Breaking Changes**: The following commands are deprecated and no longer work:
  - ***bitbucket-issue-create***
  - ***bitbucket-issue-list***
  - ***bitbucket-issue-update***
  - ***bitbucket-issue-comment-create***
  - ***bitbucket-issue-comment-list***
  - ***bitbucket-issue-comment-update***
  - ***bitbucket-issue-comment-delete***
