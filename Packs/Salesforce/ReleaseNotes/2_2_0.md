
#### Integrations

##### Salesforce

- Updated the *Credentials* parameter to be optional so that unified-connector (UCP) managed instances, which resolve the access token at runtime, are no longer rejected during pre-execution config validation with *missing xsoar integration config values: credentials*.
- Added the ***salesforce-file-delete*** command to soft-delete a file (ContentDocument) to the Recycle Bin, cascading to its versions.
- Added the ***salesforce-knowledge-article-archive*** command to archive a Knowledge article (non-destructive), setting *PublishStatus* to *Archived* via the standard *archiveKnowledgeArticles* action.
- Added the ***salesforce-knowledge-article-draft-create*** command to move a published Knowledge article to Draft using the standard *createDraftFromOnlineKnowledgeArticle* action. By default (*unpublish=true*) the online version is removed from public visibility and an editable draft is created.
- Added the ***salesforce-file-public-link-list*** command to list all *ContentDistribution* records (public links) for a *ContentDocument* ID.
- Added the ***salesforce-file-public-link-remove*** command to remove a file public link by deleting a single *ContentDistribution* record by ID (use with ***salesforce-file-public-link-list***).
