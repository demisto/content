
#### Integrations

##### Salesforce

- Made the **Credentials** parameter optional so that unified-connector (UCP) managed instances, which resolve the access token at runtime, are no longer rejected during pre-execution config validation with *missing xsoar integration config values: credentials*.
- Added the ***salesforce-delete-file*** command to soft-delete a file (ContentDocument) to the Recycle Bin, cascading to its versions.
- Added the ***salesforce-archive-knowledge-article*** command to archive a Knowledge article (non-destructive), setting *PublishStatus* to *Archived* via the standard *archiveKnowledgeArticles* action.
- Added the ***salesforce-draft-knowledge-article*** command to move a published Knowledge article to Draft using the standard *createDraftFromOnlineKnowledgeArticle* action. By default (*unpublish=true*) the online version is removed from public visibility and an editable draft is created.
- Added the ***salesforce-list-file-public-links*** command to list all *ContentDistribution* records (public links) for a *ContentDocument* ID.
- Added the ***salesforce-remove-file-public-links*** command to remove a file public link by deleting a single *ContentDistribution* record by ID (use with *salesforce-list-file-public-links*).
