
#### Integrations

##### Elasticsearch v2

- Added the *Kibana Server URL* parameter, which sets the Kibana server used by all commands with the ***es-kibana*** prefix and by fetching and mirroring security alerts and cases. Set it for on-premises (self-managed) deployments, where Kibana is hosted separately from Elasticsearch. When left empty, the Kibana URL is derived from the *Server URL*, as before.
