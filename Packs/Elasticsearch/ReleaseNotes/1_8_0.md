
#### Integrations

##### Elasticsearch v2

- Added the ***es-kibana-endpoint-isolate*** command to isolate endpoints through Kibana and return the endpoint action details.
- Added the ***es-kibana-endpoint-unisolate*** command to release an isolated endpoint through Kibana and return the endpoint action details.
- Added the ***es-kibana-endpoint-execute-command*** command to run shell commands on Elastic endpoints through Kibana.
- Added the ***es-kibana-endpoint-action-details*** command to retrieve endpoint response-action details through Kibana.
- Added the ***es-kibana-endpoint-metadata-get*** command to retrieve host metadata for an endpoint through Kibana.
- Added the ***es-kibana-endpoint-agent-get*** command to retrieve an Elastic Fleet agent through Kibana.
