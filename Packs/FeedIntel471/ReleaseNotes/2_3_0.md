
#### Integrations

##### Intel471 Credentials

- Added support for **Password numbers count (>=)** parameter that minimum number of numeric characters in the password to filter results by. must be greater than or equal to 0.
- Added support for **Password punctuation count (>=)** parameter that minimum number of punctuation characters in the password to filter results by. must be greater than or equal to 0.
- Added support for **Password lowercase count (>=)** parameter that minimum number of lowercase characters in the password to filter results by. must be greater than or equal to 0.
- Added support for **Password uppercase count (>=)** parameter that minimum number of uppercase characters in the password to filter results by. must be greater than or equal to 0.
- Added support for **Password length (>=)** parameter that minimum total password length to filter results by. must be greater than or equal to 0.
- Added support for **Password separators count (>=)** parameter that minimum number of separator characters in the password to filter results by. must be greater than or equal to 0.
- Added support for **Password symbols count (>=)** parameter that minimum number of symbol characters in the password to filter results by. must be greater than or equal to 0.
- Added support for **Credential login** parameter that search results by credential login.
