
#### Incident Types

##### New: Intel 471 Leaked Credential

Added a new incident type for leaked credentials reported by Intel471. Incidents of this type run the **Intel 471 Leaked Credential** playbook automatically on creation.

#### Layouts

##### New: Intel 471 Leaked Credential

Added a new layout for the **Intel 471 Leaked Credential** incident type.

#### Playbooks

##### New: Intel 471 Leaked Credential

Added a new playbook that runs automatically as the default playbook for the **Intel 471 Leaked Credential** incident type. It extracts and enriches the indicators attached to the incident, calculates the incident severity, assigns an analyst, and holds the incident for manual review before closing it.

#### Integrations

##### Intel471 Credentials

Reworked the integration from a feed into a fetch-incidents integration. Each leaked credential now becomes an incident of type **Intel 471 Leaked Credential**, and the observables it carries — the login, the detection and credential domains, and the infected host's IP addresses and PC name — are extracted as indicators and associated with the incident that produced them.
This is a breaking change: existing instances must be reconfigured. See the integration README for details.

##### Intel471 Watcher Alerts

- Added support for marketplace watcher alerts. Alerts about a marketplace website, a product listing, a compromised resource, or a vendor now create incidents with details specific to each of them, instead of falling back to the unknown alert type.
- Added support for data leak site watcher alerts. Alerts about a data leak site post or a leaked file listing now create incidents with details specific to each of them, including the attachments listed on the post.
- Incidents created from the new marketplace and data leak file listing alerts link back to the Verity471 portal using the link carried by the alert.
- Added details to incidents created from malware event alerts: the malware component and variant, the threat type, the bulletproof hosting provider, the first and last seen timestamps, and the GIR classification.
- Added the recipient to incidents created from forum private message alerts.
- Fixed an issue where fetching failed when an alert referenced a watcher group or a watcher that was not returned together with it.
- Fixed an issue where the alert ID was not resolved for alerts that carry it nested under the message, post, or private message object.
- Fixed an issue where incidents created from unrecognized alerts had empty details when the alert payload was not HTML.
