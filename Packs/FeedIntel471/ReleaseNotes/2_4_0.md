
#### Incident Types

##### New: Intel471 Leaked Credential

Added a new incident type for leaked credentials reported by Intel471.

#### Layouts

##### New: Intel 471 Leaked Credential

Added a new layout for the **Intel471 Leaked Credential** incident type.

#### Playbooks

##### New: Intel471 Leaked Credential

Added a new playbook that runs as the default playbook for the **Intel471 Leaked Credential** incident type. It extracts and enriches the indicators attached to the incident, calculates the incident severity, assigns an analyst, and holds the incident for manual review before closing it.

#### Integrations

##### Intel471 Credentials

Reworked the integration from a feed into a fetch-incidents integration. Each leaked credential now becomes an incident of type **Intel471 Leaked Credential**, and the observables it carries — the login, the detection and credential domains, and the infected host's IP addresses and PC name — are extracted as indicators and associated with the incident that produced them.
This is a breaking change: existing instances must be reconfigured. See the integration README for details.
