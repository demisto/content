# OpenAI (Standard Connector)

Satellite pack used by the OpenAI standard connector. It shares its logic with the OpenAI pack through the OpenAiChatGPTApiModule. Do not install it standalone.

The connector offers two services, each with its own credentials:

- **OpenAI API Platform**: Automation and Remediation (GPT commands, OpenAI API Key) and Log Collection (OpenAI Audit logs, Admin API Key).
- **ChatGPT Workspace**: Log Collection (ChatGPT Compliance logs, Compliance API Key and Workspace ID).
