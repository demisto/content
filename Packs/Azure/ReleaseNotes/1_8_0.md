
#### Integrations

##### Azure

- Added the ***azure-firewall-list*** command, which lists the Azure firewalls in the specified resource group or subscription (migrated from the **Azure Firewall** pack).
- Added the ***azure-firewall-get*** command, which gets the properties of an Azure firewall, and displays its rule collections when a rule type is specified (migrated from the **Azure Firewall** pack).
- Added the ***azure-vn-firewall-policy-rule-collection-groups-list*** command, which lists the rule collection groups of an Azure firewall policy (migrated from the **Azure Firewall** pack).
- Added the ***azure-firewall-rules-list*** command, which lists the rules of an Azure firewall rule collection or a firewall policy rule collection group (migrated from the **Azure Firewall** pack).
- Added the ***azure-firewall-rule-get*** command, which gets the properties of a specified Azure firewall or firewall policy rule (migrated from the **Azure Firewall** pack).
- Added the ***azure-firewall-service-tags-information-list*** command, which lists the service tag information resources of a specified location (migrated from the **Azure Firewall** pack).
