
#### Integrations

##### Azure

- Added the ***azure-storage-container-list*** command to list containers under the specified storage account. Migrated from the **Azure Storage Container** integration.
- Added the ***azure-storage-blob-list*** command to list blobs under the specified container. Migrated from the **Azure Storage Container** integration.
- Added the ***azure-storage-blob-update*** command to update the content of an existing blob. Migrated from the **Azure Storage Container** integration.
- Added the ***azure-storage-blob-delete*** command to mark a specific blob for deletion. Migrated from the **Azure Storage Container** integration.
- Added the ***azure-storage-container-sas-create*** command to create a SAS token for a container. Migrated from the **Azure Storage Container** integration.
