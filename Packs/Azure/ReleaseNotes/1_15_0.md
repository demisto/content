
#### Integrations

##### Azure

- Added the ***azure-rg-list-operations*** command, which lists the available Azure Resource Graph operations and their descriptions. Migrated from the **Azure Resource Graph** integration.
- Added the ***azure-rg-query*** command, which executes an Azure Resource Graph query based on Kusto Query Language (KQL) and returns the matching resources. Migrated from the **Azure Resource Graph** integration.
