
#### Integrations

##### Azure

- Added the ***azure-compute-vm-create*** command, which creates a virtual machine instance with the specified OS image (migrated from the **AzureCompute v2** pack).
- Added the ***azure-compute-vm-delete*** command, which deallocates and deletes a specified virtual machine (migrated from the **AzureCompute v2** pack).
- Added the ***azure-vn-network-interface-create*** command, which creates a virtual machine network interface (migrated from the **AzureCompute v2** pack).
