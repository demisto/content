#### Integrations

##### Azure

- Added the ***azure-postgres-flexible-server-configuration-update*** command to update a configuration of an Azure PostgreSQL Flexible Server.
- Added the following quick actions:
  - **Set Disconnection Logging on PostgreSQL Flexible Server**
  - **Set PostgreSQL Flexible Server Checkpoint Logging**
  - **Set Connection Throttling on PostgreSQL Flexible Server**
  - **Set Session Connection Logging on PostgreSQL Flexible Server**
  - **Set PostgreSQL Flexible Server Log Retention**
  - **Set PostgreSQL Flexible Server Statement Logging**
  - **Set Secure Transport on PostgreSQL Flexible Server**
