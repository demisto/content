
#### Integrations

##### Azure

- Added the ***azure-firewall-policy-create*** command to create a firewall policy (migrated from the Azure Firewall pack).
- Added the ***azure-firewall-policy-update*** command to update the threat intelligence, DNS, and base policy settings of an existing firewall policy (migrated from the Azure Firewall pack).
- Added the ***azure-firewall-policy-get*** command to retrieve a firewall policy (migrated from the Azure Firewall pack).
- Added the ***azure-firewall-policy-delete*** command to delete a firewall policy (migrated from the Azure Firewall pack).
- Added the ***azure-firewall-policy-list*** command to list the firewall policies in a resource group (migrated from the Azure Firewall pack).
- Added the ***azure-firewall-policy-attach*** command to attach a firewall policy to a firewall (migrated from the Azure Firewall pack).
- Added the ***azure-firewall-policy-detach*** command to detach the firewall policy from a firewall (migrated from the Azure Firewall pack).
