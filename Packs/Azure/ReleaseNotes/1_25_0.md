#### Integrations

##### Azure
Added the following new commands:
- ***azure-storage-fileshare-create*** that creates a new Azure file share under the specified storage account.
- ***azure-storage-fileshare-delete*** that deletes a file share under the specified storage account.
- ***azure-storage-fileshare-list*** that lists Azure file shares under the specified storage account.
- ***azure-storage-fileshare-content-list*** that lists files and directories under the specified share or directory.
- ***azure-storage-fileshare-directory-create*** that creates a new directory under the specified share or parent directory.
- ***azure-storage-fileshare-directory-delete*** that deletes the specified empty directory.
- ***azure-storage-fileshare-file-create*** that creates a new file in a share from a War Room file entry ID.
- ***azure-storage-fileshare-file-get*** that retrieves a file from a share and returns it to the War Room.
- ***azure-storage-fileshare-file-delete*** that deletes a file from a share.
