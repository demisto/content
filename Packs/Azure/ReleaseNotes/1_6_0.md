
#### Integrations

##### Azure

- Added the ***azure-storage-table-create*** command to create a new table in a storage account (migrated from the **Azure Storage Table** integration).
- Added the ***azure-storage-table-delete*** command to delete a table and all of its data (migrated from the **Azure Storage Table** integration).
- Added the ***azure-storage-table-list*** command to list the tables in a storage account (migrated from the **Azure Storage Table** integration).
- Added the ***azure-storage-table-entity-insert*** command to insert a new entity into a table (migrated from the **Azure Storage Table** integration).
- Added the ***azure-storage-table-entity-update*** command to update an existing entity in a table by merging the provided properties (migrated from the **Azure Storage Table** integration).
- Added the ***azure-storage-table-entity-replace*** command to replace an existing entity in a table (migrated from the **Azure Storage Table** integration).
- Added the ***azure-storage-table-entity-query*** command to query entities in a table (migrated from the **Azure Storage Table** integration).
- Added the ***azure-storage-table-entity-delete*** command to delete an existing entity from a table (migrated from the **Azure Storage Table** integration).
