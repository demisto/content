#### Integrations

##### Azure

- Added the ***azure-dns-zones-list*** command to list the DNS zones in all resource groups in a subscription.
- Added the ***azure-dns-cname-record-set-get*** command to retrieve a DNS record set of type CNAME.
- Added the ***azure-dns-cname-record-set-delete*** command to delete a DNS record set of type CNAME from a DNS zone.
