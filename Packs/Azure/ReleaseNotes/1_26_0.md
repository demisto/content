#### Integrations

##### Azure

- Added support for connectors restricted to the CSPM remediation permission set. Attempting to run commands outside of this permission scope will now return a clear error message.
- Updated the health check results to report the account capability (`AUTOMATION` or `CSPM_remediation`), depending on the permission set granted to the account.
- Added a dedicated health check for accounts restricted to the CSPM remediation permission set, which checks only the CSPM remediation permissions and reports each missing permission as a warning.
- Updated the health check to report authorization failures as missing permission warnings, including the name of the missing permission.
- Removed the unused read permission from the required permissions of commands that only update resources, such as the storage account, web app, Cosmos DB, MySQL flexible server, SQL transparent data encryption, policy assignment, and security rule create commands.
