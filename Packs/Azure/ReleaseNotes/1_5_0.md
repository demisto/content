#### Integrations

##### Azure

- Added support for the ***azure-firewall-list*** command that lists the Azure firewalls in the specified resource group or subscription (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-get*** command that gets the properties of a given Azure firewall, and optionally displays its rule collections of a given type (migrated from the Azure Firewall pack).
- Added support for the ***azure-vn-firewall-policy-rule-collection-groups-list*** command that lists the rule collection groups of an Azure firewall policy (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-rules-list*** command that lists the rules of an Azure firewall rule collection or of a firewall policy rule collection group (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-rule-get*** command that gets the properties of a given Azure firewall or firewall policy rule (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-service-tags-information-list*** command that lists the service tag information resources of a given location (migrated from the Azure Firewall pack).
