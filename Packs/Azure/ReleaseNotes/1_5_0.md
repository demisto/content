#### Integrations

##### Azure

- Added the ***azure-compute-vm-create*** command to create a virtual machine instance with the specified OS image (migrated from the AzureCompute v2 pack).
- Added the ***azure-compute-vm-delete*** command to deallocate and delete a virtual machine (migrated from the AzureCompute v2 pack).
- Added the ***azure-vn-network-interface-create*** command to create a virtual machine network interface (migrated from the AzureCompute v2 pack).
