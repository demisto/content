
#### Integrations

##### Azure

- Added the ***azure-vn-ip-group-create*** command to create an IP group resource (migrated from the AzureFirewall pack).
- Added the ***azure-vn-ip-group-update*** command to add or remove IP addresses in an existing IP group (migrated from the AzureFirewall pack).
- Added the ***azure-vn-ip-group-get*** command to retrieve an IP group resource (migrated from the AzureFirewall pack).
- Added the ***azure-vn-ip-group-list*** command to list the IP groups in a resource group or in the subscription (migrated from the AzureFirewall pack).
- Added the ***azure-vn-ip-group-delete*** command to delete an IP group resource (migrated from the AzureFirewall pack).
