#### Integrations

##### Azure

- Added the ***azure-nsg-virtual-networks-list*** command to list the virtual networks in a resource group (migrated from the AzureNetworkSecurityGroups pack).
- Added the ***azure-nsg-network-interface-create*** command to create a network interface in a resource group (migrated from the AzureNetworkSecurityGroups pack).
- Added the ***azure-nsg-subscriptions-list*** command to list all subscriptions for a tenant (migrated from the AzureNetworkSecurityGroups pack).
