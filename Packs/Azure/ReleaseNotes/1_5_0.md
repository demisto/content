#### Integrations

##### Azure

- Added the ***azure-application-gateway-waf-policy-get*** command, which retrieves an Application Gateway WAF policy by name (migrated from the Azure WAF pack).
- Added the ***azure-application-gateway-waf-policies-list*** command, which lists the Application Gateway WAF policies of a resource group, or of the whole subscription when no resource group is given (migrated from the Azure WAF pack).
- Added the ***azure-application-gateway-waf-policy-create-or-update*** command, which creates or updates an Application Gateway WAF policy (migrated from the Azure WAF pack).
- Added the ***azure-application-gateway-waf-policy-delete*** command, which deletes an Application Gateway WAF policy (migrated from the Azure WAF pack).
- Added the ***azure-front-door-policy-get*** command, which retrieves a Front Door WAF policy by name (migrated from the Azure WAF pack).
- Added the ***azure-front-door-policies-list*** command, which lists the Front Door WAF policies of a resource group, or of the whole subscription when no resource group is given (migrated from the Azure WAF pack).
- Added the ***azure-front-door-policy-create-or-update*** command, which creates or updates a Front Door WAF policy (migrated from the Azure WAF pack).
- Added the ***azure-front-door-policy-delete*** command, which deletes a Front Door WAF policy (migrated from the Azure WAF pack).
