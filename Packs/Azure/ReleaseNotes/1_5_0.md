#### Integrations

##### Azure

- Added support for the ***azure-firewall-instance-list*** command that lists the Azure firewalls in the specified resource group or subscription (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-instance-get*** command that gets the properties of a given Azure firewall (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-rule-collection-list*** command that lists the rule collections of an Azure firewall or of a firewall policy (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-rule-list*** command that lists the rules of an Azure firewall rule collection or of a firewall policy rule collection group (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-rule-get*** command that gets the properties of a given Azure firewall or firewall policy rule (migrated from the Azure Firewall pack).
- Added support for the ***azure-firewall-service-tag-list*** command that lists the service tag information resources of a given location (migrated from the Azure Firewall pack).
