#### Integrations

##### Azure
Added 8 commands for managing Azure Web Application Firewall (WAF) policies, migrated from the Azure WAF pack.
- Added the ***azure-waf-policy-get*** command, which retrieves an Application Gateway WAF policy by name.
- Added the ***azure-waf-policy-list*** command, which lists the Application Gateway WAF policies of a resource group, or of the whole subscription when no resource group is given.
- Added the ***azure-waf-policy-update*** command, which creates or updates an Application Gateway WAF policy.
- Added the ***azure-waf-policy-delete*** command, which deletes an Application Gateway WAF policy.
- Added the ***azure-waf-front-door-policy-get*** command, which retrieves a Front Door WAF policy by name.
- Added the ***azure-waf-front-door-policy-list*** command, which lists the Front Door WAF policies of a resource group, or of the whole subscription when no resource group is given.
- Added the ***azure-waf-front-door-policy-update*** command, which creates or updates a Front Door WAF policy.
- Added the ***azure-waf-front-door-policy-delete*** command, which deletes a Front Door WAF policy.
