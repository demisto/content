#### Integrations

##### Azure

Added the following commands, migrated from the Azure Firewall pack:

- ***azure-firewall-rule-collection-groups-create*** - Creates a network rule collection, holding a single network rule, in an Azure Firewall.
- ***azure-firewall-rule-collection-groups-update*** - Updates the priority or the action of a network rule collection in an Azure Firewall.
- ***azure-firewall-rule-collection-groups-delete*** - Deletes a network rule collection from an Azure Firewall.
- ***azure-firewall-network-rule-create*** - Creates a network rule in an existing network rule collection of an Azure Firewall.
- ***azure-firewall-network-rule-update*** - Updates a network rule in a network rule collection of an Azure Firewall.
- ***azure-firewall-network-rule-delete*** - Deletes network rules from a network rule collection of an Azure Firewall.
- ***azure-vn-firewall-policy-rule-collection-groups-create*** - Creates a rule collection group, holding a network rule collection with a single network rule, in a firewall policy.
- ***azure-vn-firewall-policy-rule-collection-groups-update*** - Updates the priority or the action of a network rule collection in a firewall policy rule collection group.
- ***azure-vn-firewall-policy-rule-collection-groups-delete*** - Deletes a rule collection group from a firewall policy.
- ***azure-vn-firewall-policy-network-rule-create*** - Creates a network rule in an existing network rule collection of a firewall policy rule collection group.
- ***azure-vn-firewall-policy-network-rule-update*** - Updates a network rule in a network rule collection of a firewall policy rule collection group.
- ***azure-vn-firewall-policy-network-rule-delete*** - Deletes network rules from a network rule collection of a firewall policy rule collection group.

All of the above commands use the Cortex built-in polling mechanism to wait for the Azure Firewall or the firewall policy rule collection group to finish provisioning, and support the *interval_in_seconds* and *polling_timeout* arguments.
