## SoChain

The API key is optional: every command works without one, limited to 2,500 lookups a day per IP. A key raises the limit (75,000 requests a month on the free plan).

### Get an API key

1. Go to the [SoChain sign-in page](https://sochain.com/signin), enter your address in **Email** and click **Email me a code**.
2. Enter the 8-digit code from the email and click **Sign in**, or click the sign-in link in the email.
3. On the plan page, click **Start free** (or **Subscribe** on a paid plan).
4. On the **Here’s your API key** page, click **Copy**. The key is shown only once; to make another, click **Create key** under **API keys** on the [SoChain dashboard](https://sochain.com/dashboard).
5. In the instance settings, paste the key into **API Key**.
