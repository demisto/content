
#### Integrations

##### Kron PAM

- Renamed the integration **Single Connect** to **Kron PAM** to match the current product name. Shared Account Password Management (SAPM) is now called Password Vault throughout the integration.
- Updated the integration logo and author image to the Kron PAM logo.
- Added support for listing all Password Vault accounts (***kron-pam-vault-account-list-all***).
- Added support for showing the password of a Password Vault account (***kron-pam-vault-account-show-password***). The account is selected with the *vault_db_id* argument.
- Added support for listing the Password Vault accounts on a specific device (***kron-pam-device-list-vault-accounts***).
- Added support for searching Password Vault accounts by secret name (***kron-pam-vault-account-search-with-secret-name***).
- Updated the context output path to *KronPAM.VaultAccount*. Results are no longer written to *SingleConnect.SapmAccount*.
- Deprecated the ***single-connect-sapm-account-list-all*** command. Use ***kron-pam-vault-account-list-all*** instead.
- Deprecated the ***single-connect-sapm-account-show-password*** command. Use ***kron-pam-vault-account-show-password*** instead.
- Deprecated the ***single-connect-device-list-sapm-accounts*** command. Use ***kron-pam-device-list-vault-accounts*** instead.
- Deprecated the ***single-connect-sapm-account-search-with-secret-name*** command. Use ***kron-pam-vault-account-search-with-secret-name*** instead.
- Updated the deprecated Single Connect commands to return an error instead of running. Playbooks that use them must be updated to use the Kron PAM commands.
