
#### Modeling Rules

##### NVIDIA DOCA Argus Modeling Rule

Updated the NVIDIA DOCA Argus modeling rule to align with DOCA Argus 3.5.2.
Added modeling support for the GPU event types (gpu_identity, gpu_metrics, gpu_topology), the kernel module event types (kernel_module_loaded, kernel_module_changed, kernel_module_unloaded) and the additional system activity event types (load_mem_regions_failed, load_mem_regions_successful, invalid_SBOM_configuration_file, invalid_SBOM_configuration_folder).
Mapped the GPU identity attributes (gpu_uuid, gpu_display_name, gpu_product_brand) and the kernel module attributes (kernel_module_name, kernel_module_size) to their XDM fields.
Mapped the container context fields (container_id, container_image_name, container_image_digest, pod_name, pod_ip_address) to their XDM fields.
Aligned the renamed network connection fields (local_address, local_port, peer_address, peer_port) and the renamed process executable path field.
Normalized the event operation mapping to be case-insensitive.
