#### Modeling Rules

##### NVIDIA DOCA Argus Modeling Rule

Updated the modeling rule to align with NVIDIA DOCA Argus 3.5.2.
- Added support for the new event types: **gpu_identity**, **gpu_metrics**, **gpu_topology**, **kernel_module_loaded**, **kernel_module_changed**, **kernel_module_unloaded**, **load_mem_regions_failed**, **load_mem_regions_successful**, **invalid_SBOM_configuration_file** and **invalid_SBOM_configuration_folder**.
- Mapped GPU identity attributes (**gpu_uuid**, **gpu_display_name**, **gpu_product_brand**) and kernel-module attributes (**kernel_module_name**, **kernel_module_size**).
- Mapped container context fields (**container_id**, **container_image_name/digest**, **pod_name**, **pod_ip_address**) to their XDM fields.
- Aligned the renamed network connection fields (**local_address/port**, **peer_address/port**) and the renamed process field (**process_executable_path**).
- Normalized the event operation mapping to be case-insensitive.
