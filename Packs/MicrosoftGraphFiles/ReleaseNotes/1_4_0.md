
#### Integrations

##### O365 File Management (Onedrive/Sharepoint/Teams)

Added the following commands:

- ***msgraph-driveitem-metadata-get*** - Retrieves the metadata of a file or folder, addressed by ID, by path, or by a sharing URL. Returns the ID of the drive that stores the item, which is the scope the returned item ID belongs to.
- ***msgraph-driveitem-activities-list*** - Retrieves the recent activities that took place on a file or folder.
- ***msgraph-driveitem-analytics-get*** - Retrieves activity statistics for a file or folder.
