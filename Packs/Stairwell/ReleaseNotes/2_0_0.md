
#### Integrations

##### New: Stairwell

New: Stairwell helps security teams speed up security workflows by continuously tying signal intelligence with their enterprise's files, performing private file and malware analysis, and bringing data search techniques to finding threats that others miss.
- Added the ***file***, ***ip*** and ***domain*** reputation commands, which return standard File, IP and Domain indicators with a DBotScore. The file score comes from Stairwell's MalEval verdict; IP and domain results carry network intelligence and a domain on Stairwell's whitelist scores good.
- Added the *Source Reliability* integration parameter.
- Added the ***stairwell-file-enrichment*** and ***stairwell-variant-discovery*** commands, replacing the ***inception-file-enrichment*** and ***inception-variant-discovery*** commands. Context paths moved from ***Inception.\**** to ***Stairwell.\****.
- Added the ***stairwell-intake-upload*** command to upload files for analysis from War Room entries or HTTP/HTTPS URLs, with automatic SHA256 calculation and preflight checks.
- Added the ***stairwell-ai-triage-summarize*** command for AI-generated threat summaries with malicious likelihood scoring and IOC extraction.
- Added the ***stairwell-object-sightings***, ***stairwell-object-opinions***, and ***stairwell-run-to-ground-generate*** commands.
- Added network intelligence commands: ***stairwell-asn-get-whois***, ***stairwell-hostname-get***, ***stairwell-hostname-get-resolutions***, ***stairwell-hostname-batch-get-resolutions***, ***stairwell-ipaddress-get***, ***stairwell-ipaddress-lookup-cloud-provider***, ***stairwell-ipaddress-get-hostnames-resolving-to-ip***, ***stairwell-ipaddress-get-whois***, and the ***stairwell-utilities-\**** canonicalization and cloud IP range commands.
- Added YARA rule commands: ***stairwell-yara-create-rule***, ***stairwell-yara-get-rule***, ***stairwell-yara-query-matches***.
- Added asset commands: ***stairwell-asset-list***, ***stairwell-asset-create***, ***stairwell-asset-get***.
- Added retry with exponential backoff for transient API failures and actionable error messages for HTTP 400, 403, 404, 409, and 5xx responses.
