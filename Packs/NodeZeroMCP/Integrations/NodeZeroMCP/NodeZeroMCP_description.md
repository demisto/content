## NodeZero MCP

To obtain the Authorization Code, follow these steps:

1. Select the **MCP Server URL** that matches your NodeZero region:
   - **US**: `https://mcp.horizon3ai.com/mcp`
   - **EU**: `https://mcp.horizon3ai.eu/mcp`
   - **AU**: `https://mcp.horizon3ai.au/mcp`
2. Save the integration instance.
3. Run the **nodezero-mcp-generate-login-url** integration command from the Playground and follow its instructions to sign in through the NodeZero portal.
4. Copy the generated Authorization Code into the integration instance and save the integration instance.
5. Run the **nodezero-mcp-auth-test** integration command from the Playground to verify that everything is configured correctly.
