
#### Integrations

##### Amazon Web Services

- Added the *mx-central-1* region to all AWS Network Firewall commands.
- Added the ***aws-network-firewall-resource-policy-delete*** command that deletes a resource policy.
- Added the ***aws-network-firewall-resource-policy-put*** command that creates or updates an AWS Identity and Access Management policy for a rule group or firewall policy.
- Added the ***aws-network-firewall-resource-policy-describe*** command that retrieves a resource policy.
- Added the ***aws-network-firewall-tags-for-resource-list*** command that retrieves the tags associated with the specified resource.
- Added the ***aws-network-firewall-resource-tag*** command that adds the specified tags to the specified resource.
- Added the ***aws-network-firewall-resource-untag*** command that removes the tags with the specified keys from the specified resource.
- Added the ***aws-network-firewall-logging-configuration-describe*** command that returns the logging configuration for the specified firewall.
- Added the ***aws-network-firewall-logging-configuration-update*** command that sets the logging configuration for the specified firewall.
