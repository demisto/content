#### Integrations

##### Amazon Web Services

- Added support for connectors restricted to the CSPM remediation permission set. Attempting to run commands outside of this permission scope will now return a clear error message.
- Updated the health check results to report the account capability (`AUTOMATION` or `CSPM_remediation`), depending on the permission set granted to the account.
- Added a dedicated health check for accounts restricted to the CSPM remediation permission set, which validates the account credentials without checking the permissions required by the automation commands.
