
#### Integrations

##### Amazon Web Services

- Added support for the ***aws-route53-hosted-zones-list*** command, which retrieves the public and private hosted zones that are associated with the AWS account (migrated from the AWS - Route53 pack). Required permissions: route53:ListHostedZones.
- Added support for the ***aws-route53-hosted-zones-by-name-list*** command, which retrieves the hosted zones that are associated with the AWS account, sorted by domain name. Required permissions: route53:ListHostedZonesByName.
- Added support for the ***aws-route53-resource-record-sets-list*** command, which lists the resource record sets in a specified hosted zone (migrated from the AWS - Route53 pack). Required permissions: route53:ListResourceRecordSets.
- Added support for the ***aws-route53-resource-record-sets-change*** command, which creates, updates (UPSERT), or deletes a single resource record set in a hosted zone, for example, to delete dangling DNS records, including weighted records (*set_identifier* and *weight*) (migrated from the create, upsert, and delete record commands of the AWS - Route53 pack). Required permissions: route53:ChangeResourceRecordSets.
