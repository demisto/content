#### Integrations

##### Amazon Web Services
- Added the ***aws-s3-bucket-objects-list-v2*** command, which lists objects in an S3 bucket using the `ListObjectsV2` API. Unlike ***aws-s3-bucket-objects-list***, it consistently returns a pagination token (`ObjectsNextToken`) for truncated results even when no delimiter is used, resolving cases where objects were missing when listing large buckets. It also supports the `start_after` argument. No additional IAM permissions are required (`s3:ListBucket`).
