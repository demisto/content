#### Integrations

##### Amazon Web Services

- Added support for the ***aws-network-firewall-subnet-change-protection-update*** command, which modifies the *SubnetChangeProtection* flag to indicate whether subnets associated with the firewall can be changed. Required permissions: network-firewall:UpdateSubnetChangeProtection.
- Added support for the ***aws-network-firewall-subnets-disassociate*** command, which disassociates specified subnets from the firewall. This removes firewall endpoints from the subnets, revoking any network filtering protections they provided. Required permissions: network-firewall:DisassociateSubnets.
- Added support for the ***aws-network-firewall-subnets-associate*** command, which associates the specified subnets in the Amazon VPC to the firewall. You can specify one subnet for each of the Availability Zones that the VPC spans. This is used to provide the firewall endpoints for the subnets. Required permissions: network-firewall:AssociateSubnets.
