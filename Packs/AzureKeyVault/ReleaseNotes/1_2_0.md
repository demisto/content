
#### Integrations

##### Azure Key Vault

- Added a new *Credentials Fetch Mode* parameter with support for an *External Credentials Vault (on-demand)* mode. In this mode, the credentials picker lists the configured secrets by name (`KEY_VAULT_NAME/SECRET_NAME`) without storing secret values in Cortex, and the secret value is fetched live from Azure Key Vault only when a credential is requested at runtime.
