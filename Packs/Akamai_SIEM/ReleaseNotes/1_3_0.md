
#### Integrations

##### Akamai WAF SIEM

- Updated the fetch-limit configuration by separating incident and event collection: the **Fetch limit** parameter was renamed to **Incident fetch limit** (controls incident fetching, maximum 2000), and a new **Events fetch limit** parameter (default *60000*, maximum *80000*) controls event collection.
- Removed the **Akamai Page size** parameter. The page size is now managed internally by the integration and is no longer configurable.
- Improved the event-collection flow for maintainability and stability.
