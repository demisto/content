
#### Integrations

##### Akamai WAF SIEM

- Added a dedicated *Events fetch limit* configuration (default 60,000) that controls the maximum number of events collected per fetch, independently of the *Incident fetch limit*.
- Maintenance and stability improvements.

#### Breaking changes

##### Akamai WAF SIEM

- The *Akamai Page size* (`page_size`) parameter was removed. The page size is now managed internally by the integration and is no longer configurable.
