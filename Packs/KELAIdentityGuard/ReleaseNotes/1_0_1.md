#### Integrations

##### KELA Identity Guard

- Fixed the **kela-identityguard-search-cookie-incidents** command and the
  cookie-incidents source of fetch-incidents, which failed with a
  ``400 Bad Request`` from the API when filtering by ``severity`` or
  ``status``. The API requires these two filters in upper case
  (``CRITICAL``/``NON_CRITICAL``, ``RESOLVED``/``UNRESOLVED``) for this
  endpoint specifically, unlike the other two sources.
