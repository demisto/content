## KELA Identity Guard

Search and manage KELA Identity Guard incidents directly from Cortex XSOAR, and automatically fetch
new incidents into the platform.

* Generate an API key for your Identity Guard account from the KELA platform.
* If you monitor a single workspace, fill in the **Default Workspace ID** so you don't need to pass
  `workspace_id` on every command. MSSP users can still target other tenant workspaces per-command.
