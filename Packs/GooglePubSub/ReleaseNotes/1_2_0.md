
#### Integrations

##### Google Cloud Pub/Sub

- Added support for Workload Identity Federation authentication via the new *Workload Identity Federation configuration (JSON)* parameter.
- Added support for Service Account Impersonation via the new *Service Account to impersonate* parameter.
- Updated the *Service account private key file contents (JSON)* parameter to *Service account private key (JSON)*.
- Improved implementation of the authentication layer by migrating from the deprecated *oauth2client* library to *google-auth*. Existing Service Account key instances keep working unchanged.
- Updated the Docker image to: *demisto/googleapi-python3:1.0.0.13053055*.
