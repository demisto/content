#### Integrations

##### Cyber Triage

- **Breaking changes:** Updated the integration to use the Cyber Triage 4.0 public REST API. Cyber Triage 4.0 or later is now required.
- **Breaking changes:** Replaced the *API Key* parameter (`api_key`) with a required *API Authentication Token* parameter (`api_auth_token`). Existing instances must be reconfigured with a token from the Cyber Triage server.
- **Breaking changes:** Renamed the *Use proxy* parameter (`use_proxy`) to *Use system proxy settings* (`proxy`).
- **Breaking changes:** Renamed the following arguments of the ***ct-triage-endpoint*** command:
  - *endpoint* to *host_name*
  - *malware_hash_upload* to *malware_scan_requested*
  - *malware_file_upload* to *send_content*
- Added the *Trust any certificate* parameter, which defaults to false.
- The *malware_scan_requested* and *send_content* arguments no longer have default values. If not set, the Cyber Triage server's default applies.
- Updated the default *scan_options* to match the Cyber Triage 4.0 data types.
