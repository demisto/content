
#### Integrations

##### FortiSIEM v2

- Added the ***fortisiem-event-list-by-incident-query*** command to query events by incident ID using a polling mechanism. Available for FortiSIEM version 7.3.3 and later.
- Added the ***fortisiem-event-list-by-incident-query-start*** command to initiate the request to get triggering events by query. Available for FortiSIEM version 7.3.3 and later.
- Added the ***fortisiem-event-list-by-incident-query-progress*** command to retrieve the progress of the triggering events query. Available for FortiSIEM version 7.3.3 and later.
- Added the ***fortisiem-event-list-by-incident-query-result*** command to retrieve the response data for the triggering events query. Available for FortiSIEM version 7.3.3 and later.
- Updated the ***fortisiem-event-list-by-incident*** command description to indicate it is available for FortiSIEM version 7.3.2 and earlier, and to point to the new ***fortisiem-event-list-by-incident-query*** command for versions 7.3.3 and later.
- Added the **Legacy fetch mode** parameter. When enabled (default), the *Fetch With Events* mode uses the current *triggeringEvents* endpoint (FortiSIEM version 7.3.2 and earlier). When disabled, it uses the new query *triggeringEvents* endpoint (FortiSIEM version 7.3.3 and later).
- Updated the **Fetch Mode** parameter description.
