#### Integrations

##### Check Point EM Alerts

- Added the *login_url*, *related_asset_name* and *related_asset_id* keys to fetched incidents. *login_url* holds *alert_data.designated_url* when the alert has it, otherwise the name of the related *employee login interface* asset, or of the first related asset that is not a keyword or company. Keyword and company assets are not used as a login URL.
- Added the **Fetch Asset Groups** parameter, selected by default. When selected, each fetched alert is enriched with the asset groups of its related assets, using one extra API request per alert. Alerts whose asset groups can't be retrieved are fetched without them.
- Documented in the integration README that *login_url* uses the configured name of the **Employee Login Interface** asset, not its nicknames. Name that asset after the login host or URL to get the login address.
- Added *designated_url* to compromised employee credentials alerts and to each of their exposed credentials, so they have the same structure as compromised customer credentials alerts. Existing *designated_url* values are not changed.

#### Incident Fields

##### New: Cyberint Login URL

- New: Holds the login URL associated with the exposed credentials in a Cyberint credentials alert.

##### New: Cyberint Domain

- New: Holds the domain reported in the Cyberint alert data.

##### New: Cyberint Related Asset Name

- New: Holds the name of the first asset related to the Cyberint alert.

##### New: Cyberint Related Asset ID

- New: Holds the full ID of the first asset related to the Cyberint alert.

##### New: Cyberint Asset Groups

- New: Holds the asset groups of the assets related to the Cyberint alert, when **Fetch Asset Groups** is selected.

#### Mappers

##### CyberInt Incoming (mapper)

- Added mapping of *login_url*, *alert_data.domain*, *related_asset_name*, *related_asset_id* and *asset_groups* to the new **Cyberint Login URL**, **Cyberint Domain**, **Cyberint Related Asset Name**, **Cyberint Related Asset ID** and **Cyberint Asset Groups** incident fields.

#### Layouts

##### Cyberint Incident Layout

- Added the **Cyberint Login URL**, **Cyberint Domain**, **Cyberint Related Asset Name**, **Cyberint Related Asset ID** and **Cyberint Asset Groups** fields to the **CyberInt Incident Details** section.
