#### Integrations

##### New: IPGeolocation.io

Initial release of the IPGeolocation.io integration, covering four v3 APIs.

- **IP Geolocation API** (`GET /v3/ipgeo`) through the `ipgeolocation-ip-lookup` command, including the optional
  `geo_accuracy`, `dma_code`, `user_agent`, `security`, `abuse` and hostname modules, response language selection,
  and the `fields` and `excludes` response filters.
- **IP Security API** (`GET /v3/security`) through the `ipgeolocation-ip-security` command.
- **Abuse Contact API** (`GET /v3/abuse`) through the `ipgeolocation-abuse-contact` command, which also populates
  the standard `IP.Registrar.Abuse` context fields.
- **ASN API** (`GET /v3/asn`) through the `ipgeolocation-asn` command, with optional routes, peers, upstreams,
  downstreams and raw WHOIS record.
- The generic `ip` reputation command, which derives a DBotScore from the IP Security threat score and detection
  flags using configurable thresholds and configurable rules for known attackers, anonymizing networks, and bot or
  spam activity.

#### Playbooks

##### New: IPGeolocation.io - IP Enrichment

Reference playbook that scores an IP address, adds Autonomous System context, and resolves the abuse contact when
