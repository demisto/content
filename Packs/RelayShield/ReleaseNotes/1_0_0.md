#### Integrations

##### New: RelayShield

New: Added a new integration, ***RelayShield***, which provides real-time identity-compromise and agent-security threat intelligence.
- Added the ***domain*** command, which checks a domain for phishing-lookalike/typosquat risk and presence in RelayShield's criminal IOC corpus.
- Added the ***ip*** command, which checks an IP address for reputation and malicious/suspicious votes.
- Added the ***email*** command, which checks an email address for breach exposure and active stolen-session risk.
- Added the ***relayshield-mcp-registry-risk*** command, which assesses an MCP server URL or package name for typosquat/supply-chain/registry risk.
- Added the ***relayshield-cert-expiry*** command, which checks a domain's TLS certificate expiry risk.
- Added the ***relayshield-supply-chain*** command, which checks up to 10 vendor domains or emails for combined breach/infostealer risk.
