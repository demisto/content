
#### Integrations

##### Flashpoint Ignite

- Added support for *vulnerability_ids* argument in the **flashpoint-ignite-vulnerability-list** command.

#### Scripts

##### New: FlashpointVulnerabilityDetails

- New: Added a new script - FlashpointVulnerabilityDetails that retrieves the CVE information of the vulnerabilities present in the incident and updates the vulnerability details in the incident data.

##### New: FlashpointReportDetails

- New: Added a new script - FlashpointReportDetails that retrieves the body of the Flashpoint report.

#### Incident Types

##### Ignite Alert

- Updated the Ignite Alert incident type to extract CVE indicators from the *Flashpoint Vulnerability Details* field.

#### Layouts

##### Ignite Alert

- Updated the Ignite Alert layout to display the *Flashpoint Alert Body* field, and added the **Vulnerability Details** and **Report Body** sections with buttons to retrieve the CVE IDs of the vulnerabilities and to import the full report information.

#### Mappers

##### Ignite Alert - Incoming Mapper

- Updated the Ignite Alert - Incoming Mapper to map the *Flashpoint Alert Body* and *Flashpoint Vulnerability Details* fields.

#### Incident Fields

##### New: Flashpoint Alert Body

- New: Added a new incident field - Flashpoint Alert Body.

##### New: Flashpoint Vulnerability Details

- New: Added a new incident field - Flashpoint Vulnerability Details.

##### New: Flashpoint Report Body

- New: Added a new incident field - Flashpoint Report Body.
