
#### Scripts

##### New: SearchAndDeleteEmail

- New: Added the **SearchAndDeleteEmail** script, which searches for emails (and optionally deletes them) across multiple email integrations. Currently supported integrations: Gmail, Microsoft Graph Mail, Microsoft Graph Security and EWS v2. The script replaces the *Search And Delete Emails - Generic v2* and *Get Original Email - Generic v2* playbooks.
<~XSOAR> (Available from Cortex XSOAR 6.10.0).</~XSOAR>
