
#### Scripts

##### FindDuplicateEmailIncidents

- Updated the descriptions of the *emailSubject*, *emailBody*, *emailBodyHTML*, and *emailFrom* arguments to clarify that they expect an incident field name (for example, **emailbody**) and not a field value (for example, **${incident.emailbody}**).
- Fixed an issue where passing a field value instead of a field name to the *emailSubject*, *emailBody*, *emailBodyHTML*, or *emailFrom* arguments caused deduplication to silently fail. The script now ignores values that contain whitespace or are longer than 100 characters and uses the default field name instead.
- Updated the misspelled *exsitingIncidentsLookback* argument as deprecated. Use the *existingIncidentsLookback* argument instead.
