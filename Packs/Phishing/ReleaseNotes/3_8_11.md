
#### Scripts

##### FindDuplicateEmailIncidents

- Improved the descriptions of the *emailSubject*, *emailBody*, *emailBodyHTML*, and *emailFrom* arguments to clarify that they expect an incident field name (for example, `emailbody`) and not a field value (for example, `${incident.emailbody}`).
- Fixed an issue where passing a field value instead of a field name to the *emailSubject*, *emailBody*, *emailBodyHTML*, or *emailFrom* arguments caused deduplication to silently fail. Values that contain whitespace or are longer than 100 characters are now ignored, and the default field name is used.
- Marked the misspelled *exsitingIncidentsLookback* argument as deprecated. Use the *existingIncidentsLookback* argument instead.
