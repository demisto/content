
#### Integrations

##### AWS-WAF

- Added 19 new commands for comprehensive AWS WAF v2 API coverage:
  - ***aws-waf-web-acl-list*** - List all web ACLs in the specified scope.
  - ***aws-waf-web-acl-get*** - Get details of a specific web ACL.
  - ***aws-waf-web-acl-create*** - Create a new web ACL with default action and optional rules.
  - ***aws-waf-web-acl-update*** - Update an existing web ACL's configuration.
  - ***aws-waf-web-acl-delete*** - Delete a specific web ACL.
  - ***aws-waf-web-acl-associate*** - Associate a web ACL with an AWS resource.
  - ***aws-waf-web-acl-disassociate*** - Disassociate a web ACL from an AWS resource.
  - ***aws-waf-web-acl-resource-list*** - List resources associated with a web ACL.
  - ***aws-waf-web-acl-for-resource-get*** - Get the web ACL associated with a specific resource.
  - ***aws-waf-logging-configuration-put*** - Create or update a logging configuration for a web ACL.
  - ***aws-waf-logging-configuration-get*** - Get the logging configuration for a web ACL.
  - ***aws-waf-logging-configuration-delete*** - Delete the logging configuration for a web ACL.
  - ***aws-waf-logging-configuration-list*** - List all logging configurations in the specified scope.
  - ***aws-waf-resource-tag*** - Add tags to a WAF resource.
  - ***aws-waf-resource-untag*** - Remove tags from a WAF resource.
  - ***aws-waf-tag-list*** - List tags for a WAF resource.
  - ***aws-waf-sampled-requests-get*** - Get sampled web requests for a web ACL rule.
  - ***aws-waf-managed-rule-group-list*** - List available managed rule groups.
  - ***aws-waf-managed-rule-group-describe*** - Get details of a specific managed rule group.
