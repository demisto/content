
#### Integrations

##### AWS-WAF

- Added 19 new commands for comprehensive AWS WAF v2 API coverage:
  - **Web ACL Management:** ***aws-waf-web-acl-list***, ***aws-waf-web-acl-get***, ***aws-waf-web-acl-create***, ***aws-waf-web-acl-update***, ***aws-waf-web-acl-delete***.
  - **Web ACL Association:** ***aws-waf-web-acl-associate***, ***aws-waf-web-acl-disassociate***, ***aws-waf-web-acl-resource-list***, ***aws-waf-web-acl-for-resource-get***.
  - **Logging Configuration:** ***aws-waf-logging-configuration-put***, ***aws-waf-logging-configuration-get***, ***aws-waf-logging-configuration-delete***, ***aws-waf-logging-configuration-list***.
  - **Tagging:** ***aws-waf-tag-resource***, ***aws-waf-untag-resource***, ***aws-waf-tag-list***.
  - **Sampled Requests:** ***aws-waf-sampled-requests-get***.
  - **Managed Rule Groups:** ***aws-waf-managed-rule-group-list***, ***aws-waf-managed-rule-group-describe***.
