
#### Integrations

##### Microsoft Defender for Endpoint

- Added the *UnManagedDevice* option to the ***isolation_type*** argument of the ***microsoft-atp-isolate-machine*** command, to support isolating unmanaged devices.
- Deprecated the ***microsoft-atp-start-investigation*** command. The Automated investigation and response APIs are deprecated by Microsoft (see the Microsoft 365 Message Center announcement [MC1411577](https://msmessagecenter.com/MC1411577/)). You can use the microsoft-atp-run-antivirus-scan command instead.
- Deprecated the ***microsoft-atp-list-investigations*** command. The Automated investigation and response APIs are deprecated by Microsoft (see the Microsoft 365 Message Center announcement [MC1411577](https://msmessagecenter.com/MC1411577/)).
