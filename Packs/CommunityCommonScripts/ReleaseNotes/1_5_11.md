
#### Scripts

##### DeleteIndicators

- Fixed an issue where indicator values were inserted into the delete query without quoting or escaping, causing characters inside a value (such as commas, asterisks, and double quotes) to be interpreted as query syntax. A value that produced a standalone `*` term could match, and permanently delete, every indicator in the tenant.
- Added a safeguard that blocks the script from running a delete whose resolved query matches all indicators.
