
#### Integrations

##### O365 File Management (Onedrive/Sharepoint/Teams) (Standard Connector)

Added the following commands:

- **msgraph-driveitem-metadata-get** - Retrieves the metadata of a file or folder, addressed by ID, by path, or by a sharing URL.
- **msgraph-driveitem-activities-list** - Retrieves the recent activities that took place on a file or folder.
- **msgraph-driveitem-analytics-get** - Retrieves activity statistics for a file or folder.
