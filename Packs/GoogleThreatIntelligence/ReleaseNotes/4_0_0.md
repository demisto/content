#### Playbooks

##### New: GTI Agentic Flow Execution - Google Threat Intelligence

This playbook executes a GTI Agentic Flow on demand. It retrieves the details of the provided Flow ID, or retrieves up to 40 Flows and asks the analyst which Flow to execute, triggers a run of the Flow, polls the status of the Flow Execution until it reaches a terminal status, cancels the Flow Execution when the polling timeout is reached, and retrieves the related objects of the Flow Execution for further investigation.

##### New: GTI Agentic Session Interaction - Google Threat Intelligence

This playbook interacts with the Google Threat Intelligence agent through a GTI Agentic Session. It asks the analyst for the message when it is not provided, posts the message to the provided session, or asks the analyst whether to continue an existing session or to create a new one, and displays the answer of the agent. It then asks the analyst whether to continue the conversation and, if so, asks for the next message after every answer, until the analyst ends the conversation. Finally, it retrieves the complete conversation of the session and optionally shares the session. The playbook supports up to 100 follow-up messages after the first message.

##### New: GTI Agentic Session Conversation Turn - Google Threat Intelligence

This playbook performs a single turn of the conversation with the Google Threat Intelligence agent in a GTI Agentic Session. It asks the analyst for the next message, posts the message to the session and displays the answer of the agent. When the analyst does not provide a message, it marks the conversation as ended. It is meant to run in a loop from the GTI Agentic Session Interaction - Google Threat Intelligence playbook, which runs it up to 100 times.
