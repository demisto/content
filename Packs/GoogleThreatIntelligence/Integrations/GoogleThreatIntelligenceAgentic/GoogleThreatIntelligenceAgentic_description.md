## Google Threat Intelligence - Agentic Help

To use the integration, an API Key will be required from your Google Threat Intelligence account.

## Authorization:

Your API key can be found in your Google Threat Intelligence account user menu, by clicking on your avatar.
Your API key carries all your privileges, so keep it secure and don't share it with anyone.

### Instance Configuration

1. Configure a Google Threat Intelligence - Agentic integration instance with a valid API Key.
2. Optionally, provide the Group ID if the API quota of the requests should be charged to a group.
3. Click **Test** to validate the connection.

| **Parameter** | **Description** |
| --- | --- |
| API Key | Provide the API key of the Google Threat Intelligence platform for the authentication. |
| Group ID | Specify the ID of the group to which the API quota of the requests should be charged. If not provided, the quota is charged to the user that owns the API key. |
| Trust any certificate (not secure) | Select to avoid the server certificate validation. |
| Use system proxy settings | Select to use the system proxy settings. |

**Note:** The Google Threat Intelligence Agentic API is available only for the users that have the Agentic capabilities enabled on their Google Threat Intelligence account.
