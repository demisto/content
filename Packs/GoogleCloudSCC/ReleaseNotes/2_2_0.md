#### Integrations

##### Google Cloud SCC

- Added support for the **google-cloud-scc-v2-finding-update** command, which updates an organization's or source's finding using the Security Command Center v2 API.
- Added support for the **google-cloud-scc-v2-finding-list** command, which lists an organization's or source's findings using the Security Command Center v2 API.
- Added support for the **google-cloud-scc-mute-rule-get** command, which gets a mute rule (mute config) of an organization using the Security Command Center v2 API.
- Added support for the **google-cloud-scc-finding-mute** command, which mutes an organization's or source's finding using the Security Command Center v2 API.
- Added support for the **google-cloud-scc-mute-rule-create** command, which creates a mute rule (mute config) for an organization using the Security Command Center v2 API.
- Added support for the **google-cloud-scc-finding-unmute** command, which unmutes an organization's or source's finding using the Security Command Center v2 API.
- Added support for the **google-cloud-scc-v2-finding-state-update** command, which updates the state of an organization's or source's finding using the Security Command Center v2 API.
- Deprecated the **google-cloud-scc-finding-list** command.
- Deprecated the **google-cloud-scc-finding-state-update** command.
- Deprecated the **google-cloud-scc-finding-update** command.
- Updated the Docker image to: *demisto/google-api-py3:1.0.0.11643673*.

#### Incident Fields

##### New: GoogleCloudSCC Finding Mute Status

- New: Added a new incident field: **GoogleCloudSCC Finding Mute Status**.

#### Layouts

##### Google Cloud SCC Finding

- Updated the Google Cloud SCC Finding layout to display the **GoogleCloudSCC Finding Mute Status** field and added the **Mute the Finding** and **Unmute the Finding** buttons.

#### Mappers

##### GoogleCloudSCC - Incoming Mapper

- Updated the GoogleCloudSCC - Incoming Mapper mapper to map the **GoogleCloudSCC Finding Mute Status** incident field.

#### Scripts

##### New: GoogleCloudSCCUnmuteFinding

- New: Added a new script: **GoogleCloudSCCUnmuteFinding**, which unmutes a Google Cloud Security Command Center finding by its finding name using the **google-cloud-scc-finding-unmute** command, and sets the mute state of the finding on the **GoogleCloudSCC Finding Mute Status** incident field.

##### New: GoogleCloudSCCMuteFinding

- New: Added a new script: **GoogleCloudSCCMuteFinding**, which mutes a Google Cloud Security Command Center finding by its finding name using the **google-cloud-scc-finding-mute** command, and sets the mute state of the finding on the **GoogleCloudSCC Finding Mute Status** incident field.
