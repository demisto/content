
#### Integrations

##### Google Gemini

- Added a *temperature* argument to the **google-gemini-send-message** command, allowing the sampling temperature to be overridden per call (defaults to 0.5). The instance-level *Temperature* parameter is still used as the client default when calling the API directly.
- Added *max_input_tokens* and *truncate* arguments to the **google-gemini-send-message** command, allowing testing of different context window sizes. Input token count is verified via the model's countTokens endpoint; when the budget is exceeded, the command errors out by default, or truncates the oldest history first (then the prompt) when *truncate=true*.
- Added the *max_tokens* argument to the **google-gemini-send-message** command, allowing the instance-level maximum output token setting to be overridden per call.
- Added *InputTokenCount*, *OutputTokenCount*, *TotalTokenCount*, and *Truncated* to the command's context outputs for measuring accuracy/attention across context sizes.
- Updated the supported model list to include the *gemini-3.1-flash-lite*, *gemini-3.5-flash-lite*, *gemini-3.5-flash*, *gemini-3.6-flash*, *gemini-3.7-flash*, and *gemini-3.8-flash* models. Older *gemini-1.5* and *gemini-2.0* models remain selectable in the **Default Model** dropdown but are no longer part of the officially supported/documented model list.
