
#### Integrations

##### Google Gemini
- Updated the Docker image to: *demisto/google-api-py3:1.0.0.13398989*.


- Added the *temperature* argument to the ***google-gemini-send-message*** command. Use this argument to override the sampling temperature for each call. The default is 0.5. When you call the API directly, the client still uses the instance-level Temperature parameter as the default.
- Added the *max_input_tokens* and *truncate* arguments to the ***google-gemini-send-message*** command. Use these arguments to test different context window sizes. The command verifies the input token count with the model's countTokens endpoint. When the input token count exceeds max_input_tokens, the command returns an error by default. If you set truncate to true, the command truncates the oldest history entries first, and then the prompt.
- Added the *max_tokens* argument to the ***google-gemini-send-message*** command. Use this argument to override the instance-level maximum output token setting for each call.
- Added the *InputTokenCount*, *OutputTokenCount*, *TotalTokenCount*, and *Truncated* context outputs to the ***google-gemini-send-message*** command. Use these outputs to measure accuracy and attention across context sizes.
- Updated the supported model list to include the **gemini-3.5-flash-lite**, **gemini-3.5-flash**, **gemini-3.6-flash**, **gemini-3.7-flash**, and **gemini-3.8-flash** models.
