
#### Integrations

##### Cloudflare WAF

- Added 11 new commands for managing rules, entry points, and versions within Cloudflare rulesets:
  - ***cloudflare-waf-ruleset-rule-create*** - Creates a new rule in a ruleset at the account or zone level.
  - ***cloudflare-waf-ruleset-rule-update*** - Updates an existing rule in a ruleset.
  - ***cloudflare-waf-ruleset-rule-delete*** - Deletes a rule from a ruleset.
  - ***cloudflare-waf-ruleset-entrypoint-get*** - Gets the entry point ruleset for a specific phase at the account or zone level.
  - ***cloudflare-waf-ruleset-entrypoint-update*** - Updates the entry point ruleset for a specific phase.
  - ***cloudflare-waf-ruleset-version-list*** - Lists all versions of a ruleset at the account or zone level.
  - ***cloudflare-waf-ruleset-version-get*** - Gets a specific version of a ruleset, including its rules.
  - ***cloudflare-waf-ruleset-version-delete*** - Deletes a specific version of a ruleset.
  - ***cloudflare-waf-ruleset-entrypoint-version-list*** - Lists all versions of the entry point ruleset for a specific phase.
  - ***cloudflare-waf-ruleset-entrypoint-version-get*** - Gets a specific version of the entry point ruleset for a phase.
  - ***cloudflare-waf-ruleset-rule-list-by-tag*** - Lists the rules of a managed ruleset filtered by tag or category.
- Fixed an issue where the ***cloudflare-waf-ruleset-get***, ***cloudflare-waf-ruleset-create***, ***cloudflare-waf-ruleset-update***, and ***cloudflare-waf-ruleset-delete*** commands failed for account-level operations (without a zone ID).

- Updated the *phase* argument on the ruleset commands to include the full set of supported phases.
- Deprecated the ***cloudflare-waf-firewall-rule-create***, ***cloudflare-waf-firewall-rule-update***, ***cloudflare-waf-firewall-rule-delete***, ***cloudflare-waf-firewall-rule-list***, ***cloudflare-waf-filter-create***, ***cloudflare-waf-filter-update***, ***cloudflare-waf-filter-delete***, and ***cloudflare-waf-filter-list*** commands. Use the ***cloudflare-waf-ruleset-rule-\**** commands instead.
