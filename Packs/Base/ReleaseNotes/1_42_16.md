
#### Scripts

##### ValidateContent

- Fixed an issue where the script failed with *logging_setup()* errors (*got an unexpected keyword argument 'calling_function'* and *missing 1 required positional argument: 'verbose'*) due to a demisto-sdk signature mismatch across Docker image versions.
- Fixed an issue where the script failed with *cannot import name 'formatargspec' from 'inspect'* on Python 3.11+ Docker images.
- Fixed an issue where the script failed to return results with *Failed to decode (loop) data ... invalid character 'P'* caused by demisto-sdk output leaking into the script's stdout. Output is now diverted away from the stdout channel for the whole run, including during imports and content-directory setup, and is reported as a debug entry instead.
- Updated the Docker image to: *demisto/xsoar-tools:1.0.0.11131287*.
