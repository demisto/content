
#### Scripts

##### CommonServerPython

- Added the ***stream_json_items*** function for memory-efficient, streaming parsing of large JSON responses, consuming the response stream and yielding one record at a time (using *ijson*).
- Added the ***stream_xml_elements*** function for memory-efficient, streaming parsing of large XML responses, consuming the response stream and yielding one element at a time (using XML *iterparse* with *.clear()*).
- Added the ***send_assets_to_xsiam*** function, which sends assets to XSIAM using the streaming serialize-and-free path by default (lower peak memory), while preserving the assets snapshot headers/sealing.
- Documented consuming a streamed HTTP response body via ***resp_type='response'*** together with ***stream=True*** in ***BaseClient._http_request***.
