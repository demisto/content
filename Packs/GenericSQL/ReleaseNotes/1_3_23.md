
#### Integrations

##### Generic SQL

- Updated the PostgreSQL connection to use the psycopg 3 driver instead of psycopg2.
- **Breaking change:** For PostgreSQL, a query that contains multiple statements now returns the result of the first statement instead of the last one. All statements still run. For example:
  - `SELECT * FROM t WHERE id = 1; SELECT * FROM t WHERE id = 5` now returns the row with `id = 1`.
  - `SET search_path TO my_schema; SELECT * FROM my_table` now returns *Command executed* with no results, because the first statement does not return rows.

  To get the result of a specific statement, run it as a separate query, or use schema-qualified names (for example, `SELECT * FROM my_schema.my_table`).
