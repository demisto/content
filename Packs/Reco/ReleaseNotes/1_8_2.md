#### Integrations

##### Reco

- Fixed an issue where ***fetch-incidents*** stopped fetching alerts when *Minimum risk level* was set below Critical. The severity filter is now sent as `eq` clauses joined with `or` instead of the unsupported `in` operator.
- Fixed an issue where ***fetch-incidents*** treated failed API calls as "no new alerts". API errors are now raised so failures are visible in Cortex XSOAR.
- Improved the ***Test*** button to query alerts with the same filter used by ***fetch-incidents***, so filter errors are caught at configuration time.
- Updated the Docker image to: *demisto/python3:3.12.14.13919218*.
