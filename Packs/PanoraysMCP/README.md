Use the Panorays Axis MCP integration to securely connect to the Panorays Axis Model Context Protocol (MCP) server and access Panorays tools in real time.

## What does this pack do?

This pack is intended for Cortex Agentic AI.

Connects to the Panorays Axis MCP server to automatically discover tools and expose them as agentic system actions that users can enable for agents.

## Tools

Tool availability depends on the permissions granted to the authenticated Panorays user or API token.
