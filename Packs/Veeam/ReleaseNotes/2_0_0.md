##### Incident Types

- Added new incident type - *SureBackup - Backup Verification and Content Scan*. The incident is based on the result of the SureBackup job run in the *Backup verification and content scan only* mode. 

    This incident type supports new fields: *Veeam Session ID*, *Veeam Next Run*, *Veeam Last Run*, *Veeam Number of Objects*.
- Added new incident type - *Security & Compliance Analyzer*. The incident is based on the results of the Veeam Security & Compliance Analyzer scan. 

    This incident type supports new fields: *Veeam Best Practice ID*, *Veeam Best Practice Name*, *Veeam Best Practice Status*, *Veeam Best Practice Details*.
- Added new incident type - *Malware Detection - Indicators of Compromise*. The incident is based on the Veeam Backup & Replication malware event.
- Added support for the new incident types to the Veeam Backup & Replication Incident Classifier and Veeam Backup & Replication Incoming Mapper.

##### Incident Layouts

- Added new incident layouts:
    - *SureBackup - Backup Verification and Content Scan*
    - *Security & Compliance Analyzer*
    - *Malware Detection - Indicators of Compromise*
- Added a button to run a playbook to the following incident layouts:
    - *Configuration Backup*
    - *Backup Repository State*
    - *Malware Detection*

##### Playbooks

Added new playbooks:

- *Veeam - Start Security & Compliance Analyzer*. Starts Security & Compliance Analyzer scan for the Veeam Backup & Replication integration instance.
- *Veeam - Start Scan Backup*. Starts a Scan Backup session with manual configuration.
- *Veeam - Start Disk Publishing*. Gets the latest restore point of the virtual machine and starts disk publishing using the specified mount server.
- *Veeam - Stop Disk Publishing*. Stops disk publishing.
- *Veeam - Start Instant Hyper-V VM Recovery Automatically*. Starts the Instant Recovery session for Microsoft Hyper-V virtual machines with automatic configuration.
- *Veeam - Start Instant Hyper-V VM Recovery Manually*. Starts the Instant Recovery session for Microsoft Hyper-V virtual machines with manual configuration.
- *Veeam - Start Quick Backup*. Starts a Quick Backup session for a VMware vSphere virtual machine.
- *Veeam - Find Entra ID User*. Checks if a user exists in the latest Microsoft Entra ID tenant backup.
- *Veeam - Compare Entra ID Items*. Compares Microsoft Entra ID item properties between the latest restore point and production.

##### Scripts

Added a new script *GetLatestCleanRestorePoint* that simplifies restore point filtering.
