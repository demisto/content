- Added support for the new *Recon Threat State* incident type.

#### Incident Types

##### SureBackup - Backup Verification and Content Scan

- Added new incident type. The incident is based on the result of the SureBackup job run in the *Backup verification and content scan only* mode.

##### Security & Compliance Analyzer

- Added new incident type. The incident is based on the results of the Veeam Security & Compliance Analyzer scan.

##### Malware Detection - Indicators of Compromise

- Added new incident type. The incident is based on the Veeam Backup & Replication malware event.

##### Recon Threat State

- Added new incident type. The incident is based on the *Recon Scanner threat state* alarm.

#### Playbooks

##### Veeam - Start Security and Compliance Analyzer

- Added new playbook. Starts Security & Compliance Analyzer scan for the Veeam Backup & Replication integration instance.

##### Veeam - Start Scan Backup

- Added new playbook. Starts a Scan Backup session with manual configuration.

##### Veeam - Start Disk Publishing

- Added new playbook. Gets the latest restore point of the virtual machine and starts disk publishing using the specified mount server.

##### Veeam - Stop Disk Publishing

- Added new playbook. Stops disk publishing.

##### Veeam - Start Instant Hyper-V VM Recovery Automatically

- Added new playbook. Starts the Instant Recovery session for Microsoft Hyper-V virtual machines with automatic configuration.

##### Veeam - Start Instant Hyper-V VM Recovery Manually

- Added new playbook. Starts the Instant Recovery session for Microsoft Hyper-V virtual machines with manual configuration.

##### Veeam - Start Quick Backup

- Added new playbook. Starts a Quick Backup session for a VMware vSphere virtual machine.

##### Veeam - Find Entra ID User

- Added new playbook. Checks if a user exists in the latest Microsoft Entra ID tenant backup.

##### Veeam - Compare Entra ID Items

- Added new playbook. Compares Microsoft Entra ID item properties between the latest restore point and production.
