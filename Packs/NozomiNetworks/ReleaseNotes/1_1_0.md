#### Integrations

##### Nozomi Networks

- Updated the mapping of the Nozomi risk to the incident severity: risk 1-5 is mapped to Low, 6-7 to Medium, 8-9 to High, and 10 to Critical.
- Added the *Custom alert filter* integration parameter, which applies an additional Nozomi query condition to fetched alerts.
- Added the *Default incident role* integration parameter, which assigns a Cortex XSOAR role to fetched incidents.
- Added the *Custom incident name pattern* integration parameter, which allows building the incident name by concatenating Nozomi alert fields, for example `{type_id}_{id} - {description}`. The default name (`{name}_{id}`) is used when the parameter is empty.
