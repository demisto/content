
#### Integrations

##### Nozomi Networks

- Added support for **Custom alert filter** parameter that an additional Nozomi query language filter appended to the alerts query, combined with the other fetch filters.
- Added support for **Default incident role** parameter that the Cortex XSOAR role assigned to incidents created from fetched Nozomi alerts, for example analyst_l2.
- Updated the Docker image to: *demisto/python3:3.12.14.13495286*.
