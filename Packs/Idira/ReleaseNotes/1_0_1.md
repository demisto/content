
#### Integrations
##### Idira Identity Response
- Initial implementation of the integration.
- Added Feature Adoption usage reporting for successfully executed commands, with a *Disable usage reporting* parameter to opt out.

#### Correlation Rules

##### New: Idira - MFA Failure Detected

- New: Detects failed or denied MFA challenges in the CyberArk Identity Security Platform audit log.

##### New: Idira - Multiple Failed Logins Detected

- New: Detects 5 or more failed logins for a single user from the same source IP within 10 minutes.

##### New: Idira - SSH Sudo Command Detected

- New: Detects sudo commands executed in SSH sessions.

#### Playbooks

##### New: Idira - Lock User

- New: Locks the issue's user in the Idira Identity Security Platform, blocking them from authenticating.

##### New: Idira - Unlock User

- New: Unlocks the issue's user in the Idira Identity Security Platform, restoring their ability to authenticate.

##### New: Idira - All Logout

- New: Ends all of the issue's user active sessions and cookies in the Idira Identity Security Platform.
