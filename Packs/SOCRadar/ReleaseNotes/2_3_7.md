
#### Integrations

##### SOCRadar Incidents v4

- Improved the reliability of fetch incidents by adding an hourly check that retrieves alarms not captured by the regular fetch cycle, without creating duplicate incidents.
- Added automatic retries when the SOCRadar API rate limit is reached or a temporary server error occurs while fetching incidents.

##### SOCRadar Incidents v4 Multi-Tenant

- Improved the reliability of fetch incidents by adding periodic checks that retrieve alarms not captured by the regular fetch cycle, without creating duplicate incidents.
- Added automatic retries when the SOCRadar API rate limit is reached or a temporary server error occurs while fetching incidents.
- Fixed an issue where the list of previously fetched alarms was shortened after a fetch error, which could cause duplicate incidents.
