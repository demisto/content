
#### Integrations

##### SOCRadar Incidents v4

- Added support for an hourly check to fetch incidents that retrieves alarms not captured by the regular fetch cycle, without creating duplicate incidents.
- Added support for automatic retries when the **SOCRadar** API rate limit is reached or a temporary server error occurs while fetching incidents.

##### SOCRadar Incidents Multi-Tenant

- Added support for periodic checks to fetch incidents that retrieve alarms not captured by the regular fetch cycle, without creating duplicate incidents.
- Added support for automatic retries when the **SOCRadar** API rate limit is reached or a temporary server error occurs while fetching incidents.
- Fixed an issue where the list of previously fetched alarms was shortened after a fetch error, which could cause duplicate incidents.
