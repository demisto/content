
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-cloudrun-functions-list*** command which lists Google Cloud functions in the specified project and region.
- Added the ***gcp-cloudrun-locations-list*** command, which lists all available Google Cloud functions locations (regions) in the project.
- Added the ***gcp-cloudrun-function-get*** command, which gets the details of a specific Google Cloud function.
- Added the ***gcp-cloudfunctions-function-execute*** command, which synchronously invokes a deployed Google Cloud (1st Gen) function and returns its execution result.
