
#### Integrations

##### Google Cloud Platform

Migrated the Google Key Management Service integration into the unified GCP integration.
- Added the ***gcp-kms-keyring-list*** command.
- Added the ***gcp-kms-key-list*** command.
- Added the ***gcp-kms-key-list-all*** command.
- Added the ***gcp-kms-key-get*** command.
- Added the ***gcp-kms-key-create*** command.
- Added the ***gcp-kms-key-update*** command.
- Added the ***gcp-kms-key-version-enable*** command.
- Added the ***gcp-kms-key-version-disable*** command.
- Added the ***gcp-kms-key-version-destroy*** command.
- Added the ***gcp-kms-key-version-restore*** command.
- Added the ***gcp-kms-public-key-get*** command.
- Added the ***gcp-kms-symmetric-encrypt*** command.
- Added the ***gcp-kms-symmetric-decrypt*** command.
- Added the ***gcp-kms-asymmetric-encrypt*** command.
- Added the ***gcp-kms-asymmetric-decrypt*** command.
- Fixed an issue where ***gcp-kms-symmetric-decrypt*** and ***gcp-kms-asymmetric-decrypt*** corrupted binary data by decoding it as UTF-8. Binary payloads are now returned as a file.
- Fixed an issue where a cipher text supplied through the *entry_id* argument was incorrectly base64-decoded instead of being read as raw bytes.
