- Added the ***gcp-kms-key-ring-list*** command.

- Added the ***gcp-kms-key-get*** command.
- Added the ***gcp-kms-key-create*** command.
- Added the ***gcp-kms-key-update*** command.
- Added the ***gcp-kms-key-version-enable*** command.
- Added the ***gcp-kms-key-version-disable*** command.
- Added the ***gcp-kms-key-version-destroy*** command.
- Added the ***gcp-kms-key-version-restore*** command.
- Added the ***gcp-kms-public-key-get*** command.

- Added the ***gcp-kms-symmetric-decrypt*** command.
