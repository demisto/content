
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-cloudrun-functions-list*** command that lists Google Cloud Functions in the specified project and region.
- Added the ***gcp-cloudrun-locations-list*** command that lists all locations (regions) available for Google Cloud Functions in the project.
- Added the ***gcp-cloudrun-function-get*** command that gets the details of a specific Google Cloud function.
- Added the ***gcp-cloudfunctions-function-execute*** command that synchronously invokes a deployed Google Cloud (1st Gen) function and returns its execution result.
