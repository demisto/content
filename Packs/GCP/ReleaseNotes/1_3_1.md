#### Integrations

##### Google Cloud Platform

Added the following new commands:
- ***gcp-compute-zone-operation-wait*** - Polls a zonal Compute Engine operation until it reaches the DONE status.
- ***gcp-compute-region-operation-wait*** - Polls a regional Compute Engine operation until it reaches the DONE status.
- ***gcp-compute-global-operation-wait*** - Polls a global Compute Engine operation until it reaches the DONE status.
