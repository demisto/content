
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-global-operation-get*** command that retrieves the specified global Operations resource. Required permission: compute.globalOperations.get.
- Added the ***gcp-compute-zone-operation-get*** command that retrieves the specified zone-specific Operations resource. Required permission: compute.zoneOperations.get.
- Added the ***gcp-compute-region-operation-get*** command that retrieves the specified region-specific Operations resource. Required permission: compute.regionOperations.get.
- Added the ***gcp-compute-global-operation-list*** command that lists the global Operations resources in the specified project. Required permission: compute.globalOperations.list.
- Added the ***gcp-compute-zone-operation-list*** command that lists the zone-specific Operations resources in the specified project and zone. Required permission: compute.zoneOperations.list.
- Added the ***gcp-compute-region-operation-list*** command that lists the region-specific Operations resources in the specified project and region. Required permission: compute.regionOperations.list.
- Added the ***gcp-compute-global-operation-delete*** command that deletes the specified global Operations resource. Required permission: compute.globalOperations.delete.
- Added the ***gcp-compute-zone-operation-delete*** command that deletes the specified zone-specific Operations resource. Required permission: compute.zoneOperations.delete.
- Added the ***gcp-compute-region-operation-delete*** command that deletes the specified region-specific Operations resource. Required permission: compute.regionOperations.delete.
