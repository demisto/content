
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-instance-groups-list*** command that retrieves the list of instance groups that are located in the specified project and zone. Required permission: compute.instanceGroups.list.
- Added the ***gcp-compute-instance-groups-aggregated-list*** command that retrieves the list of instance groups in the specified project across all zones. Required permission: compute.instanceGroups.list.
- Added the ***gcp-compute-instance-group-instances-list*** command that lists the instances in the specified instance group. Required permission: compute.instanceGroups.list.
- Added the ***gcp-compute-instance-group-insert*** command that creates an instance group in the specified project and zone. Required permission: compute.instanceGroups.create.
- Added the ***gcp-compute-instance-group-delete*** command that deletes the specified instance group. Required permission: compute.instanceGroups.delete.
- Added the ***gcp-compute-instance-group-instances-add*** command that adds a list of instances to the specified instance group. Required permission: compute.instanceGroups.update.
- Added the ***gcp-compute-instance-group-instances-remove*** command that removes one or more instances from the specified instance group, but does not delete those instances. Required permission: compute.instanceGroups.update.
- Added the ***gcp-compute-instance-group-named-ports-set*** command that sets the named ports for the specified instance group. Required permission: compute.instanceGroups.update.
- Updated the Docker image to: *demisto/googleapi-python3:1.0.0.13053055*.
