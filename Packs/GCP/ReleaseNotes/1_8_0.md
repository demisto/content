
#### Integrations

##### Google Cloud Platform

- Added support for the ***gcp-compute-image-get-from-family*** command that returns the latest image that is part of an image family and is not deprecated. Required permission: compute.images.get.
- Added support for the ***gcp-compute-image-delete*** command that deletes the specified image. Required permission: compute.images.delete.
- Added support for the ***gcp-compute-image-insert*** command that creates an image in the specified project using the data included in the request. Required permission: compute.images.create.
- Added support for the ***gcp-compute-image-labels-set*** command that sets the labels on an image. Required permission: compute.images.setLabels.
- Added support for the ***gcp-compute-images-list*** command that lists images in a specific project. Required permission: compute.images.list.
