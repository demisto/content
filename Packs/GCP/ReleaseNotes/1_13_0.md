
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-disks-list*** command that retrieves a list of persistent disks contained within the specified zone. Required permission: compute.disks.list.
- Added the ***gcp-compute-disks-aggregated-list*** command that retrieves an aggregated list of persistent disks across all zones in the project. Required permission: compute.disks.list.
- Added the ***gcp-compute-disk-get*** command that returns a specified persistent disk. Required permission: compute.disks.get.
- Added the ***gcp-compute-disk-insert*** command that creates a persistent disk in the specified project and zone. Required permission: compute.disks.create.
- Added the ***gcp-compute-disk-delete*** command that deletes the specified persistent disk. Required permission: compute.disks.delete.
- Added the ***gcp-compute-disk-resize*** command that resizes the specified persistent disk. Required permission: compute.disks.resize.
- Added the ***gcp-compute-disk-labels-set*** command that sets the labels on a persistent disk. Required permission: compute.disks.setLabels.
- Added the ***gcp-compute-disk-snapshot-create*** command that creates a snapshot of a specified persistent disk. Required permissions: compute.disks.createSnapshot, compute.snapshots.create.
- Added the ***gcp-compute-disk-types-list*** command that retrieves a list of disk types available in the specified zone. Required permission: compute.diskTypes.list.
- Added the ***gcp-compute-disk-types-aggregated-list*** command that retrieves an aggregated list of disk types across all zones in the project. Required permission: compute.diskTypes.list.
- Added the ***gcp-compute-disk-type-get*** command that returns the specified disk type. Required permission: compute.diskTypes.get.
