
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-network-peering-add*** command that adds a peering connection to the specified network. Required permission: compute.networks.addPeering.
- Added the ***gcp-compute-network-peering-remove*** command that removes a peering connection from the specified network. Required permission: compute.networks.removePeering.
- Added the ***gcp-compute-network-delete*** command that deletes the specified network. Required permission: compute.networks.delete.
