
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-machine-type-get*** command that returns the specified machine type. Required permission: compute.machineTypes.get.
- Added the ***gcp-compute-machine-types-list*** command that retrieves a list of machine types available in the specified zone. Required permission: compute.machineTypes.list.
- Added the ***gcp-compute-machine-types-aggregated-list*** command that retrieves an aggregated list of machine types across all zones of the specified project. Required permission: compute.machineTypes.list.
