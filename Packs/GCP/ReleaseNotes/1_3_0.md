
#### Integrations

##### Google Cloud Platform

- Added the following Google Kubernetes Engine (GKE) commands, migrated from the **GoogleKubernetesEngine** pack:
  - ***gcp-container-cluster-list***
  - ***gcp-container-cluster-get***
  - ***gcp-container-node-pool-list***
  - ***gcp-container-node-pool-get***
  - ***gcp-container-node-pool-management-set***
  - ***gcp-container-operation-list***
  - ***gcp-container-operation-get***
  - ***gcp-container-operation-cancel***
- Updated the ***gcp-container-cluster-security-update*** command to support Binary Authorization (*enable_binary_authorization*), addon toggles (*enable_http_load_balancing*, *enable_kubernetes_dashboard*, *enable_network_policy*), basic authentication (*enable_basic_auth*), legacy ABAC authorization (*enable_legacy_authorization*), and Stackdriver Kubernetes monitoring/logging (*enable_stackdriver_kubernetes*).
