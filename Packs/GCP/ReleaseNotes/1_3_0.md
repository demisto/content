
#### Integrations

##### Google Cloud Platform

- Added the **gcp-compute-network-peering-add** command that adds a peering to the specified network. Required permission: compute.networks.addPeering.
- Added the **gcp-compute-network-peering-remove** command that removes a peering from the specified network. Required permission: compute.networks.removePeering.
- Added the **gcp-compute-network-delete** command that deletes the specified network. Required permission: compute.networks.delete.
