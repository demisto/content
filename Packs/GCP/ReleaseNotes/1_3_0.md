#### Integrations

##### Google Cloud Platform
- Added the following new commands:
  - ***gcp-compute-firewalls-list***
  - ***gcp-storage-buckets-list***
  - ***gcp-storage-bucket-policies-list***
  - ***gcp-storage-bucket-object-policies-list***
  - ***gcp-gke-cluster-security-update***

- Deprecated the following matching commands:
  - ***gcp-compute-firewall-list***
  - ***gcp-storage-bucket-list***
  - ***gcp-storage-bucket-policy-list***
  - ***gcp-storage-bucket-object-policy-list***
  - ***gcp-container-cluster-security-update***

- Updated the context output path of the command ***gcp-compute-firewall-get*** to start with the prefix *GCP.Compute.Firewalls*.
- Updated the context output path of the command ***gcp-compute-snapshots-list*** to start with the prefix *GCP.Compute.Snapshots*.
- Updated the context output path of the command ***gcp-compute-snapshot-get*** to start with the prefix *GCP.Compute.Snapshots*.
- Updated the context output path of the command ***gcp-compute-instances-aggregated-list-by-ip*** to start with the prefix *GCP.Compute.AggregatedInstances*.
- Updated the context output path of the command ***gcp-storage-bucket-metadata-update*** to start with the prefix *GCP.Storage.Buckets*.
- Updated the context output path of the quick action ***Enable GCP Bucket Versioning*** to start with the prefix *GCP.Storage.Buckets*.
- Updated the context output path of the quick action ***Set GCP Bucket Access to Uniform*** to start with the prefix *GCP.Storage.Buckets*.
- Updated the context output path of the command ***gcp-storage-bucket-get*** to start with the prefix *GCP.Storage.Buckets*.
- Updated the context output path of the command ***gcp-storage-bucket-objects-list*** to start with the prefix *GCP.Storage.Buckets.Objects*.
- Updated the context output path of the command ***gcp-storage-bucket-policy-set*** to start with the prefix *GCP.Storage.BucketPolicies*.
- Updated the context output path of the command ***gcp-storage-bucket-object-policy-set*** to start with the prefix *GCP.Storage.BucketObjectPolicies*.
- Updated the context output path of the quick action ***Enable GKE Cluster Intra-Node Visibility*** to start with the prefix *GCP.GKE.Operations*.
- Updated the context output path of the quick action ***Enable Master Authorized Networks on GKE*** to start with the prefix *GCP.GKE.Operations*.
