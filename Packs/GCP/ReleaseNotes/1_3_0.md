
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-firewall-delete*** command that deletes the specified firewall rule.
- Added the ***gcp-compute-snapshot-delete*** command that deletes the specified snapshot.
- Added the ***gcp-compute-snapshot-labels-set*** command that sets the labels on a snapshot.
- Added the ***gcp-compute-project-info-metadata-add*** command that adds or updates project-wide metadata.
