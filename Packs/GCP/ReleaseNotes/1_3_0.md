
#### Integrations

##### Google Cloud Platform

- Added support for **gcp-compute-image-get-from-family** command that returns the latest image that is part of an image family and is not deprecated. required permission: compute.images.get.
- Added support for **gcp-compute-image-delete** command that deletes the specified image. required permission: compute.images.delete.
- Added support for **gcp-compute-image-insert** command that creates an image in the specified project using the data included in the request. required permission: compute.images.create.
- Added support for **gcp-compute-image-labels-set** command that sets the labels on an image. required permission: compute.images.setLabels.
- Added support for **gcp-compute-images-list** command that lists images in a specific project. required permission: compute.images.list.
