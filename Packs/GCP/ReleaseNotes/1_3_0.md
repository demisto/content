#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-disks-list*** command to retrieve a list of persistent disks contained within a specified zone (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disks-aggregated-list*** command to retrieve an aggregated list of persistent disks across all zones in a project (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-get*** command to retrieve a specified persistent disk (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-insert*** command to create a persistent disk in a specified project and zone (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-delete*** command to delete a specified persistent disk (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-resize*** command to increase the size of a specified persistent disk (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-labels-set*** command to set the labels on a persistent disk (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-snapshot-create*** command to create a snapshot of a specified persistent disk (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-types-list*** command to retrieve a list of disk types available in a specified zone (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-types-aggregated-list*** command to retrieve an aggregated list of disk types across all zones in a project (migrated from the Google Cloud Compute pack).
- Added the ***gcp-compute-disk-type-get*** command to retrieve a specified disk type (migrated from the Google Cloud Compute pack).
