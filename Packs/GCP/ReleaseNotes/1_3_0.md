
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-address-get*** command, which returns the specified regional address resource.
- Added the ***gcp-compute-address-list*** command, which retrieves the list of regional address resources in the specified region.
- Added the ***gcp-compute-address-aggregated-list*** command, which retrieves an aggregated list of regional address resources across all regions.
- Added the ***gcp-compute-address-insert*** command, which creates a regional address resource in the specified project.
- Added the ***gcp-compute-address-delete*** command, which deletes the specified regional address resource.
- Added the ***gcp-compute-global-address-get*** command, which returns the specified global address resource.
- Added the ***gcp-compute-global-address-list*** command, which retrieves the list of global address resources.
- Added the ***gcp-compute-global-address-insert*** command, which creates a global address resource in the specified project.
- Added the ***gcp-compute-global-address-delete*** command, which deletes the specified global address resource.
