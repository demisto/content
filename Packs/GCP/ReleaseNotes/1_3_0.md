
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-machine-type-get*** command to retrieve a specific machine type in a zone.
- Added the ***gcp-compute-machine-types-list*** command to retrieve a list of the machine types available in a zone.
- Added the ***gcp-compute-machine-types-aggregated-list*** command to retrieve an aggregated list of the machine types across all zones of a project.
