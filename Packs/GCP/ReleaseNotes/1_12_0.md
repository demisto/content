
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-address-get*** command that returns the specified regional address resource. Required permission: compute.addresses.get.
- Added the ***gcp-compute-address-list*** command that retrieves the list of regional address resources in the specified region. Required permission: compute.addresses.list.
- Added the ***gcp-compute-address-aggregated-list*** command that retrieves an aggregated list of regional address resources across all regions. Required permission: compute.addresses.list.
- Added the ***gcp-compute-address-insert*** command that creates a regional address resource in the specified project. Required permission: compute.addresses.create.
- Added the ***gcp-compute-address-delete*** command that deletes the specified regional address resource. Required permission: compute.addresses.delete.
- Added the ***gcp-compute-global-address-get*** command that returns the specified global address resource. Required permission: compute.globalAddresses.get.
- Added the ***gcp-compute-global-address-list*** command that retrieves the list of global address resources. Required permission: compute.globalAddresses.list.
- Added the ***gcp-compute-global-address-insert*** command that creates a global address resource in the specified project. Required permission: compute.globalAddresses.create.
- Added the ***gcp-compute-global-address-delete*** command that deletes the specified global address resource. Required permission: compute.globalAddresses.delete.
