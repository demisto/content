
#### Integrations

##### Google Cloud Platform

- Added the ***gcp-compute-zone-operation-wait*** command that polls a zonal Compute Engine operation until it reaches the DONE status. Required permission: compute.zoneOperations.get.
- Added the ***gcp-compute-region-operation-wait*** command that polls a regional Compute Engine operation until it reaches the DONE status. Required permission: compute.regionOperations.get.
- Added the ***gcp-compute-global-operation-wait*** command that polls a global Compute Engine operation until it reaches the DONE status. Required permission: compute.globalOperations.get.
