
#### Integrations

##### OpenCTI Feed 4.X

- Fixed an issue where the ***fetch-indicators*** command stopped retrieving new indicators after several fetch cycles. Indicators are now retrieved in a deterministic order (by creation time).
- Improved implementation of error handling. When OpenCTI returns an error (for example, *DATABASE_ERROR: Fail to execute engine pagination*), the command now fails with a detailed error message that includes the stored pagination cursor and the remediation steps.
