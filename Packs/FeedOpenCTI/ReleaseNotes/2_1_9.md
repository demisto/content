
#### Integrations

##### OpenCTI Feed 4.X

- Fixed an issue where the ***fetch-indicators*** command stopped retrieving new indicators after several fetch cycles. Indicators are now retrieved in a deterministic order (by last update time), so indicators that are updated in OpenCTI after they are created (for example, scored by an enrichment connector) are retrieved again with their latest values, as long as they still match the configured filters. After updating, the first fetches retrieve all indicators again from the beginning (existing indicators are updated, not duplicated).
- Improved implementation of error handling. When OpenCTI returns an error (for example, *DATABASE_ERROR: Fail to execute engine pagination*), the command now fails with a detailed error message that includes the stored pagination cursor and the remediation steps.
- Organized the integration configuration parameters into the *Connect* and *Collect* sections.
- Updated the Docker image to: *demisto/vendors-sdk:1.0.0.14788468*.
