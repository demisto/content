
#### Scripts

##### JiraCreateIssue-example

- Fixed an issue where custom field values containing non-ASCII characters (e.g. Korean, Japanese), spaces, hyphens, or other special characters were silently dropped when using the `customFields` argument.
- Added validation: when `customFields` is used, providing additional named arguments (e.g. `summary`, `projectKey`) alongside it now raises a clear error. All required fields must be included in the `customFields` comma-separated list (e.g. `summary=My Issue,projectKey=PROJ,issueTypeName=Task,customfield_10214=value`).
