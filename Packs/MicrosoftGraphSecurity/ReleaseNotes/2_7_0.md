#### Integrations

##### Microsoft Graph Security

<~XSOAR>
- Added support for incoming and outgoing mirroring of alerts and incidents, including comments.
- Added the following parameters: **Incident Mirroring Direction**, **Close Mirrored XSOAR Incident**, **Close Mirrored Microsoft Alert/Incident**, **Comment Entry Tag (to Microsoft)** and **Comment Entry Tag (from Microsoft)**.
</~XSOAR>
- Removed the deprecated **Germany** option from the **Azure Cloud** parameter.

#### Incident Fields

- New: **Microsoft Graph Security Alert Status**
- New: **Microsoft Graph Security Incident Status**
- New: **Microsoft Graph Security Classification**
- New: **Microsoft Graph Security Incident Tags**
- New: **Microsoft Graph Incident Id**

#### Mappers

##### New: Graph Security Mapper - Incoming

- New: Maps Microsoft Graph Security alerts and incidents, including comments and the mirroring fields, to Cortex XSOAR incidents. <~XSOAR>(Available from Cortex XSOAR 6.10.0).</~XSOAR>

##### New: Graph Security Mapper - Outgoing

- New: Maps Cortex XSOAR incident fields to Microsoft Graph Security alerts and incidents for outgoing mirroring. <~XSOAR>(Available from Cortex XSOAR 6.10.0).</~XSOAR>

#### Classifiers

##### New: Graph Security Classifier

- New: Sets the incident type to **Graph Security Alert** or **Graph Security Incident**. <~XSOAR>(Available from Cortex XSOAR 6.10.0).</~XSOAR>
