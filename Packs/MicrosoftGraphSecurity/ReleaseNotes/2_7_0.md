#### Integrations

##### Microsoft Graph Security

- Added support for incident and alert mirroring: incoming, outgoing, or both.
- Added the *Incident Mirroring Direction*, *Close Mirrored XSOAR Incident*, *Close Mirrored Microsoft Alert/Incident*, *Comment Entry Tag (to Microsoft)* and *Comment Entry Tag (from Microsoft)* parameters.
- Added the ***get-remote-data***, ***get-modified-remote-data***, ***update-remote-system*** and ***get-mapping-fields*** commands.
- Added mirroring of the alert *customDetails* in and out with the **Additional Data** field (`key: value` items).
- When *Close Mirrored XSOAR Incident* is enabled, incoming mirroring closes the Cortex XSOAR incident only if it is still open, and reopens it only if it is closed. Other updates, such as comments, no longer add a reopen entry to an incident that is already open.
- A Microsoft incident that is redirected (merged into another incident) closes the mirrored Cortex XSOAR incident as **Duplicate**, with the target incident ID in the close notes.
- When *Close Mirrored Microsoft Alert/Incident* is enabled, closing in Cortex XSOAR sends only the `resolved` status and a close comment with the close reason and the close notes. The classification is sent only when the **Microsoft Graph Security Classification** field is changed.
- The assigned user (*assignedTo*) is mirrored in only and is never sent to Microsoft.
- Added a validation to the **Test** button that fails when the *Comment Entry Tag (to Microsoft)* and *Comment Entry Tag (from Microsoft)* parameters have the same value.
- Removed the *Germany* option from the *Azure Cloud* parameter, as Microsoft Cloud Germany was closed in October 2021.

#### Incident Fields

- New: **Microsoft Graph Security Alert Status**
- New: **Microsoft Graph Security Incident Status**
- New: **Microsoft Graph Security Classification**
- New: **Microsoft Graph Security Incident Tags**
- New: **Microsoft Graph Incident Id**

#### Mappers

##### New: Graph Security Mapper - Incoming

- Added an incoming mapper for Microsoft Graph Security alerts and incidents, including the mirroring fields. It is the default incoming mapper of the integration.
- The Microsoft description is mapped to the **Description** field.
- The Microsoft classification and determination are mapped together to the **Microsoft Graph Security Classification** field.
- Comments are mirrored as War Room notes, not mapped to a field.
- The existing **Graph Security Alert** incoming mapper is unchanged.

##### New: Graph Security Mapper - Outgoing

- Added an outgoing mapper for mirroring Microsoft Graph Security alerts and incidents.

#### Classifiers

##### New: Graph Security Classifier

- Added a classifier that sets the incident type of fetched records to **Graph Security Alert** or **Graph Security Incident**.
