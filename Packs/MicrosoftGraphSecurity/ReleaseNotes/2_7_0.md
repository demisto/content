#### Integrations

##### Microsoft Graph Security

- Added support for incoming and outgoing mirroring of alerts and incidents.
- Added the following parameters: *Incident Mirroring Direction*, *Close Mirrored XSOAR Incident*, *Close Mirrored Microsoft Alert/Incident*, *Comment Entry Tag (to Microsoft)* and *Comment Entry Tag (from Microsoft)*.
- Added the ***get-remote-data***, ***get-modified-remote-data***, ***update-remote-system*** and ***get-mapping-fields*** commands.
- Removed the *Germany* option from the *Azure Cloud* parameter. Microsoft Cloud Germany was closed in October 2021.

#### Incident Fields

- New: **Microsoft Graph Security Alert Status**
- New: **Microsoft Graph Security Incident Status**
- New: **Microsoft Graph Security Classification**
- New: **Microsoft Graph Security Incident Tags**
- New: **Microsoft Graph Incident Id**

#### Mappers

##### New: Graph Security Mapper - Incoming

- New: Maps Microsoft Graph Security alerts and incidents to Cortex XSOAR incidents, including the mirroring fields.
- New: Maps the alert comments to the **Microsoft Graph Security Comment** field, which is refreshed on every incoming mirror sync.

##### New: Graph Security Mapper - Outgoing

- New: Maps Cortex XSOAR incident fields to Microsoft Graph Security alerts and incidents for outgoing mirroring.

#### Classifiers

##### New: Graph Security Classifier

- New: Sets the incident type to **Graph Security Alert** or **Graph Security Incident**.
