
#### Modeling Rules

##### Microsoft Graph Security Modeling Rules

- Fixed an issue where `xdm.source.host.device_id` was mapped to the `tenantId` field, which holds the Microsoft Entra tenant ID and is identical for every alert. It is now mapped to the `mdeDeviceId` field of the `deviceEvidence` object, falling back to `azureAdDeviceId`.
- Updated the modeling rule to map `xdm.source.host.hostname` to the `hostName` field of the `deviceEvidence` object, falling back to `deviceDnsName`.
