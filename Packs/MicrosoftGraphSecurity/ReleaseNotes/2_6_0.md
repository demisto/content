
#### Integrations

##### Microsoft Graph Security

- Added support for fetching **Incidents** in addition to **Alerts**, controlled by the new **Fetch incidents type** parameter (default: Alerts). Fetched incidents include their related alerts as raw data.
- Added the **Fetched Incidents filter** parameter for filtering fetched incidents, and renamed the display of the existing filter to **Fetched Alerts filter**.
- Fixed the *odata* argument of the ***msg-list-security-incident*** command so it is passed as a raw OData `$filter` expression.
