
#### Integrations

##### Microsoft Graph Security

- Added support for the **Fetch incidents type** parameter to fetch incidents in addition to alerts. Fetched incidents include their related alerts as raw data.
- Added the **Incidents Filter** parameter to filter fetched incidents, and renamed the existing filter display name to **Alerts Filter**.
- Renamed the **Max incidents per fetch** parameter display name to **Fetch limit per type**, as it now applies to both alerts and incidents. The default value was updated to 50.
- Added the *extra_data* argument to the ***msg-list-security-incident*** command. When set to true, each incident includes its related alerts.
- Fixed an issue where the *odata* argument of the ***msg-list-security-incident*** command was not passed as a raw OData `$filter` expression.

#### Incident Types

##### Graph Security Incident

- Added the **Graph Security Incident** incident type for classifying fetched incidents.
