
#### Integrations

##### Microsoft Graph Security

- Added support for the **Fetch incidents type** parameter to fetch incidents in addition to alerts. Fetched incidents include their related alerts as raw data.
- Added the **Fetched Incidents filter** parameter to filter fetched incidents, and renamed the existing filter display name to **Fetched Alerts filter**.
- Fixed an issue where the *odata* argument of the ***msg-list-security-incident*** command was not passed as a raw OData `$filter` expression.
