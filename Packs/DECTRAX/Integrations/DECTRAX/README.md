# DECTRAX Integration

Connect Cortex XSOAR with DECTRAX Autonomous Cyber Deception platform.

## Commands
### `!dectrax-get-blocked-ips`
Returns list of current IP addresses on the active EDL firewall interdiction feed.

### `!dectrax-check-ip`
Queries whether an IP has touched synthetic decoys across the deception grid.

### `!dectrax-block-ip`
Instructs DECTRAX to append an IP address to the perimeter firewall drop list immediately.
