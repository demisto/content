# DECTRAX Cyber Deception Pack for Cortex XSOAR

Empowers Security Operations Center (SOC) and Incident Response teams to ingest high-fidelity deception indicators and automatically trigger line-rate firewall drops in <1.5 seconds.

## Key Features
- **Zero False-Positive Deception Triggers**: Decoys emulate Active Directory LDAP, Windows RDP, SMB, Modbus SCADA, and SSH services.
- **Line-Rate Firewall Interdiction**: Polling and injecting malicious IPs directly into DECTRAX live External Dynamic List (EDL) feed.
- **Automated Playbook Integration**: Automatically check suspicious IPs during phishing or malware triage to see if the host also engaged in internal reconnaissance.
