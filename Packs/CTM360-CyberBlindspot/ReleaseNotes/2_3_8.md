
#### Integrations

##### CTM360 CyberBlindspot

- Fetch Incidents now follows the API search_after cursor when the server returns one, so records that share a timestamp are not skipped.
- Incoming mirroring pages modified incidents with its own cursor, separate from the fetch cursor.
- Added the **Severities to Fetch** parameter so Incidents fetch can be limited to selected severities.

##### CTM360 HackerView

- Fetch Incidents now follows the API search_after cursor for Light Scan and Deep Scan when the server returns one.
- Incoming mirroring pages modified issues with its own cursor, separate from the fetch cursor.
- Added the **Severities to Fetch** parameter so Light Scan and Deep Scan fetches can be limited to selected severities.
