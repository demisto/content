#### Integrations

##### CTM360 CyberBlindspot

- Fixed an issue where incidents sharing a timestamp were skipped during fetch. The integration now follows the API *search_after* cursor when the server returns one.
- Improved implementation of incoming mirroring to page modified incidents with its own cursor, separate from the fetch cursor.
- Added the *Severities to Fetch* parameter so Incidents fetch can be limited to selected severities.
- Updated the Docker image to: *demisto/python3:3.12.15.14069087*.

##### CTM360 HackerView

- Fixed an issue where incidents sharing a timestamp were skipped during fetch. The integration now follows the API *search_after* cursor for Light Scan and Deep Scan when the server returns one.
- Improved implementation of incoming mirroring to page modified issues with its own cursor, separate from the fetch cursor.
- Added the *Severities to Fetch* parameter so Light Scan and Deep Scan fetches can be limited to selected severities.
- Updated the Docker image to: *demisto/python3:3.12.15.14069087*.
