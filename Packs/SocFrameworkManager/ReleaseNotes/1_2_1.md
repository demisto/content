
#### Integrations

##### SOC Framework Pack Manager

- Fixed **socfw-install-pack** installing a pack's version record without its content. The direct ZIP upload introduced in 1.2.0 was made the default; it registers the pack on the tenant and installs none of its scripts, lists, playbooks or fields. Verified against a live tenant: the same pack ZIP through the direct path set the version and left all 24 of its scripts and lists missing, while the demisto-sdk path installed all 24. The demisto-sdk path is the default again. The **use_sdk** argument still selects between them, but its default is now **true**, and setting it false is a deliberate choice to register a pack without its content rather than a faster install.
