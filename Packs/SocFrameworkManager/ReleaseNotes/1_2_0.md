
#### Integrations

##### SOC Framework Pack Manager

- Added the *use_sdk* argument to ***socfw-install-pack*** to select between the demisto-sdk install path (default, installs the pack's content items) and a direct ZIP upload.
- Fixed an issue where ***socfw-install-pack*** reported success for an upload that did not take. The command now verifies the installed version against the ZIP filename and errors when they disagree.
- Fixed an issue where ***socfw-install-pack*** defaulted to the direct ZIP upload, which registered the pack version without its content. The *use_sdk* default is now *true*.
- Updated the Docker image to: *demisto/demisto-sdk:1.39.10.13226002*.

#### Scripts

##### SOCFWPackManager

- Fixed an issue where **SOCFWPackManager** reported success when a pack failed to upgrade. The check now compares the installed version against the release filename and reports the version it landed at.
- Updated the Docker image to: *demisto/python3:3.12.14.13053055*.
