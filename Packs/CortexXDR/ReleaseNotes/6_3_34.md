
#### Integrations

##### Cortex XDR - IR

- Fixed an issue where the ***xdr-case-list*** command returned the nested issue identifier as **alert_id** instead of the documented **PaloAltoNetworksXDR.Case.Issues.issue_id**, and documented the full set of **PaloAltoNetworksXDR.Case.Issues.*** outputs it returns.
- Fixed an issue where the ***xdr-case-list*** command with *extra_data=true* did not return the documented **PaloAltoNetworksXDR.Case.Issues.host_ip_list** output.

#### Playbooks

##### Cortex XDR Incident Handling v3

- Replaced the deprecated ***xdr-get-incident-extra-data*** command with ***xdr-case-list*** using *extra_data=true*.
- Updated all context paths from **PaloAltoNetworksXDR.Incident** to **PaloAltoNetworksXDR.Case**.

##### Cortex XDR Alerts Handling v2

- Replaced the deprecated ***xdr-get-incident-extra-data*** polling command with ***xdr-case-list*** using *extra_data=true*.
- Updated all context paths from **PaloAltoNetworksXDR.Incident** to **PaloAltoNetworksXDR.Case**.
- **Breaking Change**: Following the replacement of the deprecated ***xdr-get-incident-extra-data*** command with ***xdr-case-list***, the data is now written to **PaloAltoNetworksXDR.Case** instead of **PaloAltoNetworksXDR.Incident**. As a result, the default values of the *incident_id* and *alert_id* playbook inputs were updated accordingly: *incident_id* now defaults to **PaloAltoNetworksXDR.Case.case_id** instead of **PaloAltoNetworksXDR.Incident.incident_id**, and *alert_id* now defaults to **PaloAltoNetworksXDR.Case.Issues.issue_id** instead of **PaloAltoNetworksXDR.Incident.alerts.alert_id**. The input names are unchanged. Custom parent playbooks that run this playbook as a sub-playbook and pass these inputs explicitly must be updated to the new context paths.
