#### Integrations

##### Recorded Future Alerts

- Added new alert types to the *Playbook Alerts: Categories to fetch* parameter and the ***rf-alerts*** command's *playbook_alert_categories* argument.

#### Classifiers

##### RF - Classifier

- Added support for new Recorded Future alert types.
- *code_repo_leakage* alerts are now classified as **RF Code Repository** instead of **RF Data Leakage on Code Repo Playbook Alert**.

#### Mappers

##### RF - Incoming Mapper

- Added mappings for new Recorded Future alert types.

#### Incident Types

Added incident types:
- RF Code Repository
- RF Dark Web Brand
- RF Identity Exposure
- RF Social Media Impersonation
- RF Malicious Sites

Renamed incident types:
- Renamed the display name of **RF Vulnerability Playbook Alert** to **RF Vulnerability**. The incident type ID is unchanged.
- Renamed the display name of **RF Domain Abuse Playbook Alert** to **RF Domain Abuse**. The incident type ID is unchanged.
- Renamed the display name of **RF Facility Risk Playbook Alert** to **RF Facility Risk**. The incident type ID is unchanged.
- Renamed the display name of **RF Third-Party Cyber Playbook Alert** to **RF Third-Party Cyber**. The incident type ID is unchanged.

Deprecated incident types:
- Deprecated the **RF Data Leakage on Code Repo Playbook Alert** incident type. Use **RF Code Repository** instead.
