## Cisco Webex Teams v2

Authenticate with a Webex access token:

- **Bot access token (recommended)**: Create a bot at [developer.webex.com](https://developer.webex.com/my-apps/new/bot). Bot tokens do not expire and are not tied to an individual user.
- **Personal access token**: Available from [developer.webex.com](https://developer.webex.com/docs/getting-started). These tokens are short-lived and should be used for non-production testing only.

The default Server URL, `https://webexapis.com`, works for all commercial Webex organizations. Change it only for Webex for Government or a custom API gateway.

When this integration is configured from the Cisco Webex connector, these settings are managed by the connector.
