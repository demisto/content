# Cisco Webex

This pack backs the **Cisco Webex** unified connector. It contains:

- **Cisco Webex Event Collector v2** - collects Webex admin audit, security audit and compliance officer events using a single OAuth 2.0 integration app. Events are stored in the `cisco_webex_v2_raw` dataset.
- **Cisco Webex Teams v2** - sends messages and manages people, rooms, teams, memberships and webhooks using a Webex bot (or personal) access token.
- **Cisco Webex Feed v2** - ingests the public Webex service domains and IP ranges as indicators.

Configure these integrations from the Cisco Webex connector page.
