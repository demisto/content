
#### Integrations

##### Anthropic Claude (Standard Connector)

- Added all Anthropic Claude commands to the standard connector integration. Previously, only the two delete commands were available. The integration now covers the Compliance API directory, chat, project, and delete commands, and the Claude model commands.
- Added the **Log Collection** capability. The integration collects Activity Feed events into the *anthropic_claude_raw* dataset.
- Added support for the Messages API key and the Compliance Access Key as separate connector profiles. Each command authenticates with the key its capability requires.
- Updated the default value of the *Model* parameter to *claude-haiku-4-5*, and removed retired Claude 3.x models from its options.
