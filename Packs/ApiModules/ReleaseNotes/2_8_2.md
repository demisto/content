
#### Scripts

##### AggregatedCommandApiModule

- Added Unified Connector authentication for the Messages API and Compliance API clients. Each client selects its connector profile by capability and sends the key in the *x-api-key* header.
- Added support for an optional *first_fetch* parameter that sets the start time of the first event fetch.
- Fixed an issue where the connection test failed when the *max_tokens* parameter was empty.
