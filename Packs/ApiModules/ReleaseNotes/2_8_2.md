
#### Scripts

##### COOCApiModule

- Added the `validate_command_is_allowed` function to support connectors restricted to the CSPM remediation permission set. Attempting to run commands outside of this permission scope will now return a clear error message.
- Updated the health check results to include the `capability` field. The capability is `AUTOMATION` or `CSPM_remediation`, depending on the permission set granted to the account.
