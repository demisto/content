
#### Scripts

##### New: SlackEventCollectorApiModule

- New: Added the SlackEventCollectorApiModule, which holds the shared Slack audit logs collection logic.

##### New: SlackIAMApiModule

- New: Added the SlackIAMApiModule, which holds the shared Slack SCIM (IAM) logic, and the ***slack-user-session-reset*** command used by the Slack IAM (Standard Connector) integration.

##### New: SlackV3ApiModule

- New: Added the SlackV3ApiModule, which holds the shared Slack v3 logic, including reading the Slack tokens from the ConnectUs credentials. Unset *Types of Notifications to Send* and *Enable Incident Mirroring* values are now handled: no extra notification types are sent, and mirroring stays enabled.
