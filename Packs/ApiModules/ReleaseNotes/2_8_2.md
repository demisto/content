
#### Scripts

##### COOCApiModule

- Added the `validate_command_is_allowed` function to support connectors restricted to the CSPM remediation permission set. Attempting to run commands outside of this permission scope will now return a clear error message.
- Added the `get_is_all_commands_allowed` function, which determines whether a connector is restricted to the CSPM remediation permission set based on the capabilities selected for the connector.
- Updated the health check results to include the `capability` field. The capability is `AUTOMATION` or `CSPM_remediation`, depending on the permission set granted to the account.
- Updated the health check to return a `SUCCESS` classification entry when no issues are found, and to include the name of the missing permission in permission error (`WARNING`) entries.
