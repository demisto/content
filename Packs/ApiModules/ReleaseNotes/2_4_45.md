
#### Scripts

##### New: MicrosoftGraphTeamsApiModule

- Added a new API module extracted from the community **O365 Teams (Using Graph API)** integration. Exposes `run_microsoft_graph_teams_integration()` as the shared entrypoint plus the `MsGraphClient` class, so the community `MicrosoftGraphTeams` pack and the new xsoar-supported `MicrosoftGraphTeamsStandardConnector` satellite pack can share one code base. Adds the `msgraph-teams-message-update-policy-violation` command (Microsoft Graph DLP policy-violation remediation for Teams messages) to the shared surface.
