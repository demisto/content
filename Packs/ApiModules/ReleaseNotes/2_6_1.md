
#### Scripts

##### MCPApiModule

- Fixed an issue where the **list-tools** command returned tool schemas that the platform could not read when a property type was a list such as ["string", "null"], or when an output property had no description. As a result, some MCP tools were not created as actions.
- A type list that names one real type, such as ["string", "null"], now becomes that type. A list that names several, such as ["string", "number"], now loses its type, which the platform shows as unknown. An output property without a description now uses its title or its name.
