##### CertificateManagerSaaSApiModule

Added the **CertificateManagerSaaSApiModule** script, the shared code of the CyberArk Certificate Manager SaaS and Next-Gen Trust Security integrations: the API client, certificate search and enrichment, machine lookups, revocation, certificate requests, certificate and keystore downloads, the expiry and revocation-failure fetch, and the ***certificate*** reputation command.
