
#### Scripts

##### MicrosoftGraphTeamsApiModule

- Fixed an issue where **test-module** failed with `Requested API is not supported in application-only context` when the integration ran under the Unified Connector Platform (UCP). The connectivity check now targets an application-permission compatible resource when UCP injects an app-only token, and continues to use the delegated resource otherwise.
- Fixed an issue where **test-module** was reported as failed even after the connectivity check succeeded, because the returned entry did not match the expected result payload.
