
#### Scripts

##### MCPApiModule

- Aligned the module with the MCP 2026-07-28 specification.
- MCP sessions now negotiate the stateless per-request protocol introduced in MCP 2026-07-28 (SEP-2575, SEP-2567), falling back to the *initialize* handshake for servers that do not support it.
- Added the **application_type** field to OAuth Dynamic Client Registration requests (SEP-837), derived from the redirect URI so that loopback redirects register as *native* and public HTTPS redirects as *web*.
- Updated the protocol version declared on OAuth discovery requests to *2026-07-28*.
- Added validation of the **state** parameter on the authorization response (CSRF protection). Previously the value was generated and sent but never verified.
- Added validation of the **iss** parameter on the authorization response (RFC 9207 / SEP-2468), protecting against authorization server mix-up attacks.
- Added validation that the authorization server metadata **issuer** matches the URL it was discovered from (RFC 8414).
- Fixed an issue where the **state** parameter was discarded in the OAuth 2.0 Authorization Code flow, which left it unverifiable.
- The **Authorization code** parameter now accepts the full redirect URL in addition to a bare authorization code. Pasting the full URL enables the **state** and **iss** verifications. Support for pasting only the authorization code is deprecated and will be removed in a future version.
