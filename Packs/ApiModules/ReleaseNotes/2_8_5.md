
#### Scripts

##### MCPApiModule

- Fixed an issue where OAuth Dynamic Client Registration failed for MCP servers whose authorization server has a path in its issuer (for example, Glean). OAuth metadata discovery now tries the RFC 8414 path-inserted URL first, then the legacy URL, and validates the issuer against the discovered base URL.
- Changed the Dynamic Client Registration `scope` to an empty string, as a list is rejected by some authorization servers.
