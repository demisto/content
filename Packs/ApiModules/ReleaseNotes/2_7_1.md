
#### Scripts

##### NGINXApiModule

- Added shared helpers that check whether the long-running ports are already in use and whether an already-running instance is healthy, so that the **Test** button reports success for a running healthy instance instead of failing with an `Address in use` error.
- Added an instance identity check so that the **Test** button fails with a clear error when the Listen Port is used by a different integration instance.
- Fixed an issue where the running-instance health check failed when the app route took longer than 10 seconds to respond. A connection that the app accepts but does not answer in time is now treated as healthy.
