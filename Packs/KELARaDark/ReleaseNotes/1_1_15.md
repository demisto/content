##### RaDark (Deprecated)

- Deprecated. Use the KELA Monitor integration instead.
- Deprecated the ***radark-incident-get-items***, ***radark-email-enrich***, ***radark-item-handle*** and ***radark-item-purchase*** commands. No available replacement.
- Fixed an issue where the API key could appear in error messages and logs when a request failed, including in debug mode.
- Fixed an issue where item and incident IDs were not encoded in the request path.
- Added the *Mask passwords* parameter (selected by default). Passwords are now masked in the War Room tables and context of ***radark-email-enrich*** and ***radark-incident-get-items***.
