
#### Integrations

##### NetBox Event Collector

- Fixed an issue where fetching events failed with a *404 - Not Found* error on NetBox v4.1 and above, which moved the object changes API endpoint from `/api/extras/object-changes/` to `/api/core/object-changes/`.
- Added the **NetBox Version** parameter to select the version of the NetBox server. Default is *v4.1 and above*. If your NetBox server is older than v4.1, set this parameter to *Below v4.1*.
- Improved the ***test-module*** command to check all the event types.
- Improved implementation of error messages and debug logs.
