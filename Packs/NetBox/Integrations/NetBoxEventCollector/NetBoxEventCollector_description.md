Use this integration to collect events automatically from NetBox.
You can also use the ***netbox-get-events*** command to manually collect events.

## NetBox Version
Select the version of your NetBox server in the ***NetBox Version*** parameter. NetBox v4.1 moved the object changes API endpoint from `/api/extras/object-changes/` to `/api/core/object-changes/`.

## API Key
To get the API key, go to the NetBox web interface, click on the user icon in the top right corner, and select ***API Tokens***, then click ***Add a Token***.
