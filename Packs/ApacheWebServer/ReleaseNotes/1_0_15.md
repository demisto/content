
#### Modeling Rules

##### Apache Web Server

- Limited the Apache Web Server modeling rule to Cortex XSIAM 2.10 and below. Mappings for Cortex XSIAM 2.11 and later are now handled in a new version of the modeling rule.

##### New: Apache Web Server Modeling Rule

- New: Added a new modeling rule version that maps the `xdm.*.identity.*` fields alongside the existing `xdm.*.user.*` fields.
