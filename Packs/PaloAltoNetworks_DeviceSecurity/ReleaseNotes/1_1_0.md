#### Integrations

##### Palo Alto Networks Device Security

- Fixed an issue where repeated vulnerability fetch cycles could create duplicate incidents and fail to progress through vulnerability results.
- Added support for resumable vulnerability pagination. The integration continues across short or empty intermediate pages and commits the fetch timestamp after it completes the scan, without depending on the API sort order.
- Updated the vulnerability deduplication to retain IDs throughout the scan and at the fetch timestamp without trimming them. The integration excludes records detected before the scan start time.
- Fixed an issue with detection date handling. The integration now uses the earliest valid date in list-valued responses, regardless of list order or timestamp format.
- Added support for validation and migration of vulnerability fetch checkpoints, validation of API page responses, and debug logging for fetch progress.
- Updated the SCM authentication to refresh cached tokens when the authentication URL changes and to report missing client secrets.
- Updated the Docker image to: *demisto/fastapi:0.142.2.13587997*.
