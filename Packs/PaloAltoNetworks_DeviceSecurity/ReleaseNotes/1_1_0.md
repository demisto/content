#### Integrations

##### Palo Alto Networks Device Security

- Fixed an issue where repeated vulnerability fetch cycles could create duplicate incidents and fail to progress through vulnerability results.
- Added resumable vulnerability pagination that continues across short or empty intermediate pages and commits the fetch timestamp after completing the scan, without depending on API sort order.
- Updated vulnerability deduplication to retain IDs throughout the scan and at the fetch timestamp without trimming them. Records detected before the scan start time are excluded.
- Fixed detection date handling to use the earliest valid date in list-valued responses, regardless of list order or timestamp format.
- Added validation and migration for vulnerability fetch checkpoints, validation of API page responses and debug logging for fetch progress.
- Updated SCM authentication to refresh cached tokens when the authentication URL changes and report missing client secrets.
- Updated the Docker image to: *demisto/fastapi:0.142.2.13587997*.
