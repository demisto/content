Displays the current vulnerability incident's **Reason History** JSON field as a Markdown table in the **Detection & Resolution History** layout section.

The table includes timestamp, action, evidence type, user email, resolution and reopen types, system event, reason, and evidence. Empty history displays an informational message. Invalid JSON or a history value other than an object or list of objects returns an error.

This script runs in the incident context and has no arguments or context outputs.
