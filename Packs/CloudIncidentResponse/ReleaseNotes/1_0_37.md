
#### Playbooks

##### Cortex XDR - Cloud Data Exfiltration Response

- Fixed an issue where the *username* input resolved to an empty value, by updating the context paths from **PaloAltoNetworksXDR.Incident.alerts.user_name** to **PaloAltoNetworksXDR.Case.Issues.user_name**, to match the output of the ***xdr-case-list*** command that replaced the deprecated ***xdr-get-incident-extra-data*** command in the calling playbook.
- **Breaking Change**: Following the replacement of the deprecated ***xdr-get-incident-extra-data*** command with ***xdr-case-list*** in the calling playbook, the *username* and *Username* task inputs now read from **PaloAltoNetworksXDR.Case.Issues.user_name** instead of **PaloAltoNetworksXDR.Incident.alerts.user_name**. Custom playbooks or automations that rely on the previous **PaloAltoNetworksXDR.Incident.alerts.user_name** context path must be updated to the new context path.
