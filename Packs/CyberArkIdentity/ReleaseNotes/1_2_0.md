
#### Integrations

##### CyberArk Identity Event Collector

- Fixed an issue where fetching events could fall behind and stop during periods of high event volume.
- Fixed an issue where events that occurred in the same millisecond could be skipped or duplicated.
- Updated the *Maximum number of events per fetch* parameter to apply across multiple pages. The default is now 5000.
- Updated the default *limit* of the ***cyberarkidentity-get-events*** command to 50.
- Added the *to* argument to the ***cyberarkidentity-get-events*** command.
- Updated the Docker image to: *demisto/py3-tools:1.0.0.13712671*.
