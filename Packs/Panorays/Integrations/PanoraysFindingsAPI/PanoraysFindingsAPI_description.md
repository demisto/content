## How to get your Panorays API Key

1. Log in to your Panorays platform.
2. Navigate to **Settings → Integrations → Public API**.
3. Click **Generate API Key** and assign it a role.
4. Copy the token.

This integration only reads data (company findings, supplier findings, and the supplier list) - it never creates,
updates, or deletes anything in Panorays. The read-only **Observer** role is sufficient for both **Company
Findings** and **Supplier Findings** scopes, including reading across your entire supplier portfolio.

For full instructions, see the [Panorays Public API documentation](https://support.panoraysapp.com/en/articles/520347-panorays-public-api).
