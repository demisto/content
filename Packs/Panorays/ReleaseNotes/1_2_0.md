#### Integrations

##### Panorays Findings API

- Added support for ingesting findings from across your supplier (third-party) portfolio, so that critical supply chain findings raise incidents in Cortex XSOAR.
- Added the **Findings scope** parameter, which selects whether an instance fetches your own organization's findings or your suppliers' findings. Configure a separate instance for each scope.
- Added the **Supplier finding severities** parameter (default **CRITICAL**), which controls the severities that create incidents when fetching supplier findings.
- Added the **Supplier finding statuses** parameter (default **OPEN,REOPENED**), which excludes remediated (DONE) findings while still covering findings that were reopened.
- Added the **Date field to fetch by**, **Supplier segment IDs**, and **Supplier tags** parameters for narrowing which supplier findings are ingested.
- Added the **Supplier list cache TTL (hours)** parameter, which controls how often the supplier portfolio is re-enumerated.
- Added the **Maximum API requests per minute** parameter (default **120**) and client-side throttling, so that fetching across a large portfolio cannot exceed the Panorays rate limit of 150 requests per minute, which blocks the caller for one hour.
- Fetching supplier findings now stops immediately when the Panorays rate limit is reached, instead of continuing to poll the remaining suppliers while blocked. The cursor is preserved, so the pass resumes from the same supplier once the block expires.
- Fixed an issue where list commands and fetches only returned the first page of results. The Panorays API is cursor paginated, but the integration sent an unsupported `page` parameter, which the API ignored.
- Added the **severity**, **status**, and **asset_name** arguments to the ***panorays-finding-list*** command.
- Deprecated the **page** argument of the ***panorays-finding-list*** command. The Panorays API uses cursor pagination, so the argument was never applied.
- Added the ***panorays-supplier-list*** command, which lists the suppliers in your Panorays portfolio.
- Added the ***panorays-supplier-finding-list*** command, which lists the findings detected for a specific supplier.
- Changed the default **Incidents Fetch Interval** to 15 minutes, which suits fetching across a supplier portfolio. This only applies to newly created instances; existing instances keep their configured interval.
- When fetching supplier findings, a run that reaches **Maximum number of incidents to fetch per run** part-way through a supplier resumes on that same supplier, so the limit is honored and no findings are skipped.
- Updated the Docker image to: *demisto/python3:3.12.14.13495286*.

#### Playbooks

##### Panorays Finding - Triage and Response

- Added an ***IsIntegrationAvailable*** check as the first step, so the incident is routed to a manual review task instead of being auto-closed or handed to a remediation task when the Panorays Findings API instance is disabled or unreachable.
- Added `INFO` as a match for the Low/Informational auto-close branch, alongside the existing `Informational` match, since the Panorays API returns upper-case severity values.
- Clarified that the Critical/High notification task uses the generic ***send-notification*** command, which is implemented by chat integrations (Slack, Slack v3, Microsoft Teams, Mattermost, and others) and does not cover email-only integrations such as Gmail or EWS, which implement ***send-mail*** instead.

#### Incident Fields

##### New: Panorays Supplier Business Impact

The business impact level assigned to the supplier in Panorays, as a numeric value.

##### New: Panorays Supplier Combined Score

The combined Panorays risk score of the supplier.

##### New: Panorays Supplier Domain

The primary domain of the supplier the finding belongs to.

##### New: Panorays Supplier ID

The Panorays identifier of the supplier the finding belongs to.

##### New: Panorays Supplier Name

The name of the supplier (third party) the finding belongs to.

##### New: Panorays Supplier Posture Score

The external posture score of the supplier as calculated by Panorays.

##### New: Panorays Supplier Risk

The overall risk level of the supplier in Panorays, as a numeric value.

##### New: Panorays Supplier Tags

The tags assigned to the supplier in Panorays, as a comma-separated list.
