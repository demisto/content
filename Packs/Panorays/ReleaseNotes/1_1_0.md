#### Scripts

##### New: PanoraysCheckOlderDuplicate

Added a new script that checks whether an older open/pending **Panorays Finding** incident already exists for the same Finding ID, returning a single explicit boolean output for use in playbook conditions.

#### Playbooks

##### New: Panorays Finding - Triage and Response

Added a new playbook that automates triage of Panorays Finding incidents based on severity: low/informational findings are auto-closed (close reason and notes configurable via playbook inputs), medium findings are routed to an analyst review task, and critical/high findings trigger an optional notification and a native remediation task with an SLA. Any unrecognized or empty severity value is routed to a manual review task instead of being auto-closed. Includes duplicate-finding detection, via the new **PanoraysCheckOlderDuplicate** script, that only closes the newer of two incidents for the same finding, avoiding a race between near-simultaneous duplicates. All branches converge on a final Done task, and finding summaries are printed to the War Room ahead of each manual task. Remediation is tracked entirely with native Cortex XSOAR tasks; see the pack README for how to extend this with your own ITSM.
