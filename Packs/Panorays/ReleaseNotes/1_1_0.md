#### Playbooks

##### New: Panorays Finding - Triage and Response
- Automates triage of Panorays Finding incidents based on severity: low/informational findings are auto-closed (close reason and notes configurable via playbook inputs), medium findings are routed to an analyst review task, and critical/high findings trigger an optional notification and a native remediation task with an SLA. Any unrecognized or empty severity value is routed to a manual review task instead of being auto-closed. Includes duplicate-finding detection with a quoted query to avoid false matches on free-form finding IDs. Remediation is tracked entirely with native Cortex XSOAR tasks; see the pack README for how to extend this with your own ITSM.
