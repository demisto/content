#### Incident Types

##### New: Health Check and BPA

- New: Added the **Health Check and BPA** incident type for health check and best practice assessment results.

#### Layouts

##### New: HealthCheckIssueLayout

- New: Added the **HealthCheckIssueLayout** layout to display health check statistics, custom content details, and actionable items.

#### Layout Rules

##### New: HealthCheck issue Layout Rule

- New: Added the **HealthCheck issue Layout Rule** to apply the HealthCheck issue layout to health check issues.

#### Playbooks

##### New: HealthCheck-xsiam

- New: Added the dedicated **HealthCheck-xsiam** playbook for Cortex XSIAM environments, providing automated health assessment and telemetry collection from XSIAM dashboards.

##### HealthCheck-x8

- Added the dedicated **HealthCheck-x8** playbook for Cortex XSOAR v8 environments.

##### HealthCheck

- Updated the primary **HealthCheck** playbook dedicated for Cortex XSOAR v6 environments.

#### Dashboards

##### Health Check - Agent and Asset

- Added support for evaluating endpoint policy assignments, default policy concentration, scan states, auto-upgrade status, and endpoints with disabled EDR protection in Cortex XSIAM.

##### Health Check - Ingestion and Integration

- Added support for tracking identity domain ingestion (CIE), non-reporting domains, playbook task failures, and data feed presets (Authentication, Network, and SaaS Audit).

##### Health Check - Issues and Cases

- Added support for evaluating noisy detection method categories, correlation engine alert ratios, correlation rules lacking automation, and non-prevented issues.

#### Scripts

##### New: HealthCheckBIOCRules

- New: Counts the BIOC rules configured in the tenant.

##### New: HealthCheckCollect

- New: Collects dashboard query results from Cortex XSIAM via the XQL query history and stores them by query source name.

##### New: HealthCheckCollectData

- New: Collects endpoint data from the Cortex XDR API and runs health check analysis queries on it.

##### New: HealthCheckCustomDashboards

- New: Counts the custom dashboards in the tenant.

##### New: HealthCheckCustomFields

- New: Collects statistics about custom fields.

##### New: HealthCheckCustomLayouts

- New: Collects statistics about custom layouts.

##### New: HealthCheckCustomScripts

- New: Collects statistics about custom and detached scripts.

##### New: HealthCheckCustomWidgets

- New: Counts the custom widgets in the tenant.

##### New: HealthCheckDisconnectedEngines

- New: Identifies disconnected engines.

##### New: HealthCheckExportIssueDataXSIAM

- New: Exports issue, context, and widget data in JSON format.

##### New: HealthCheckGetAdminUsers

- New: Retrieves Account Admin and Instance Administrator users and displays them in a table.

##### New: HealthCheckInsightsEndpointManagement

- New: Provides endpoint management insights for the health check.

##### New: HealthCheckOutdatedEngines

- New: Identifies engines running an outdated version.

##### New: HealthCheckParseResults

- New: Evaluates collected query results (`HealthCheck.CollectResults`) and generates prioritized actionable items across the Agent and Asset, Ingestion and Integration, and Issues and Cases dashboards.

##### New: HealthCheckStart

- New: Creates a HealthCheck alert and posts a link to the created alert in the War Room.

#### Triggers

##### New: HealthCheck and BPA

- New: Added a trigger that runs the **HealthCheck** playbook when a Healthcheck Report alert is raised in the Health domain.
