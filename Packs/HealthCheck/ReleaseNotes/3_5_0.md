
#### Playbooks

##### HealthCheck-xsiam

- Added the dedicated **HealthCheck-xsiam** playbook for Cortex XSIAM environments, providing automated health assessment and telemetry collection from XSIAM dashboards.

##### HealthCheck-x8

- Added the dedicated **HealthCheck-x8** playbook for Cortex XSOAR v8 environments.

##### HealthCheck

- Updated the primary **HealthCheck** playbook dedicated for Cortex XSOAR v6 environments.

#### Dashboards

##### Health Check - Agent and Asset

- Added support for evaluating endpoint policy assignments, default policy concentration, scan states, auto-upgrade status, and endpoints with disabled EDR protection in Cortex XSIAM.

##### Health Check - Ingestion and Integration

- Added support for tracking identity domain ingestion (CIE), non-reporting domains, playbook task failures, and data feed presets (Authentication, Network, and SaaS Audit).

##### Health Check - Issues and Cases

- Added support for evaluating noisy detection method categories, correlation engine alert ratios, correlation rules lacking automation, and non-prevented issues.

#### Scripts

##### HealthCheckParseResults

- Added the new **HealthCheckParseResults** script to evaluate collected query results (`HealthCheck.CollectResults`) and generate prioritized actionable items across Agent & Asset, Ingestion & Integration, and Issues & Cases dashboards.

##### HealthCheckCollect

- Added support for automated query collection from Cortex XSIAM dashboards via XQL search history.
