
#### Integrations

##### OpenCTI

- Added support for **opencti-malware-create** command that creates a new malware.
- Added support for **opencti-intrusion-set-create** command that creates a new intrusion set.
- Added support for **opencti-grouping-create** command that creates a new grouping.
- Added support for **opencti-incident-response-create** command that creates a new incident response.
- Added support for **opencti-vulnerability-create** command that creates a new vulnerability.
- Added support for **opencti-add-object-to-container** command that adds an object to a container (report, grouping, case-rft, case-rfi, case-incident).
- Added support for **opencti-campaign-create** command that creates a new campaign.
- Added support for **opencti-report-create** command that creates a new report.
- Added support for **opencti-threat-actor-group-create** command that creates a new threat actor group.
- Added support for the **ip**, **domain**, **email**, **url** and **file** reputation commands. They search the value in the OpenCTI observables and indicators, return the relationships of the observable and the indicator, and calculate the DBot score from the OpenCTI score of the indicator: good up to the suspicious score threshold, suspicious up to the malicious score threshold, malicious above it, unknown when the value is unknown to OpenCTI.
- Added the *Source Reliability*, *Suspicious score threshold*, *Malicious score threshold* and *Create relationships* integration parameters, used by the reputation commands.
- Fixed an issue where the **opencti-observable-field-update** command failed with recent pycti versions.
- Updated the integration description: compatible with OpenCTI 6.9 and later versions (tested with OpenCTI 6.9.0 and 7.261).
- Updated the Docker image to: *demisto/opencti:1.0.0.7499058* for pycti==6.9.0 compatibility.
