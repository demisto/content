#### Integrations

##### OpenCTI

- Added support for the ***opencti-malware-create*** command that creates a new malware.
- Added support for the ***opencti-intrusion-set-create*** command that creates a new intrusion set.
- Added support for the ***opencti-grouping-create*** command that creates a new grouping.
- Added support for the ***opencti-grouping-context-list*** command that lists the grouping contexts.
- Added support for the ***opencti-incident-response-create*** command that creates a new incident response.
- Added support for the ***opencti-incident-response-types-list*** command that lists the incident response types.
- Added support for the ***opencti-vulnerability-create*** command that creates a new vulnerability.
- Added support for the ***opencti-add-object-to-container*** command that adds an object to a container (**report**, **grouping**, **case-rft**, **case-rfi**, **case-incident**).
- Added support for the ***opencti-campaign-create*** command that creates a new campaign.
- Added support for the ***opencti-report-create*** command that creates a new report.
- Added support for the ***opencti-threat-actor-group-create*** command that creates a new threat actor group.
- Added support for the ***ip***, ***domain***, ***email***, ***url*** and ***file*** reputation commands. They search for the value in the OpenCTI observables and indicators, return the relationships of the observable and the indicator, and calculate the DBot score from the OpenCTI score of the indicator. The DBot score is **Good** up to the *Suspicious score threshold*, **Suspicious** up to the *Malicious score threshold*, and **Malicious** above the *Malicious score threshold*. If OpenCTI does not know the value or all its indicators are revoked, the DBot score is **Unknown**.
- The reputation commands run automatically when indicators of these types are enriched, which sends additional API calls to OpenCTI. To avoid these calls, exclude the OpenCTI integration from the enrichment of these indicator types.
- Added the *Source Reliability*, *Suspicious score threshold*, *Malicious score threshold* and *Create relationships* integration parameters, used by the reputation commands.
- Fixed an issue where the ***opencti-observable-field-update*** command failed with recent pycti versions.
- Updated the integration description to state that the integration is compatible with OpenCTI 6.9 and later versions (tested with OpenCTI 6.9.0 and 7.261).
- Updated the Docker image to: *demisto/opencti:1.0.0.7499058* for pycti==6.9.0 compatibility.
