
#### Scripts

##### DeleteAndExcludeIndicators

- Fixed an issue where indicator values were inserted into the delete query without quoting or escaping, and commas were rewritten as `or` operators. Characters inside a value (such as asterisks and double quotes) were therefore interpreted as query syntax, and a value that produced a standalone `*` term could match, and permanently delete, every indicator in the tenant.
- Added a safeguard that blocks the script from running a delete whose resolved query matches all indicators.
- The script now reports a clear error when no indicator values are supplied, instead of running an empty query.
