#### Integrations

##### Hydden Control

`hydden-blast-radius` now outputs only `Hydden.Identity.blast_radius` as a string. `hydden-deprovision-account` outputs only `Hydden.Identity.deprovisioned`.

#### Playbooks

##### New: Hydden - Blast Radius

Takes the account ID from a Cortex issue and calls `hydden-blast-radius`. Replaces Hydden - Resolve Identity Context.

##### Hydden - Deprovision Account

Takes the account ID from a Cortex issue and calls `hydden-deprovision-account`. Returns `Hydden.Identity.deprovisioned`.

##### Hydden - Resolve Identity Context

Removed. Use Hydden - Blast Radius.
