#### Integrations

##### New: Hydden Control

Return an account's blast radius from Hydden Control (`hydden-blast-radius`) and deprovision an account (`hydden-deprovision-account`).

#### Modeling Rules

##### New: Hydden Mesh Modeling Rule

Maps `hydden_mesh_raw` Mesh events into Cortex XDM (actor, target, auth, alert, observer).

#### Playbooks

##### New: Hydden - Blast Radius

Takes the account ID from a Cortex issue and calls `hydden-blast-radius`. Returns `Hydden.Identity.blast_radius`.

##### New: Hydden - Deprovision Account

Takes the account ID from a Cortex issue and calls `hydden-deprovision-account`. Returns `Hydden.Identity.deprovisioned`.

#### XSIAM Dashboards

##### New: Hydden Identity System of Record

XQL widgets on `hydden_mesh_raw` for Hydden Mesh identity activity (event volume, privileged identities, new accounts, top events, actions, actors, and targets).
