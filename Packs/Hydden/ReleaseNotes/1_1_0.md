#### Playbooks

##### New: Hydden - Account Probing

Resolves Account probing issues (failed logons to never-used hosts) against the Hydden identity record.

##### New: Hydden - Dormant User Login

Resolves dormant-user logins against the Hydden identity record, including leftover accounts after offboarding.

#### Triggers

##### New: Hydden - Account probing

Runs **Hydden - Account Probing** when the issue name contains Account probing.

##### New: Hydden - Dormant user login

Runs **Hydden - Dormant User Login** when the issue name contains dormant user.
