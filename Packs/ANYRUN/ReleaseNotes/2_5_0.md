
#### Integrations

##### ANY.RUN Cloud Sandbox
- Updated the Docker image to: *demisto/anyrun-sdk:1.0.0.12844876*.

- Added the *opt_automated_interactivity* argument (default: *True*) to the ***anyrun-detonate-file-windows*** and ***anyrun-detonate-url-windows*** commands, which controls whether the sandbox automatically interacts with the sample during analysis. This option is not supported on Linux or Android, so it remains hidden and defaults to *False* for the ***anyrun-detonate-file-linux***, ***anyrun-detonate-url-linux***, ***anyrun-detonate-file-android***, and ***anyrun-detonate-url-android*** commands.
- Updated the ***anyrun-get-analysis-report*** command with *report_format=ioc* to return indicator details formatted for ingestion as Cortex XDR IOCs (*ANYRUN.IOCDetails*), in addition to the existing *ANYRUN.IOCs* output. Building and returning *ANYRUN.IOCDetails* now requires the new *create_xdr_iocs* argument (default: *False*), since returning it unconditionally could delay the newly created indicators from becoming available for immediate association to the incident.
- Fixed an issue where the ***anyrun-get-analysis-report*** command failed when the *report_format* argument was not provided. It now defaults to *summary*.
- Fixed an issue where the ***anyrun-get-analysis-report*** command with *report_format=ioc* returned no result when the analysis report contained no IOCs. It now returns a *"No IOCs found"* message.
- Fixed an issue where the *ANYRUN.IOCDetails* output of the ***anyrun-get-analysis-report*** command sent an invalid reliability code and a hardcoded vendor reputation. It now sends the correct reliability code and the actual reputation of each indicator.

#### Playbooks

##### ANYRUN Detonate File Android

- Added the *Using* playbook input to select which *ANY.RUN Cloud Sandbox* instance to run the playbook against. If left empty, the first active instance is automatically used.
- Fixed an issue where the *Associate IOCs to incident* task could fail with a *"Indicators do not exist"* error due to a race condition. The task now automatically retries a few times before failing.

##### ANYRUN Detonate File Android for XDR

- New: This playbook submits a file from a Cortex XDR issue to the *ANY.RUN Cloud Sandbox* for dynamic analysis in an Android environment. It automates malware detonation and behavior observation on Android OS. Sets *create_xdr_iocs=true* when loading IOCs to Threat Intel, so Cortex XDR IOC details are generated.
