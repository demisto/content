
#### Integrations

##### ANY.RUN Cloud Sandbox

- New: Added the *opt_automated_interactivity* argument (default: *True*) to the ***anyrun-detonate-file-windows***, ***anyrun-detonate-file-linux***, ***anyrun-detonate-file-android***, ***anyrun-detonate-url-windows***, ***anyrun-detonate-url-linux***, and ***anyrun-detonate-url-android*** commands, to control whether the sandbox automatically interacts with the sample during analysis.
- New: The ***anyrun-get-analysis-report*** command with *report_format=ioc* now also returns indicator details formatted for ingestion as Cortex XDR IOCs (*ANYRUN.IOCDetails*), in addition to the existing *ANYRUN.IOCs* output.
- Fixed an issue where the ***anyrun-get-analysis-report*** command failed when the *report_format* argument was not provided. It now defaults to *summary*.

#### Playbooks

##### ANYRUN Detonate File Android

- New: Added a *Using* playbook input to select which ANY.RUN Cloud Sandbox instance to run the playbook against. When left empty, the first active instance is used automatically.

##### New: ANYRUN Detonate File Android for XDR

This playbook submits a file from a Cortex XDR issue to the ANY.RUN Cloud Sandbox for dynamic analysis in an Android environment. It helps to automate malware detonation and behavior observation on Android OS.
