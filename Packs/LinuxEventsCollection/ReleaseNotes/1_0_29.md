
#### Parsing Rules

##### Linux Events Collection Parsing Rule

- Fixed an issue where syslog logs in RFC 3164 format (for example, `/var/log/messages` and `/var/log/secure`) collected by the XDR Collector were dropped instead of being ingested into the *linux_linux_raw* dataset. These logs are now parsed the same way as syslog-collected RFC 3164 logs, with *_time* derived from the log timestamp (interpreted as UTC, since RFC 3164 carries no timezone).
