
#### Integrations

##### Palo Alto Networks PAN-OS

- Added support for native polling in the ***pan-os-platform-get-jobs*** command. When the *polling* argument is set to *true* and a single job *id* is provided, the command polls until the job reaches a terminal state (*status* = *FIN*) or the *timeout_in_seconds* is reached (default 3600 seconds), using an interval defined by *interval_in_seconds* (default 30 seconds).
