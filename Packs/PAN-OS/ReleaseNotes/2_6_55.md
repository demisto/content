
#### Integrations

##### Palo Alto Networks PAN-OS

- Added the ***pan-os-hygiene-get-snapshot*** command, which reads one configuration snapshot for the hygiene checks with a single API request.
- Added the ***pan-os-hygiene-evaluate-snapshots*** command, which runs all the configuration hygiene checks on snapshots without calling the device.

#### Playbooks

##### New: PAN-OS - Run Security Configuration Hygiene Checks (Snapshots)

- New: Runs the configuration hygiene checks with one API call per snapshot task, and evaluates them in a single task.
