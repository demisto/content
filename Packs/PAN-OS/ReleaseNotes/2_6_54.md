#### Playbooks

##### PAN-OS - Security Advisories Vulnerability Check

- The playbook now accepts a comma-separated list of CVE IDs in the *cve_id* input and checks them in a single run, retrieving the PAN-OS system information only once.

#### Scripts

##### CheckFirewallAndGPForCVEs

- Advisories that failed enrichment (for example, non-Palo Alto Networks CVE IDs) are now skipped instead of being reported as not affecting any firewall.

##### PAN-OS_Security_Advisories_Enrichment

- Duplicate CVE IDs in the *cve_id* argument are now enriched only once.
