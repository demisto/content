#### Integrations

##### Imperva Incapsula Event Collector v2

- Fixed a CEF parsing and tokenization issue where unescaped single quotes, apostrophes (e.g., city names like `Al 'Ayyat` or `'Amran`), and special characters in extension fields caused the parser to enter an unclosed string literal state, corrupting subsequent columns.
- Implemented comprehensive multi-column CEF value sanitization (single-quote normalization, multi-line character stripping, JSON double-quote normalization, and non-printable character removal) across all header and extension attributes.
- Ensured 100% field extraction integrity across high-volume traffic without dropping parsed attributes (`request`, `src`, `act`, `postbody`, etc.).
