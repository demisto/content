#### Integrations

##### Imperva Incapsula Event Collector v2

- Initial release of the Imperva Incapsula Event Collector v2 Pack for Cortex XSIAM.
- Added native XSIAM event collection support (`fetch-events` / `send_events_to_xsiam`) into dataset `imperva_siemintegration_raw`.
- Implemented multi-format decompression engine supporting GZIP, ZLIB, and raw DEFLATE log payloads.
- Added support for stateful incremental ingestion tracking (`starting_file_id`) and fetch rate limiting (`max_logs`).
- Added Health Module reporting for execution status tracking in the Cortex XSIAM **Fetch History** tab.
- Added manual CLI inspection command `imperva-v2-get-logs-index`.
