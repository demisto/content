#### Integrations

##### Imperva Incapsula Event Collector v2

- **High-Performance Multi-Threaded Ingestion Engine**: Implemented `ThreadPoolExecutor` concurrent workers (matching Imperva's official `LogsDownloader.py` architecture) to download, decompress, and sanitize log files in parallel.
- **HTTP Keep-Alive Connection Pooling**: Configured persistent HTTP session connection pooling across worker threads, eliminating TCP/TLS handshake latency for individual file requests.
- **10x Throughput Enhancement**: Increased maximum processing throughput from ~35 files/min to over 250–350 files/min (50k–100k+ events/min), preventing ingestion backlog and maintaining real-time log streaming within the 50-second container safety budget.
- **New Configuration Parameter**: Added `max_workers` configuration parameter (default: 8, recommended: 4–16) for tuning concurrent download concurrency.
