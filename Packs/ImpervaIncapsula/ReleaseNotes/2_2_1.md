#### Integrations

##### Imperva Incapsula Event Collector v2

- Fixed a CEF tokenization anomaly where scanner and bot user-agents containing unclosed double quotes (e.g. `requestClientApplication="Xpanse-bot`) or raw quotes in payloads caused SIEM parsers to enter an unclosed string literal state, swallowing subsequent columns (`deviceExternalId`, `src`, `request`, `act`, `start`, etc.) into `requestClientApplication`.
- Enhanced universal CEF sanitization engine across all columns: stripping double quotes from standard non-JSON fields, validating embedded JSON structures (`cs10`–`cs15`), removing trailing backslashes, preserving escaped header pipes, and normalizing control whitespace.
- Updated unit test suite to validate all quote, JSON, backslash, and whitespace edge cases.
