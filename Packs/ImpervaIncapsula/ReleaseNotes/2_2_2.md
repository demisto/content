#### Integrations

##### Imperva Incapsula Event Collector v2

- Added an execution time-budget safety guard (`FETCH_TIMEOUT_SAFETY_SECONDS = 50`) in `fetch_events` to yield cleanly and persist state before Docker container execution limits are reached.
- Reduced individual log download timeout to 30 seconds to prevent network hangs on large log batches.
- Added `safe_send_events_to_xsiam` with exponential backoff and retry mechanism to handle transient XSIAM ingestion server errors (e.g., empty responses, rate limits, 502/503).
- Added graceful error handling during background polling in `fetch-events` to maintain health module status without failing the integration instance on transient network hiccups.
