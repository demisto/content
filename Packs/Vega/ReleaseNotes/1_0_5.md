#### Incident Fields

##### New: Vega Detection Mode

- New: Added a new incident field- Vega Detection Mode that The detection mode of the Vega alert (for example ALERT).


##### New: Vega Detection Version ID

- New: Added a new incident field- Vega Detection Version ID that The version identifier of the detection rule that triggered this alert.


##### New: Vega Resolved At

- New: Added a new incident field- Vega Resolved At that The timestamp when this Vega incident was resolved.


##### Vega Timeline Events Source

- Updated the Vega Timeline Events Source incident field type to a grid.


##### New: Vega Typed Observables

- New: Added a new incident field- Vega Typed Observables that Typed observables associated with this Vega incident.


##### New: Vega Verdict Agreement

- New: Added a new incident field- Vega Verdict Agreement that Agreement status between automated and analyst verdicts for this Vega incident.



#### Mappers

##### Vega Mapper

- Updated the Vega Mapper to map Detection Mode, Detection Version ID, Resolved At, Typed Observables, and Verdict Agreement.


#### Layouts

##### Vega Incident

- Updated the Vega Incident layout to show Typed Observables instead of Observables.


#### Integrations

##### Vega

- Updated the Vega integration to fetch Detection Mode, Detection Version ID, Resolved At, Verdict Agreement, and Typed Observables.
- Changed the default **Investigation Statuses to fetch** to COMPLETED and FAILED.
- Added a User-Agent header on API requests.
- Updated the **Include alert metadata on incidents** parameter to be enabled by default.
