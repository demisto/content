#### Incident Fields

##### New: Vega Actors

- Added a new incident field: **Vega Actors**, which represents actors associated with this Vega alert, keyed by field name.


##### New: Vega Detection Mode

- Added a new incident field: **Vega Detection Mode**, which represents the detection mode of the Vega alert (for example ALERT).


##### New: Vega Detection Version ID

- Added a new incident field: **Vega Detection Version ID**, which represents the version identifier of the detection rule that triggered this alert.

##### New: Vega Resolved At

- Added a new incident field: **Vega Resolved At**, which represents the timestamp when this Vega incident was resolved.


##### New: Vega Targets

- Added a new incident field: **Vega Targets**, which represents targets associated with this Vega alert, keyed by field name.


##### Vega Timeline Events Source

- Updated the Vega Timeline Events Source incident field type to a grid.


##### New: Vega Typed Observables

- Added a new incident field: **Vega Typed Observables**, which represents typed observables associated with this Vega incident.


##### New: Vega Verdict Agreement

- Added a new incident field: **Vega Verdict Agreement**, which represents the agreement status between automated and analyst verdicts for this Vega incident.


#### Mappers

##### Vega Mapper

- Updated the Vega Mapper to map Actors, Detection Mode, Detection Version ID, Resolved At, Targets, Typed Observables, and Verdict Agreement.


#### Layouts

##### Vega Incident

- Updated the Vega Incident layout to show Typed Observables instead of Observables.


#### Integrations

##### Vega

- Updated the Vega integration to fetch Actors, Detection Mode, Detection Version ID, Resolved At, Targets, Verdict Agreement, and Typed Observables.
- Updated the default *Investigation Statuses to fetch* to *COMPLETED* and *FAILED*.
- Added a User-Agent header on API requests.
- Updated the *Include alert metadata on incidents* parameter to be enabled by default.
