
#### Integrations

##### Vega

- Updated the **Include alert metadata on incidents** parameter to be enabled by default.
- Added incoming mirroring for **Assets**, **Observables**, **Key Findings**, and **Recommended Actions** on Vega Incident investigations.
- Updated incoming mirroring to replace the **Vega Alerts** grid when a related alert is added or an existing alert is modified.
- Updated modified-alert mirroring to also sync the parent Vega incident, because an alert change does not update the incident timestamp.
