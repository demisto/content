#### Integrations

##### Vega

Added *typedAssets* to incident fetch and mapped it to the **Vega Assets** grid. Kept the raw *assets* list on **Vega Assets Value**. Stored observables, data sources, and MITRE ATT&CK values as single-column grids.

#### Incident Fields

##### Vega Assets

Changed **Vega Assets** to a grid with *Type* and *Value* columns, populated from *typedAssets*.

##### Vega Assets Value

New: **Vega Assets Value**. Stores the raw asset value list.

##### Vega Observables

Changed **Vega Observables** to a grid with a *Value* column.

##### Vega Data Sources

Changed **Vega Data Sources** to a grid with a *Value* column populated from the raw data source list.

##### Vega MITRE ATT&CK

Changed **Vega MITRE ATT&CK** to a grid with a *Value* column populated from the raw tactic and technique list.

#### Mappers

##### Vega Mapper

Updated the **Vega Mapper** to map *typedAssets* to **Vega Assets**, *assets* to **Vega Assets Value**, and observables to the **Vega Observables** grid.

#### Layouts

##### Vega Incident

Added **Vega Assets**, **Vega Observables**, and **Vega Data Sources** grids to the Vega Incident Info tab, and showed **Vega Assets Value** for the raw asset list.

##### Vega Alert

Added **Vega Data Sources** and **Vega MITRE ATT&CK** grids to the Vega Alert Info tab.
