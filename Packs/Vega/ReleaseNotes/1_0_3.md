#### Integrations

##### Vega

- Display vendor alert events that include `cid` or `eid` as a Timestamp, Source, and Log table. Timestamp comes from `timestamp`, Source from `SourceVendors`, and Log keeps the remaining `getAlertsEvents` fields.

Added *typedAssets* to incident fetch and mapped it to the **Vega Assets** grid. Kept the raw *assets* list on **Vega Assets Value**. Stored observables, data sources, and MITRE ATT&CK values as single-column grids.

- Updated `getAlertsEvents` to accept up to 10 alert IDs in one request and return per-alert event results.
- Updated incident fetch and `updateIncidents` to use analyst user status and Vega investigation status.
- Added **Incident Investigation Statuses to fetch**. An empty user-status or investigation-status selection fetches all values.
- Outgoing incident mirroring now sends `userStatus` on the update mutation.

#### Incident Fields

##### Vega Assets

Changed **Vega Assets** to a grid with *Type* and *Value* columns, populated from *typedAssets*.

##### Vega Assets Value

New: **Vega Assets Value**. Stores the raw asset value list.

##### Vega Observables

Changed **Vega Observables** to a grid with a *Value* column.

##### Vega Data Sources

Changed **Vega Data Sources** to a grid with a *Value* column populated from the raw data source list.

##### Vega MITRE ATT&CK

Changed **Vega MITRE ATT&CK** to a grid with a *Value* column populated from the raw tactic and technique list.

#### Mappers

##### Vega Mapper

Updated the **Vega Mapper** to map *typedAssets* to **Vega Assets**, *assets* to **Vega Assets Value**, and observables to the **Vega Observables** grid.

#### Layouts

##### Vega Incident

Added **Vega Assets**, **Vega Observables**, and **Vega Data Sources** grids to the Vega Incident Info tab, and showed **Vega Assets Value** for the raw asset list.

##### Vega Alert

Added **Vega Data Sources** and **Vega MITRE ATT&CK** grids to the Vega Alert Info tab.

#### Incident Fields

##### Vega Incident Status

Updated the selectable values to the Vega user statuses: OPEN, IN REVIEW, ON HOLD, and RESOLVED.

##### Vega Investigation Status

New: **Vega Investigation Status**. Stores the Vega investigation status (`NEW`, `INVESTIGATING`, `COMPLETED`, `FAILED`).

#### Mappers

##### Vega Mapper

Mapped incident user status to **Vega Incident Status** and `investigationStatus` to **Vega Investigation Status**.

#### Layouts

##### Vega Incident

Added **Vega Investigation Status** next to **Vega Incident Status**.

#### Incident Fields

##### VegaTimelineEventsSource

New: **Vega Timeline Events Source**. Mapped from the timelineEvents array.

##### VegaCommentsSource

New: **VegaCommentsSource**. Stores the unmodified Vega comments for Vega alerts and Vega incidents.

#### Mappers

##### Vega Mapper

Mapped *timelineEvents* to **Vega Timeline Events Source** for Vega incidents, and *VegaCommentsSource* to **Vega Comments Source** for Vega alerts and Vega incidents.
