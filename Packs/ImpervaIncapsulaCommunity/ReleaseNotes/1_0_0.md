#### Integrations

##### Imperva Incapsula Community Event Collector

New: Agentless, Cloud-to-Cloud event collector for Imperva Cloud WAF (Incapsula) accounts using
Retrieve (Pull mode) / Imperva API log integration. Fetches, decrypts, and decompresses log files from
the Imperva log buffer and ingests them into the `imperva_incapsula_raw` dataset.

#### Parsing Rules

##### Imperva Incapsula Community Event Collector

New: Extracts CEF header and all 56 documented Imperva event fields (plus their `csNLabel` companions)
from raw Imperva Incapsula log lines, per
[Imperva's official Log File Structure documentation](https://docs-cybersec.thalesgroup.com/bundle/cloud-application-security/page/more/log-file-structure.htm).
Matches key names case-insensitively to tolerate the casing inconsistencies present in Imperva's own
documented examples. Validated against Imperva's own official example line via a live Cortex XSIAM
tenant before merge.
