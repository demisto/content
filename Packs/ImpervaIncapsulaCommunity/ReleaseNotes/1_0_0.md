#### Integrations

##### Imperva Incapsula Community Event Collector

New: Agentless, Cloud-to-Cloud event collector for Imperva Cloud WAF (Incapsula) accounts using the
Imperva API log connection type. Fetches, decrypts, and decompresses log files from the Imperva log
buffer and ingests them into the `imperva_incapsula_raw` dataset.
