#### Integrations

##### Netcraft

- Added the *impersonation_target_id* argument to the ***netcraft-attack-report*** command. Use this argument to attach an impersonation target to a takedown.
- Added the ***netcraft-impersonation-target-list*** command, which gets the impersonation targets available to a region.
- Added the ***netcraft-impersonation-target-profile-list*** command, which gets the known social media profiles of an impersonation target.
- Updated the Docker image to: *demisto/python3:3.12.16.14740428*.
