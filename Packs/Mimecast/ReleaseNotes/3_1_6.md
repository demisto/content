
#### Integrations

##### Mimecast v2

- Fixed an issue where fetching **Held Messages** created duplicate incidents for messages that remained in the held queue. The latest incident time is now kept while paginating, so a completed pagination cycle no longer resets the fetch time to the oldest message.
  After upgrading, set the desired **Max fetch limit** and then reset the instance **last run**. A fetch cycle that was in progress during the upgrade can create duplicate incidents one more time.
