
#### Integrations

##### Mimecast v2

- Migrated the ***mimecast-update-block-sender-policy*** command to the Mimecast v2 API. Only the fields you explicitly provide are updated.
- **Breaking changes:** The ***mimecast-update-block-sender-policy*** command no longer emits context outputs. Use ***mimecast-get-policy*** or ***mimecast-list-policies*** to retrieve the updated policy.
- **Breaking changes:** The *fromType* argument in ***mimecast-update-block-sender-policy*** no longer accepts `free_mail_domains` or `header_display_name`. These values are rejected by the v2 API.
- Added the *confirm_block_all* argument to ***mimecast-update-block-sender-policy***. When *fromType* is set to `everyone`, this argument must be set to `true` to prevent accidental blocking of all senders.
- Added the *from_date* argument to ***mimecast-update-block-sender-policy***.
- Added the *to_date* argument to ***mimecast-update-block-sender-policy***.
- Improved OAuth2 authentication.
- Updated the Docker image to: *demisto/python3:3.12.13.10404775*.
