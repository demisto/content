
#### Integrations

##### Mimecast v2

- Updated the ***mimecast-update-block-sender-policy*** command to the Mimecast v2 API. Only the fields you explicitly provide are updated.
- Updated the ***mimecast-update-block-sender-policy*** command. **Breaking change:** The command no longer emits context outputs. Use ***mimecast-get-policy*** or ***mimecast-list-policies*** to retrieve the updated policy.
- Updated the *fromType* argument in the ***mimecast-update-block-sender-policy*** command. **Breaking change:** It no longer accepts *free_mail_domains* or *header_display_name*. These values are rejected by the v2 API.
- Added the *confirm_block_all* argument to ***mimecast-update-block-sender-policy***. When *fromType* is set to *everyone*, this argument must be set to *true* to prevent accidental blocking of all senders.
- Added the *from_date* argument to ***mimecast-update-block-sender-policy***.
- Added the *to_date* argument to ***mimecast-update-block-sender-policy***.
- Improved implementation of OAuth2 authentication.
- Updated the Docker image to: *demisto/python3:3.12.13.10404775*.
