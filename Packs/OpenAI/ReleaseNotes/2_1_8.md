
#### Integrations

##### OpenAI GPT

- Moved the integration logic into the shared **OpenAiChatGPTApiModule**, which is also used by the OpenAI standard connector. The integration parameters, commands and outputs are unchanged.
- Added support for authenticating through the OpenAI standard connector.
- Fixed an issue where **Test** failed with *model_not_found* when the configured model was retired. The test now validates the API Key with the models endpoint and no longer calls a model.
- **Model** is now a free-text parameter that takes a model ID (see https://developers.openai.com/api/docs/models). The previous model dropdown, which listed retired models and defaulted to the retired *gpt-3.5-turbo*, is now hidden. Existing instances keep the model selected there when **Model** is empty.
- Before each GPT command runs, the model is now checked against the models available to the API Key, with a clear error when it is missing or unavailable.
- Note: You can move to the OpenAI standard connector by creating a standard connector instance and then disabling this instance. Running both against the same organization ingests duplicate events into the same datasets.
