
#### Integrations

##### Proofpoint Email Security Event Collector

- Fixed an issue where WebSocket connections were not closed after a failed connection attempt, which caused repeated *HTTP 409* (Conflict) errors.
- Fixed an issue where reconnection attempts were retried immediately after a connection failure. Reconnection attempts now use an exponential backoff.
- Fixed an issue where the ***proofpoint-es-get-last-run-results*** command showed only the result of the last fetched event type. The command now shows the results of the last fetch for each event type.
- Fixed an issue where WebSocket keep-alive failures were written to the error output, which caused the long-running execution to be marked as failed and restarted.
- Updated the Docker image to: *demisto/netutils:1.0.0.14169403*.
