
#### Integrations

##### Proofpoint Email Security Event Collector

- Fixed an issue where WebSocket connections were not closed after a failed connection attempt, which caused repeated *HTTP 409* (Conflict) errors.
- Added an exponential backoff between reconnection attempts when the connection to Proofpoint fails.
- Improved the ***proofpoint-es-get-last-run-results*** command to show the results of the last fetch for each event type.
- Fixed an issue where WebSocket keep-alive failures were written to the error output, which caused the long-running execution to be marked as failed and restarted.
