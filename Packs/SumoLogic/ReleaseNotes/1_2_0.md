#### Integrations

##### SumoLogic

- Fixed an issue where the ***search*** command failed with a *400 searchjob.raw.messages.not.available* error when running aggregate queries, due to the Sumo Logic API no longer retaining raw messages by default for aggregate search jobs.
- Fixed an issue where the ***search*** command aborted before returning aggregate records when raw message retrieval failed.
- Added the *requiresRawMessages* argument to the ***search*** command, which controls whether the search job retains raw messages.
