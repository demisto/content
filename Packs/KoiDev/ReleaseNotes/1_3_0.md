
#### Integrations

##### KOI Dev

- Development/testing version of KOI v1.3.0 integration.
- All commands prefixed with `koi-dev-` to avoid conflicts with production.
- Includes DBot scoring, custom "Koi Software Item" indicator type, CVE extraction.
- Standalone `koi-dev-alert-list` command with OCSF alert surfacing.
- Enhanced `koi-dev-private-item-details-get` with structured sub-tables.
- Source reliability configuration via `integrationReliability` parameter.
