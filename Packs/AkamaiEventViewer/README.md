Collect Akamai Control Center portal-visible events stored in the Akamai Event Logger system into Cortex XSIAM.

## What does this pack do?

- Collects Control Center events such as configuration changes, login attempts, alert activity, and log deliveries.
- Optionally limits collection to selected event types.

For more information, see the [Akamai Event Viewer API documentation](https://techdocs.akamai.com/event-viewer/reference/api-get-started).
