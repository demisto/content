
#### Integrations

##### Microsoft Defender for Cloud Apps Event Collector

- Fixed an issue where an event type with no events in a cycle could fall behind.
- Fixed an issue where activity events were retrieved in small pages, which limited throughput for high-volume tenants. Activities are now retrieved in larger pages.
- Replaced the *limit* parameter with the *alerts_limit* and *activities_limit* parameters to control the maximum number of events fetched per event type per cycle.
- Added the *event_types_to_fetch* argument to the ***microsoft-defender-cloud-apps-get-events*** command to scope a run to specific event types.
