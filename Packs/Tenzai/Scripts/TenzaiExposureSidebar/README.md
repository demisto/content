Renders the Validate tab's left-column exposure detail: a Timeline card showing the exposure lead's status history (OPEN / IN_PROGRESS / BLOCKED / MATERIALIZED / INVALIDATED, with timestamps). Reads the persisted Tenzai Timeline grid field on the issue.

This script is a dynamic-section widget used by the **Tenzai Issue Layout** and is not intended to be run directly.
