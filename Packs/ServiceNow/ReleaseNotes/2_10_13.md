#### Integrations

##### ServiceNow v2

- Added the new **servicenow-create-event** command, which creates an event in ServiceNow Event Management by posting to the `/api/global/em/jsonv2` webhook endpoint (writes to the `em_events` table). Supports individual field arguments (`source`, `node`, `type`, `time_of_event`, `resource`, `severity`, `description`, `message_key`, `resolution_state`, `additional_info`) with automatic mapping of Cortex severity labels and resolution states to ServiceNow values, and a `raw_event` argument for passing a raw JSON event object.

#### Scripts

##### New: ServiceNowCreateEvent

- New script that wraps the **servicenow-create-event** integration command for use in playbooks. Creates an event in ServiceNow Event Management with Cortex-to-ServiceNow field mapping.
