
#### Modeling Rules

##### ServiceNow ServiceNow Modeling Rule
- Added support for mapping *Outbound HTTP Log* events (`source_log_type = "outbound_http_log"`) to XDM, including HTTP method, response code, URL, path, and byte counts.
- Fixed the *Audit* branch filter to explicitly match `source_log_type = "audit"` instead of a negated `not in` condition, preventing outbound HTTP log events from being incorrectly classified as audit events.
