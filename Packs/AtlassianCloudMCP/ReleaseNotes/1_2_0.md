
#### Integrations

##### Atlassian Cloud MCP

- Renamed the **Authorization code** parameter to **Redirect URL or Authorization Code**. It now accepts the full redirect URL returned after running the `\!atlassian-cloud-mcp-generate-login-url` command, in addition to a bare authorization code.
- Pasting the full URL lets Cortex verify the **state** parameter on the authorization response, protecting against CSRF attacks.
- Support for pasting only the authorization code is deprecated and will be removed in a future version.
