
#### Integrations

##### Wiz

- Migrated Issue notes to the Wiz Comments API ahead of the retirement of the Issue Notes API. ***wiz-set-issue-note***, ***wiz-clear-issue-note***, and the note arguments of ***wiz-reject-issue***, ***wiz-resolve-issue***, and ***wiz-reopen-issue*** now create and delete Issue comments; incoming mirroring reads Issue comments.
- **Action required:** the Wiz service account used by the integration needs the `write:comments` scope to add notes (commands and outgoing mirroring), the `read:comments` scope for incoming mirroring, and both scopes for ***wiz-clear-issue-note***. Review the service account's permissions before upgrading.
- Issue notes are no longer included in fetched incident data. Comments are requested only by ***wiz-clear-issue-note*** and incoming mirroring.

##### WizDefend

- Migrated threat comments to the Wiz Comments API. ***wiz-defend-set-threat-comment***, ***wiz-defend-clear-threat-comments***, and the note arguments of ***wiz-defend-resolve-threat*** and ***wiz-defend-reopen-threat*** now use Issue comments.
- **Action required:** the service account needs `write:comments` to add comments, and both `read:comments` and `write:comments` for ***wiz-defend-clear-threat-comments***.

#### Classifiers

##### WizDefend Mapper

- Removed the **Wiz Issue Note** mapping, which relied on the retired Issue Notes field.
