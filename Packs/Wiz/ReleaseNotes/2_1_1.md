
#### Integrations

##### Wiz

- Updated the ***wiz-reject-issue*** and ***wiz-resolve-issue*** commands and outgoing status mirroring to save the note as the Issue resolution note, shown in Wiz as the **Ignore Comment** for rejected Issues, instead of adding an Issue comment. These notes no longer require the *write:comments* scope.
- Fixed an issue where ***wiz-reject-issue*** and mirrored rejections failed on tenants that require a note when rejecting Issues.

##### WizDefend

- Updated the ***wiz-defend-resolve-threat*** command to save the note as the threat resolution note instead of adding an Issue comment. This note no longer requires the *write:comments* scope.
