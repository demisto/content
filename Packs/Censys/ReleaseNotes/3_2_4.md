
#### Integrations

##### Censys Platform

- Added the *Determine IP score using Censys Host Reputation data (for Censys Core customers)* configuration parameter. When enabled, the ***ip*** command scores IPs as Malicious, Suspicious or Good based on the Censys host reputation label. If label-based scoring is also enabled, the higher of the two scores is applied.
- Updated the configuration parameter names from *Determine IP score by labels (for paid subscribers)* to *Determine IP score using Censys Labels*, and from *Use enrichment API for the ip command* to *Use Censys Host Enrichment API for ip command* (now enabled by default).
- Added the new label options to the *IP Malicious labels* and *IP Suspicious labels* parameters. These parameters can accept custom labels that aren't listed.
- Updated the output of the ***ip*** and ***cen-rescan*** commands to remove the Mallory information.
