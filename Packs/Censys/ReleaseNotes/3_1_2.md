
#### Integrations

##### Censys v2

- Added a new configuration parameter **Use enrichment API for the ip command** with a default value of False (leaving existing instances unaffected). When enabled, the ***ip*** command uses the host enrichment API.
- Added support for *use_enrichment_endpoint* argument in the **ip** command.
- Updated the Docker image to: *demisto/python3:3.12.14.12343672*.
