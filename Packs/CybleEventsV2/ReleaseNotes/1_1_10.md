#### Integrations

##### CybleEvents v2

- Improved implementation of ***fetch-incidents*** for large backlogs: checkpoint progress after each page (*service*, *skip*, *chunk_gte*, *chunk_lte*, *window_lte*), exit gracefully before Docker timeout, and resume on the next run.
- Fixed an issue where the fetch window (*window_lte*) could keep growing across failed or partial runs by freezing it for the duration of a fetch cycle.
- Fixed an issue where incidents were not created because an empty final *demisto.incidents* call wiped earlier inserts; incidents are now submitted once at the end of each fetch.
- Fixed an issue where pagination did not advance *skip* by the number of rows returned and could exceed the API page size of 100.
- Fixed an issue where outgoing mirroring did not run ***update-remote-system***, and fixed ***get-modified-remote-data*** double-nesting the service filter when All collections is selected.
