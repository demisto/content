#### Integrations

##### CybleEvents v2

- Improved `fetch-incidents` reliability for large backlogs: checkpoint progress after each page (`service`, `skip`, `chunk_*`, `window_lte`), exit gracefully before Docker timeout, and resume on the next run.
- Freeze the fetch window (`window_lte`) for the duration of a fetch cycle so failed or partial runs do not keep growing the time range.
- Submit incidents once at the end of each fetch via `demisto.incidents(data)` (avoids empty final calls wiping inserts and satisfies FetchNewIncidents).
- Fixed pagination to advance `skip` by the number of rows returned and clamp API page size to 100.
- Fixed outgoing mirroring by wiring `update-remote-system` in `main`, and fixed `get-modified-remote-data` double-nesting the service filter when All collections is selected.
