
#### Parsing Rules

##### Huawei FW Parsing Rule

- Updated the parsing rule to support the Huawei USGxxxxF firewall series (for example, USG6710F). The log header parsing now handles the log format where the log serial-number segment (`[serial]`) is omitted, so these logs are correctly ingested into the *huawei_fw_raw* dataset instead of being routed to *unknown_unknown_raw*.
