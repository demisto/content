
#### Parsing Rules

##### Huawei FW Parsing Rule

- Fixed an issue where logs from the Huawei USGxxxxF firewall series (for example, USG6710F) were not parsed correctly. The log header parsing now handles the log format where the log serial-number segment (*[serial]*) is omitted, so these logs are correctly ingested into the *huawei_fw_raw* dataset instead of being routed to *unknown_unknown_raw*.
