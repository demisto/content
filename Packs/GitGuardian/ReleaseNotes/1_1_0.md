
#### Integrations

##### GitGuardian Event Collector

- Added support for the GitGuardian SaaS deployment by fetching secret incidents from the *api/v1/incidents/secrets* endpoint instead of the deprecated *api/v1/secrets* endpoint, which returns a 404 on SaaS.
- Added the *_ENTRY_STATUS* field to secret incident events to indicate whether an incident is *new* or *updated*.
- Updated the default server URL to *https://api.gitguardian.com*.
