
#### Integrations

##### Sekoia XDR

- Fixed an issue where expired (HTTP 410 Gone) or canceled events search jobs were polled indefinitely during mirroring and fetching, which slowed down the mirroring queue.
- Fixed an issue where ***fetch-incidents*** failed with the error *Earliest time must be anterior to latest time* when an alert had a *first_seen_at* timestamp later than the current time.
- Improved ***fetch-incidents*** so that a failed event search for one alert no longer fails the whole fetch. The incident is created without its events.
