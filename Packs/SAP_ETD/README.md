# SAP Enterprise Threat Detection

## Overview

SAP Enterprise Threat Detection (ETD) identifies, analyzes, and neutralizes cyberattacks in SAP applications. It provides real-time monitoring and alerting for security events across SAP landscapes.

This pack includes an integration that fetches alerts from an **on-premise** SAP ETD server and ingests them into Cortex XSIAM for centralized security monitoring, correlation, and threat analysis.

> **Note:** Only SAP Enterprise Threat Detection **on-premise** is supported. SAP Enterprise Threat Detection, Cloud Edition (SAP BTP) is not supported by this pack.
