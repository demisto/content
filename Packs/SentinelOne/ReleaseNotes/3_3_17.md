#### Integrations

##### SentinelOne v2

- Added the ***sentinelone-create-firewall-rule*** command that creates a Firewall Control rule for a specified scope and OS to allow or block network traffic using the v2.1 firewall-control endpoint.
- Added the ***sentinelone-delete-firewall-rule*** command that deletes Firewall Control rules matching the specified filter using the v2.1 firewall-control endpoint.
