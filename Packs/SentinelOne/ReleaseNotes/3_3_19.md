
#### Integrations

##### SentinelOne v2

- Added the ***sentinelone-create-firewall-rule*** command, which creates a Firewall Control rule that allows or blocks network traffic. Relevant for API version 2.1.
- Added the ***sentinelone-delete-firewall-rule*** command, which deletes Firewall Control rules that match the specified filters. Relevant for API version 2.1.
