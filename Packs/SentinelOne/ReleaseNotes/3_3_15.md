
#### Integrations

##### SentinelOne v2

- Added the ***sentinelone-get-unified-exclusions*** command that lists unified exclusion items using the v2.1 unified-exclusions endpoint.
- Added the ***sentinelone-create-unified-exclusion*** command that creates a new unified exclusion item using the v2.1 unified-exclusions endpoint.
- Added the ***sentinelone-delete-unified-exclusions*** command that deletes unified exclusion items by their IDs and types using the v2.1 unified-exclusions endpoint.
- Added the ***sentinelone-get-alert-with-raw-indicators*** command that retrieves a UAM alert along with its raw SDL indicators, structured MITRE ATT&CK mappings, and a pre-built Deep Visibility query filter via the v2.1 unified alerts GraphQL endpoint.
- Fixed the ***sentinelone-get-activities*** command to correctly send multiple `activity_types` values as a single comma-separated query parameter instead of repeated parameters.
- Fixed an issue where UAM alerts could be missed during fetch because they were queried before SentinelOne finished indexing them. The fetch window now ends 5 minutes in the past to allow indexing to complete before querying.
