# KELA Monitor

KELA Monitor tracks your organization's exposure on the dark web. This pack fetches Monitor incidents into Cortex XSOAR and lets analysts list them by incident type.

## What does this pack include?

- **KELA Monitor** integration: fetches incidents of the incident types you choose (one Monitor per instance) and provides `kela-monitor-incident-list` and `kela-monitor-incident-scroll`.

The integration is read-only. Sensitive data is masked by default and hacking discussions are fetched as a snippet only.
