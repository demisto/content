
#### Playbooks

##### Azure - VM Instance Network Security Group Remediation

Updated the playbook to use the new Azure commands (`azure-vn-security-rules-list`, `azure-vn-security-rule-update`, `azure-vn-security-rule-create`, `azure-vn-public-ip-address-get`, and `azure-vn-network-interface-get`) and their standardized context output paths, replacing the deprecated `azure-nsg-*` and `azure-vm-*` commands. Renamed the security rule creation argument `action` to `access` to match the new `azure-vn-security-rule-create` command.

#### Scripts

##### AzureIdentifyNSGExposureRule

Updated the script to call the new `azure-vn-security-rules-list` command, replacing the deprecated `azure-nsg-security-rules-list` command.
