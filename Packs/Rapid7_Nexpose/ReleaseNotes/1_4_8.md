
#### Integrations

##### Rapid7 InsightVM

- Fixed an issue where large **fetch-assets** runs failed while streaming events because the report download stream was cut off after 5 minutes. The download now uses an idle-read timeout with no overall time limit, so large reports complete in a single run.
- Improved error messages for **fetch-assets** streaming failures to include the underlying error type, so failures are no longer reported with a blank message.
- Added diagnostic logging to report the number of lines received when the report download stream finishes or fails.
