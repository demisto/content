
#### Integrations

##### Rapid7 InsightVM

- Fixed an issue where the **fetch-assets** command regenerated a failed or aborted Rapid7 report indefinitely within a single run. A report is now regenerated at most twice per run, with a backoff between attempts, and the run stops after 12 hours without a completed report. The next scheduled fetch retries.
- Fixed an issue where a regenerated report instance was not saved until the report completed, which caused an extra regeneration if the run was interrupted.
