
#### Integrations

##### Rapid7 InsightVM

- Fixed an issue where the **fetch-assets** command regenerated a failed or aborted Rapid7 report indefinitely within a single run. A report is now regenerated at most twice per run, with a backoff between attempts, and the run stops after 12 hours without a completed report. The next scheduled fetch retries.
- Fixed an issue where a regenerated report instance was not saved until the report completed, which caused an extra regeneration if the run was interrupted.
- Improved the performance of the vulnerability query used by the **fetch-assets** command. The 100-day date filter is now applied before the findings are aggregated, which reduces the load on the Rapid7 Security Console. The collected data is unchanged.
- Fixed an issue where **fetch-assets** skipped assets whose most recent scan had not completed (for example, a running, paused, stopped, or aborted scan), even when the asset had earlier completed scans. Assets are now collected based on their latest completed scan.
- Updated the Docker image to: *demisto/auth-utils:1.0.0.13804971*.
