
#### Integrations

##### Rapid7 InsightVM

- Added the *Lookback (days)* parameter, which sets how many days back the ***fetch-assets*** command collects assets and vulnerability findings. The default is 100 days, the same as the previous fixed window.
- Fixed an issue where the ***fetch-assets*** command regenerated a failed or aborted Rapid7 report indefinitely within a single run. A report is now regenerated at most twice per run, with a backoff between attempts, and the run stops after 12 hours without a completed report. The next scheduled fetch retries.
- Fixed an issue where a regenerated report instance was not saved until the report completed, which caused an extra regeneration if the run was interrupted.
- Fixed an issue where the ***fetch-assets*** command skipped assets whose most recent scan had not completed (for example, a running, paused, stopped, or aborted scan), even when the asset had earlier completed scans. Assets are now collected based on their latest completed scan.
- Improved implementation of the vulnerability query used by the ***fetch-assets*** command. The date filter is now applied before the findings are aggregated, which reduces the load on the Rapid7 Security Console. The collected data is unchanged.
- Updated the Docker image to: *demisto/auth-utils:1.0.0.13804971*.
