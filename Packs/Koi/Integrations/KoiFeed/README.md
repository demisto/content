Fetches Koi (Agentic Endpoint Security) inventory items as indicators for Cortex XSOAR TIM and Cortex XSIAM TIM.

Creates "Koi Software Item" indicators with DBot scoring based on risk assessment. Automatically links indicators to related file hashes (SHA-1/SHA-256) and CVEs via EntityRelationships, and extracts CVE indicators from item findings for vulnerability tracking.

Install alongside the KOI data collection integration for full coverage.
