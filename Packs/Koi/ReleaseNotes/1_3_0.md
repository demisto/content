
#### Integrations

##### KOI Feed

- Added the **KOI Feed** integration for fetching Koi inventory items as "Koi Software Item" indicators into Cortex XSOAR TIM and Cortex XSIAM TIM.
- Added DBot scoring based on Koi risk assessment for all fetched indicators.
- Added marketplace filtering and minimum risk score threshold configuration.
- Added EntityRelationship links between indicators and related file hashes (SHA-1/SHA-256) and CVEs.
- Added CVE indicator extraction from item findings for automated vulnerability tracking.
- Updated the Docker image to: *demisto/fastapi:0.141.1.13241299*.
