
#### Integrations

##### KOI

- Added 35 new commands covering all Koi API v2 endpoints:
  - **Agent Activity**: *koi-agent-activity-events-list*, *koi-agent-activity-sessions-list* — List agent activity events and sessions.
  - **Approval Requests**: *koi-approval-request-list*, *koi-approval-request-create*, *koi-approval-request-approve*, *koi-approval-request-reject* — Manage item approval workflows.
  - **Devices**: *koi-device-list*, *koi-device-archive*, *koi-device-inventory-get* — List, archive, and inspect device inventory.
  - **Findings**: *koi-finding-list*, *koi-finding-customize-risk* — List findings and customize risk levels.
  - **Groups**: *koi-group-list*, *koi-group-create*, *koi-group-update*, *koi-group-device-add*, *koi-group-device-remove* — Manage device groups.
  - **Runtime Policies**: *koi-runtime-policy-list*, *koi-runtime-policy-create*, *koi-runtime-policy-get*, *koi-runtime-policy-update*, *koi-runtime-policy-delete* — Manage agent runtime policies (hardening).
  - **Koidex**: *koi-koidex-fetch*, *koi-koidex-risk-report-get*, *koi-koidex-search* — Trigger risk scans, retrieve risk reports, and search the marketplace catalog.
  - **Private Items**: *koi-private-item-list*, *koi-private-item-upload*, *koi-private-item-details-get* — Manage and scan private items.
  - **Remediations**: *koi-remediation-list*, *koi-remediation-submit*, *koi-remediation-dismiss* — List, submit, and dismiss remediations.
  - **Reports**: *koi-report-create*, *koi-report-status-get* — Create async reports and check status.
  - **Users**: *koi-user-list*, *koi-user-create*, *koi-user-delete* — Manage users.
- Added 7 new marketplace values: *binaries*, *bitbucket*, *github*, *gitlab*, *mcp_registry*, *ollama*, *skill*.
