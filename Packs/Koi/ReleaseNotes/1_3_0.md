
#### Integrations

##### KOI

- Updated the fetch mechanism to read alerts and audit logs with the KOI API's cursor paging, so events that share a timestamp are no longer skipped or ingested twice.
- Fixed an issue where a failed fetch was not reported and stopped ingestion without an error. Failures are now shown in the instance status, and the events ingested before the failure are kept.
- Fixed an issue where events written by KOI shortly after a fetch could be missed. The fetch now reads up to 2 minutes before the current time.
- Improved fetch performance by requesting smaller pages and skipping the total count.
- The ***test-module*** now checks every event type selected for fetching.
- Added the EU server URL to the *Server URL* parameter help.
