
#### Integrations

##### KOI Feed

- New feed integration for Threat Intelligence Management (TIM) indicator population.
- Added fetching of Koi inventory items as "Koi Software Item" indicators with DBot scoring based on risk assessment.
- Added marketplace filtering, minimum risk score threshold, and configurable fetch interval.
- Added EntityRelationship links between indicators and related file hashes (SHA-1/SHA-256) and CVEs.
- Added CVE indicator extraction from item findings for automated vulnerability tracking.
