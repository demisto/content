
#### Integrations

##### CheckPoint Firewall v2

- Added support for the following commands:
  - ***checkpoint-access-rule-get***, that returns a single access rule by name, UID, or rule number.
  - ***checkpoint-session-discard***, that discards uncommitted session changes.
  - ***checkpoint-dns-domain-list***, that lists DNS domain objects.
  - ***checkpoint-dns-domain-get***, that shows a single DNS domain object.
  - ***checkpoint-dns-domain-add***, that creates a DNS domain object.
  - ***checkpoint-dns-domain-update***, that modifies a DNS domain object.
  - ***checkpoint-dns-domain-delete***, that deletes a DNS domain object.
- Fixed an issue in the ***checkpoint-access-rule-add*** command where multiple values for the *source*, *destination*, and *service* arguments were sent as a single object name.
- Added support for the *tags* and *entry_id* arguments in the ***checkpoint-access-rule-add*** command.
- Updated the ***checkpoint-access-rule-list*** command to return the full rule objects, and added support for the *filter*, *order_asc*, *order_desc*, *package*, *show_as_ranges*, *show_expiration_settings*, *use_object_dictionary*, *hits_settings_from_date*, *hits_settings_target*, *hits_settings_to_date*, *dereference_group_members*, and *show_membership* arguments.
- Added support for the *install_on_add* and *install_on_remove* arguments in the ***checkpoint-nat-rule-update*** command.
- Added support for the *details_level* argument in the ***checkpoint-show-task*** command, and included additional failure fields (message, warnings, error, blocking errors, code) in the output.
- Added support for the *ignore_warnings*, *ignore_errors*, and *use_default_session_timeout* arguments in the ***checkpoint-tcp-service-add***, ***checkpoint-tcp-service-update***, ***checkpoint-udp-service-add***, and ***checkpoint-udp-service-update*** commands.
