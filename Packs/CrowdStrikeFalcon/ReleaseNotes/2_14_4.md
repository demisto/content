
#### Integrations

##### CrowdStrike Falcon

- Fixed an issue where the ***cs-falcon-device-count-ioc***, ***cs-falcon-device-ran-on***, and ***cs-falcon-processes-ran-on*** commands failed with an HTTP 403 error by migrating from the retired `/indicators/...` endpoints to the modern `/iocs/...` endpoints.
- Fixed an issue where the ***cs-falcon-device-ran-on*** and ***cs-device-ran-on*** commands returned only the first 100 device IDs. The commands now page through the results and return all device IDs.
- Added support for a comma-separated list of values in the *value* argument of the ***cs-falcon-device-count-ioc***, ***cs-falcon-device-ran-on***, and ***cs-device-ran-on*** commands. A separate result is returned for each value, and the *type* argument applies to all values.
- The ***cs-falcon-device-count-ioc*** command now returns a *DeviceCount* of 0 in the context when no devices have observed the indicator.
