
#### Integrations

##### CrowdStrike Falcon

- Fixed an issue where the ***cs-falcon-device-count-ioc*** and ***cs-falcon-device-ran-on*** commands failed with an HTTP 403 error due to deprecated endpoints.
- Fixed an issue where the ***cs-falcon-device-ran-on*** command returned only the first 100 device IDs without pagination.
- Added support for multiple values in the *value* argument of the ***cs-falcon-device-count-ioc*** and ***cs-falcon-device-ran-on*** commands.
- Updated the ***cs-falcon-device-count-ioc*** command to return a *DeviceCount* of 0 in the context when no devices are found.
