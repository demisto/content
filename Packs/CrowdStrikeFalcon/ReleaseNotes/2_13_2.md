
#### Integrations

##### CrowdStrike Falcon

- Fixed an issue where Spotlight assets were discarded instead of ingested when the CrowdStrike Devices API returned the resolved devices with a partial-success response, so no assets reached the asset inventory.
- Fixed an issue where the Spotlight assets snapshot was sealed with an incorrect record count, leaving the assets unavailable in the asset inventory. The final batch now declares the number of assets Cortex confirmed it stored across the whole fetch cycle, instead of the number of host IDs submitted for enrichment.
- Fixed an issue where a failed CrowdStrike Devices API asset enrichment was not reported, so a fetch that enriched no assets was indistinguishable from one that found none. Failed enrichments are now logged as errors.
- Fixed an issue where the Spotlight assets snapshot could be sealed before the record count of the last batch was applied, so the snapshot declared fewer assets than were stored and the assets remained unavailable in the asset inventory.
- Fixed an issue where a failure to seal the Spotlight assets snapshot also failed the whole fetch cycle, discarding vulnerability data that had already been stored successfully.
- Updated the Docker image to: *demisto/py3-tools:1.0.0.13176850*.
