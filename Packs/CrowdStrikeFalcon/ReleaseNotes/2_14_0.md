
#### Integrations

##### CrowdStrike Falcon

- Added the *Spotlight vulnerabilities lookback (days)* parameter, to bound how far back Spotlight vulnerabilities are fetched. Default is 100 days.
- Improved implementation of the Spotlight vulnerabilities fetch to reduce memory consumption and the time spent between pagination requests, so the pagination cursor is less likely to expire mid-fetch:
  - Severities are now fetched two at a time, smallest first, instead of all six at once.
  - The next page is now requested before the current page is compressed and uploaded.
  - Reduced the page size on the long-running flow.
  - Bounded the number of concurrent asset enrichment requests.
  - Reused a single HTTP session for uploads instead of opening one per attempt.
  - Memory held by a fetch cycle is now released at the end of the cycle on the long-running flow, instead of accumulating across cycles.
- Fixed an issue where retrying a partially sent sealing batch could duplicate records, preventing the snapshot from ever becoming queryable.
- Fixed an issue where a severity that failed mid-fetch left uploads running, which could report records that were successfully stored as failed and prevent the snapshot from sealing.
- Updated the Docker image to: *demisto/py3-tools:1.0.0.13176850*.
