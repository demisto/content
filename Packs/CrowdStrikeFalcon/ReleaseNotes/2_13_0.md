
#### Integrations

##### CrowdStrike Falcon

- Fixed an issue where the number of Spotlight vulnerability records sent to Cortex XSIAM did not match the number declared, so the assets snapshot never sealed on large tenants.
- Fixed an issue where a single failed page or send aborted the collection of an entire severity instead of continuing with the remaining pages.
- Fixed an issue where Spotlight assets were never collected on tenants that span multiple CIDs (CrowdStrike Flight Control / MSSP parent-child deployments).
- Fixed an issue where a transient Cortex XSIAM error marked the instance as errored even when the retry succeeded and no data was lost.
- Added the *Long running instance for Spotlight vulnerabilities* parameter, which runs the Spotlight vulnerabilities fetch in a long-running container instead of on the assets fetch schedule. Use it when a full Spotlight fetch takes longer than the assets fetch interval and is therefore repeatedly interrupted.
NOTE: This mode fetches Spotlight vulnerabilities only, and cannot be enabled together with the assets fetch on the same instance. To collect CNAPP Alerts, configure a separate instance using the regular assets fetch.
