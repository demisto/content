
#### Integrations

##### CrowdStrike Falcon

- Fixed an issue where the Spotlight vulnerabilities assets snapshot never sealed because records were counted before the asynchronous send to XSIAM, so failed sends were counted-but-dropped (declared > stored). Records are now counted only after XSIAM confirms storing them, counting each batch by the number of records actually stored. A failed send no longer aborts the severity: the fetch continues with the remaining pages and the records that were not stored are simply not counted, and are picked up on the next fetch cycle.
- Fixed an issue where oversized vulnerability pages could be truncated and raise a JSON decode error that aborted an entire severity fetch. The same page is now retried with progressively smaller page sizes and automatically reverts to the default size on the next page.
- Improved completed-severity checkpointing so each severity's progress is persisted as soon as it finishes (in completion order) instead of waiting for slower severities, removing head-of-line blocking.
