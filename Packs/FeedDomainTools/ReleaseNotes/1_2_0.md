#### Indicator Fields

##### DomainToolsFeed IP ASN

- Added a new indicator field- DomainToolsFeed IP ASN that stores the autonomous system number (routing provider) associated with the IP address.


##### DomainToolsFeed IP All Threats Combined Count

- Added a new indicator field- DomainToolsFeed IP All Threats Combined Count that stores the count of confirmed or predicted malicious domains hosted on the IP.


##### DomainToolsFeed IP All Threats Combined Percent

- Added a new indicator field- DomainToolsFeed IP All Threats Combined Percent that stores the percentage of total domains on the IP that are confirmed or predicted malicious.


##### DomainToolsFeed IP All Threats Percent

- Added a new indicator field- DomainToolsFeed IP All Threats Percent that stores the percentage of domains on the IP including all threat types.


##### DomainToolsFeed IP Bad PDNS Resolutions

- Added a new indicator field- DomainToolsFeed IP Bad PDNS Resolutions that stores the count of confirmed bad domains seen on the IP in the last 24 hours.


##### DomainToolsFeed IP City

- Added a new indicator field- DomainToolsFeed IP City that stores the city derived from geolocation data for the IP address.
