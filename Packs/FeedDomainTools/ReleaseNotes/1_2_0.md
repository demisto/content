#### Indicator Fields

##### DomainToolsFeed IP ASN

- Added a new indicator field: **DomainToolsFeed IP ASN**, which stores the autonomous system number (routing provider) associated with the IP address.


##### DomainToolsFeed IP All Threats Combined Count

- Added a new indicator field: **DomainToolsFeed IP All Threats Combined Count**, which stores the count of confirmed or predicted malicious domains hosted on the IP.


##### DomainToolsFeed IP All Threats Combined Percent

- Added a new indicator field: **DomainToolsFeed IP All Threats Combined Percent**, which stores the percentage of total domains on the IP that are confirmed or predicted malicious.


##### DomainToolsFeed IP All Threats Percent

- Added a new indicator field: **DomainToolsFeed IP All Threats Percent**, which stores the percentage of domains on the IP including all threat types.


##### DomainToolsFeed IP Bad PDNS Resolutions
