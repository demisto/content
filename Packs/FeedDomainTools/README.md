The DomainTools Feed provides real-time access to newly registered and observed domains, enabling proactive threat detection and defense.

## What does this pack do?

- Ingests domain and IP indicators from DomainTools threat feeds (including IP Hotlist and IP Risk).
- Enriches indicators with geolocation, ASN, organization, passive DNS resolution counts, and threat-score fields.
- Provides a dedicated indicator type and layout for IP indicators sourced from DomainTools feeds.
