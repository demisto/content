
#### Parsing Rules

##### F5LTM Parsing Rule

- Added support for F5 BIG-IP iRule HTTP access logs (**ir-log_http**), including deriving **_time** from the *req_st* field.

#### Modeling Rules

##### F5LTM Modeling Rule

- Added mapping for F5 BIG-IP iRule HTTP access logs (**ir-log_http**):
  - Client-side connection: *cssi/cssp* to **xdm.source.ipv4/xdm.source.port**, *csdi/csdp* to **xdm.target.ipv4/xdm.target.port**.
  - Server-side (load-balancer to backend) hop: *sssi/sssp* to **xdm.intermediate.ipv4/xdm.intermediate.port** with **xdm.intermediate.is_proxy**, consistent with the PAN-OS NGFW intermediate/proxy convention to enable NGFW-to-F5 correlation. Note: the backend server endpoint (*ssdi/ssdp*) is not represented distinctly because *xdm.intermediate* holds a single ip/port pair.
  - HTTP enrichment: *htme* to **xdm.network.http.method**, *htur* to **xdm.target.url**, *htho* to **xdm.network.http.domain**, *htst* to **xdm.network.http.response_code**, *hhua* to **xdm.source.user_agent**, *hhrf* to **xdm.network.http.referrer**.
