
#### Integrations

##### Cloudflare Zero Trust

- Fixed an issue where fetching *Access Authentication Logs* could fail with the *access.api.error.invalid_url_parameter_value* error, stopping event collection.
- Fixed an issue where a failure in one event type stopped the other event types from being collected.
- Fixed an issue where a failure while fetching a later page of events discarded the events already fetched, causing the fetch to retry the same time window indefinitely.
