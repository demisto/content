The Contrast Security Pack helps security teams receive and respond to application security incidents and issues detected by Contrast Security. It allows ingestion of both security incidents and vulnerability issues into Cortex XSOAR by polling at a configured interval, allowing teams to take quick actions such as blocking IP addresses, updating ADR (Application Detection and Response) rule modes, managing issue status, and investigating attack observations directly from Cortex XSOAR.

## What does this pack do?

* Fetch Contrast Security Incidents or Issues as Cortex XSOAR incidents through polling-based ingestion.
* List and retrieve Contrast Security Issues with filtering and sorting capabilities.
* List Incident Observations with cursor-based pagination for efficient data retrieval.
* Retrieve detailed information about specific Observations.
* Add comments to Contrast Security Incidents and Issues.
* Update the status of Contrast Security Incidents and Issues.
* Block IP addresses associated with a Contrast Security Incident by creating organization-level IP policies.
* Configure ADR (Application Detection and Response) rule modes per environment (Development, QA, Production) for a Contrast Security application.
* Support bi-directional incident mirroring to keep Cortex XSOAR and Contrast Security in sync.
* Support outgoing issue mirroring from Cortex XSOAR to Contrast Security.
