
#### Integrations

##### Xporter

- Renamed the integration display name from **XSOAR Incident Exporter** to **Xporter**. Existing instances are unaffected; the integration ID and all command names are unchanged.
- Added the **xsoar-exporter-sync-war-room** command to sync War Room entries from Cortex XSOAR incidents to matching Cortex XSIAM issues with deduplication.
- Added the **Sync War Room entries on push** integration parameter to automatically sync War Room entries during incident push.
- Added automatic retry with exponential backoff on Cortex XSIAM API rate limits (HTTP 429).
- Fixed the **update_alerts** API payload format and resolution status values to match the current Cortex XSIAM API.
