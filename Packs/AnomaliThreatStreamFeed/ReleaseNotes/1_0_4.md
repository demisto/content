
#### Integrations

##### Anomali ThreatStream Feed

- Fixed an issue where the ***fetch-indicators*** command consumed excessive memory and failed with an out-of-memory error when the feed returned a large number of indicators.
- Fixed an issue where the ***fetch-indicators*** command repeatedly failed with a timeout error after a single failed fetch cycle. Fetch progress is now saved after every batch of indicators.
- Added the *Maximum indicators per fetch* integration parameter, which limits the number of indicators fetched in a single fetch cycle.
- Added the *Bypass exclusion list* and *Tags* integration parameters.
- Updated the Docker image to: *demisto/py3-tools:1.0.0.13712671*.
