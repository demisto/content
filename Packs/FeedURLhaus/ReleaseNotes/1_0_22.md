
#### Integrations

##### URLhaus Feed

- Fixed an issue where the *fetch-indicators* command failed with a *410 Gone* error after abuse.ch retired the legacy URLhaus download endpoint. The integration now downloads the abuse.ch v2 export of online URLs, and sends the *Auth Key* in the request URL instead of the *Auth-Key* header.
- The *Auth Key* parameter is now required.
- **Breaking change**: The *Feed Fetch Interval* parameter now has a minimum of 5 minutes, as requested by abuse.ch. The *test-module* and *fetch-indicators* commands fail for instances set lower. Raise the interval to 5 minutes or more after upgrading.
- Updated the Docker image to: *demisto/python3:3.12.16.14740428*.
